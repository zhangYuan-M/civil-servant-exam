# 01-图推-位置规律-01-平移

> **讲义对应**：精讲精练-判断 1（讲义 P1–16）
> **一句话**：元素组成基本相同 → 找「谁在动、往哪动、走几步、到边界怎么办」。

---

## 📌 0. 三十秒判断流程

```
数一数各图元素数量
   ├─ 基本相同（全同，或个别少 1）→ 位置规律（平移 / 旋转翻转）
   └─ 差异大 → 不是平移，转去看样式 / 属性 / 数量规律
        ↓
看是不是宫格（9 / 16 / 25 / 蜂窝）
   ├─ 是 → 看中间，判方向
   └─ 否 → 直接找方向与步数
        ↓
定方向 → 定步数 → 定路径（循环 / 反弹）→ 代入选项排除
```

---

## 1. 图形特征：什么时候该想平移

| 特征 | 说明 |
| --- | --- |
| **元素组成基本相同** | 每幅图的元素种类、数量基本一致，只是位置变了 |
| **数量可以「少一个」** | 题干数量 3、2、3、3、3 属正常：两块走到同一格**重合**了 |
| **有格子** | 9 宫格、16 宫格、25 宫格最常见；蜂窝格、六边形也会考 |

---

## 2. 宫格类：看中间，判方向

**第一步永远是看中间**（中心格 / 内圈），由它决定走「绕圈」还是「走直线」。

### 2.1 绕圈走（中间黑块数量相同）

- 内圈黑块数量**每图一样** → 内外圈**分开看**
- 优先看**内圈**：格子少、变化快、最省时间
- 内圈步数：依次顺时针 / 逆时针走 1 格、2 格，或「左右交替」
- 25 宫格中心恒为黑球、蜂窝格中心恒为白球，都是「内外圈」的典型信号

### 2.2 走直线（中间黑块数量不同）

中心数量对不上 → 不走圈，看**行、列上的数量**定方向：

| 观察结果 | 结论 |
| --- | --- |
| 每**行**黑块数量相同 | **左右**走 |
| 每**列**黑块数量相同 | **上下**走 |
| 行列都相同 | 优先左右（更常见） |

---

## 3. 移动路径：循环走 > 反弹走

> 方向：直线（上下左右斜对角），绕圈（顺时针逆时针）；步数：恒定，等差递增

| 路径 | 行为 | 考频 |
| --- | --- | --- |
| **循环走** | 走到头 → 回到起点，继续同方向 | 高 |
| **反弹走** | 走到头 → 原路折返 | 低 |

**做题顺序**：先按循环走验证；循环走解释不通，再试反弹走。不要一上来就假设反弹。

## 4. 提分技巧（本讲核心）

### ① 找一圈 / 半圈（看周期）

图 1 与图 5 内圈位置相同 → 周期是 4 → **「？」应与图 2 一致**。
不用逐格推，直接用周期跳到答案，这是考场最省时的一招。

### ② 优先看「数量少」的列 / 元素

某列只有 1 个黑球时，它的轨迹最清晰，先锁定它，再用它排除选项。

### ③ 相同元素：先标号，再就近假设（多胞胎）

外圈两个黑块长得一模一样时：

1. 先随意标号 1、2；
2. 假设 1 号从图 1 到图 2 走到最近的位置；
3. 一路验证到图 3，能走通就继续，走不通就换假设。

### ④ 两个相同元素看「间隔」

当两个黑块无法区分时，看它们之间的白块数量变化：

| 间隔变化 | 说明 |
| --- | --- |
| 间隔不变 | 同方向、同速度 |
| 间隔每次 +1 | 同方向、前者速度更快 |
| 间隔每次 +2 | 相反方向、各自走 1 格 |

例：间隔 2 → 4 → 6，则「？」应为间隔 8 个白块。

### ⑤ 黑球看不懂，就看白球

平移的对象不一定是黑块。**哪个元素规律明显就先看哪个**（如白球组成「V」字，整体顺时针转一格）。

---

## 5. 特殊路径：一条路走不通就换方向

- 表现：图 1 → 图 2 沿某方向规律成立，图 2 → 图 3 走不通
- 处理：**换一个方向**继续验证（左右不通试上下，斜线不通换另一条斜线）
- 六边形 / 蜂窝格：横竖少见，优先试斜线 `／` 和 `＼`

> 这是近年联考、国考的「难题」——不是规律更复杂，而是**规律中途换向**。

## 📌 6. 易错清单（考前扫一遍）

- [ ] 只数黑块总数就下结论 —— 要看**每行 / 每列**的数量
- [ ] 数量少 1 就以为不是平移 —— 可能是**走重合**
- [ ] 一上来就整体看 —— 应该**先看中间**
- [ ] 循环走没验证就假设反弹
- [ ] 图 1→2 的规律硬套图 2→3 —— 可能**中途换方向**
- [ ] 两个相同元素分不清 —— 没标号、没看间隔
- [ ] 只盯黑球 —— 白球往往更规整
- [ ] 九宫格只会横着看 —— 也可按列看；「米」字形少见，别优先
