# 06-图推-属性规律-02-曲直性与开闭性

> **讲义对应**：精讲精练-判断 2（讲义第 2–5 页）
> **一句话**：元素组成不同 → 先看对称；对称没规律，**别忘曲直性、开闭性**。

---

## 📌 0. 三十秒判断流程

```
元素组成不同 → 属性规律
        ↓
对称性（先排除：只要有一幅图不对称，整组就不看对称）
        ↓
图里有明显的圆、弧、全曲线？
   ├─ 有 → 曲直性：全直 / 全曲 / 曲+直
   └─ 没有，且是生活化 / 粗线条 /「一团黑」→ 开闭性：全封闭 / 全开放 / 半开半闭
        ↓
还选不出 → 数曲线、数直线、做运算（数量规律）
```

> 老师反复强调：**「不要忘记我！」**——曲直性、开闭性考得少，学久了最容易漏。

---

## 一、曲直性

### 1. 图形特征

| 信号 | 说明 |
| --- | --- |
| **出现明显的圆、弧等全曲线图形** | 讲义原文的特征图，最直接的信号 |
| 每幅图都「有曲有直」 | 先想曲直性；无规律再数曲线 / 直线 |
| 细线条图形 | **只有细线条图形**才考虑曲直性 |

### 2. 三种类型

| 类型 | 判定 | 讲义图 |
| --- | --- | --- |
| **全直线** | 图形只有直线 | 图一 |
| **全曲线** | 图形只有曲线（圆、弧） | 图二 |
| **曲 + 直** | 既有曲线又有直线 | 图三 |

> 「曲+直」是独立一类，不要并进全直线。

### 3. 例题（2024 山东，分组分类）

```
① 有曲有直    ② 全曲线    ③ 全直线
④ 有曲有直    ⑤ 全直线    ⑥ 全直线
```

- 先排除对称性（图①不对称 → 整组不看对称）；
- 初步分法：①②④ 含曲线，③⑤⑥ 全直线；
- 更严谨的分法是「①②④ 均为曲+直」——讲义提示：**分组题最好让每组各有自己的规律**，不严谨时才退用「一组有曲线、一组全直线」；
- **答案：B（①②④ / ③⑤⑥）**

### 4. 曲直性选不出 → 接数量规律

```
每幅图都有曲有直
   → 曲直性（先判类型，常选不出答案）
   → 数曲线
   → 曲线数无规律 → 数直线
   → 两个数做运算（谁比谁多 2 条等）
```

- 真题里：曲线数 2、1、6、3、2、3，直线数 4、3、4、1、4、1，单数都无规律；
- 运算后：①②⑤ 一组「直线比曲线多 2」，③④⑥ 一组「曲线比直线多 2」；
- 答疑：**不要按奇偶分组**，极不严谨。

## 二、开闭性

### 1. 图形特征

| 信号 | 说明 |
| --- | --- |
| **生活化图形** | 银行标志、邮箱标志这类日常图案 |
| **粗线条图形** | 粗线条画出来的图形，无细线可辨 |
| 「一团黑」 | 无法看曲直，直接看开闭 |

### 2. 三种类型

| 类型 | 判定 | 讲义图 |
| --- | --- | --- |
| **全封闭** | 外部有轮廓，内部有封闭空间 | 图一 |
| **全开放** | 内部没有封闭空间 | 图二 |
| **半开半闭** | 既有封闭空间，又有开放区域（外侧有出头的线条、有端点） | 图三 |

**两个判例（讲义原文）**：

- 「○—」圆内一条横线 → **全封闭**（线在圆内，没有出头）；
- 圆内一条横线 + 圆外连着一条直线、外侧有端点 → **半开半闭**。

> 一句话判据：**看有没有「出头的线 / 端点」**——有端点就是开放的信号。

### 3. 例题（2024 事业单位，分组分类）

- 图①既不是轴对称也不是中心对称 → 整组排除对称性；
- 题干全是「一团黑」的图形 → **无法看曲直**，只剩开闭性；
- ①③④ 没有白色封闭区域 → **全开放**；②⑤⑥ 内部有封闭空间 → **全封闭**；
- **答案：D（①③④ / ②⑤⑥）**

**讲义答疑要点**：

1. 图①外圈 5 个部分，中心对称要求正倒一样、左右对应，5 是奇数对不上 → 不对称；
2. 生活化、粗线条图形，**可直接考虑开闭性**；
3. 不能分成「一组中心对称、一组不是」——**分组后每组内部都要各自成立**。

## 📌 三、曲直性 vs 开闭性：怎么快速选

| 看到什么 | 先想哪个 |
| --- | --- |
| 明显的圆、弧、细线条 | **曲直性** |
| 生活化图案、粗线条、「一团黑」 | **开闭性** |
| 有缺口的图形（有端点） | 开闭性（半开半闭） |
| 每幅图都有曲有直 | 曲直性 → 曲线数 → 直线数 → 运算 |

> 顺序：**先对称（能排除就排除）→ 再曲直 → 再开闭 → 最后数量**。

---

## 📌 四、易错清单

- [ ] 属性只想到对称性，忘了曲直、开闭（老师最常提醒的一点）
- [ ] 有「等腰」元素却先看曲直 —— 对称优先
- [ ] 「一团黑」还硬看曲直性
- [ ] 把「曲+直」当成「全直」
- [ ] 曲直性选不出却不接数量（曲线数 / 直线数 / 运算）
- [ ] 分组题两组判据不统一（一组按曲直、一组按数量）
- [ ] 半开半闭看漏「出头的线 / 端点」
- [ ] 按奇偶分组、或「一组对称一组不对称」这种不严谨分法

---

## 📌 五、口诀

> 各不相似想属性，先对称、再曲直、后开闭；
> 圆月弧形看曲直，全直全曲加混合；
> 曲直不分就数线，曲线不够数直线；
> 生活化、粗线条，一团黑只看开闭；
> 有端点、有出头，半开半闭别认错。
