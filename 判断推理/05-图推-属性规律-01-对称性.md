# 图推-属性规律-第1讲-01对称性

> **讲义对应**：精讲精练-判断 1（讲义第 34–42 页）
> **一句话**：元素**各不相同**、又出现「等腰」形状 → 画出对称轴，按「类型 → 数量方向 → 线点面」逐层看。

---

## 0. 30 秒判断流程

```
元素组成相同 → 位置规律
元素组成相似 → 样式规律
元素组成不同（各不相同、不相似）→ 属性规律 ← 本节
        ↓
出现「等腰」元素 / 平行四边形 / S·N·Z → 对称性
        ↓
画出对称轴
   ├─ 先看类型：轴对称 / 中心对称 / 轴+中心
   ├─ 再看数量、方向（旋转 45° 递推；可用周期）
   └─ 还选不出 → 对称轴与原图的「线 → 点 → 面」关系
        ↓
两个图形挨着 / 内外分开 → 分开画对称轴，看两条轴的关系
```

---

## 1. 图形特征

| 信号 | 说明 |
| --- | --- |
| **元素组成不相同、不相似** | 属性规律的入口，每幅图长得都不一样 |
| 「等腰」元素 | 等腰三角形、等腰梯形、箭头、五角星——先想**轴对称** |
| 平行四边形、S / N / Z 变形 | 先想**中心对称** |
| 相同图形反着放 | 中心对称的典型信号 |
| 考频 | 国考、联考几乎每年必考，是属性规律里最重要的一类 |

---

## 2. 三种对称类型

| 类型 | 判定 | 特征图 | 易错 |
| --- | --- | --- | --- |
| **轴对称** | 沿一条线折叠，两侧完全重合 | 等腰三角形、等腰梯形、箭头、五角星 | 五角星**只是**轴对称 |
| **中心对称** | 正看、倒看长得一样（旋转 180° 重合） | 平行四边形、S/N/Z 及变形、相同图形反着放 | 五角星正倒不同，**不是**中心对称 |
| **轴 + 中心对称** | 存在**两条相互垂直**的对称轴 | 正方形、圆（无数条轴） | 「垂直」是关键词，不是随便两条轴 |

> 判断顺序：先看有没有「等腰」→ 再看正倒是否一样 → 最后看有没有两条相互垂直的轴。

---

## 3. 四种考法（按顺序想，别乱）

### ① 区分对称类型

分组分类最常见：一组「仅轴对称」，另一组「轴+中心」。
辅助判据：**对称轴数量**——1 条多为纯轴对称，2 条且垂直多为轴+中心。

### ② 对称轴的数量与方向

| 维度 | 说明 |
| --- | --- |
| 数量 | 如 6、5、4、3、2 等差递减；正方形 4 条、圆无数条 |
| 方向 | 每幅图固定转同一角度，常见 **45°**（顺时针为主） |
| 加速 | **周期**：图 5 方向与图 1 相同 → 「？」与图 2 相同 |

### ③ 对称轴与原图的「线 → 点 → 面」

数量、方向都选不出唯一答案时才看这一层，**按考频从高到低试**：

| 顺序 | 看什么 | 判据 |
| --- | --- | --- |
| 1 | **线** | 对称轴有没有与原图的线条**重合** |
| 2 | **点** | 对称轴有没有经过原图的**交点** |
| 3 | **面** | 对称轴经过了原图的**几个面**（常考数量：1 / 2 / 3 个） |

> 「面数量」是近年最火考法，2023 国考、2017 河南几乎同题。

### ④ 两个图形挨着 / 内外分开 → 分开看

整体不对称时，**分别**画出两个图形的对称轴，看两条轴的关系：

| 关系 | 结论 |
| --- | --- |
| 平行 | 一类 |
| 垂直 | 一类 |
| 重合 | 一类 |

---

## 4. 解题四步（默写版）

1. **识别**：元素组成不同 + 「等腰」元素 → 对称性；
2. **画轴**：一定要把对称轴画出来（不画容易看错）；
3. **数量 / 方向**：能选出唯一答案就停手；
4. **线 → 点 → 面**：仍选不出再逐层加深；两面挨着就分开画轴。

---

## 5. 易错清单

- [ ] 看到「等腰」却先数面 / 数线，没先画对称轴
- [ ] 把五角星当成中心对称
- [ ] 数量、方向就能选出答案，却继续分析线点面（浪费时间）
- [ ] 线/点/面顺序乱试 —— 应按 **线 → 点 → 面**（考频排序）
- [ ] 两面挨着还整体看对称 —— 应**分开**画轴
- [ ] 看不出「轴 + 中心」的判据是**两条垂直轴**
- [ ] 忘了周期技巧（图 1 与图 5 相同 → 答案与图 2 相同）
- [ ] 分组题选「一组对称、一组不对称」这种不严谨的分法

---

## 6. 口诀

> 各不相似想属性，等腰先画对称轴；
> 类型数量再方向，线点面按顺序走；
> 垂直两轴是复合，正倒一样中心对称；
> 两面挨着分开画，轴轴平行或垂直；
> 图一图五若同向，答案常在图二处。

---

## 7. 训练建议

1. **画轴强迫症**：所有对称题都动笔画轴，练到不画也能看出方向；
2. **分层练**：先专练「数量方向」20 题，再专练「线点面」20 题；
3. **真题复现**：2017 河南、2019/2020/2023 国考连着做，体会出题套路；
4. **错题归因**：写清是「类型看错」「数量数错」还是「线点面顺序用反」。

---

## 8. 属性规律全景（判断2 的提醒）

| 考点 | 特征图 | 一句话打法 |
| --- | --- | --- |
| **对称性** | 「等腰」、正倒一样、垂直两轴 | 画轴 → 类型 → 数量方向 → 线点面 |
| **曲直性** | 明显的圆、弧、全曲线 | 全直 / 全曲 / 曲+直，不够就数线 |
| **开闭性** | 生活化、粗线条图形 | 全封闭 / 全开放 / 半开半闭 |

> 老师原话的意思：**对称性无规律后，千万别忘了曲直性、开闭性**——这两个考点考得少，最容易学久了就忘。
