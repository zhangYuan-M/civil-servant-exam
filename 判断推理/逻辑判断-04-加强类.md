# 判断推理 · 逻辑论证「加强类」

> 整理自：2026.06.19 精讲精炼-判断11（搭桥）、2026.06.20 精讲精练-判断12（必要条件、补充论据、不能加强）

## 0 专题地图

```
加强 = 证明题干结论成立 / 论证成立
│
├─ 一、搭桥 ← 力度最强，问"前提/假设"首选（约 90% 的前提题）
│   ├─ 普通搭桥：去同存异，把论点、论据的差异词连起来
│   └─ 翻译类搭桥：箭头前一致 / 箭头后一致，注意方向
│
├─ 二、必要条件 ← 问"前提"但无搭桥项时才用（约 10%）
│   └─ 没它不行（否定代入）
│
└─ 三、补充论据 ← 考得最多（加强题的绝对主力）
    ├─ 解释原因：整体上说明为什么成立
    └─ 举例支持：部分上举一个例子
```

**力度排序**：搭桥 ≈ 必要条件 ＞ 原因解释 ＞ 举例支持。
**直接复述论点、直接复述论据都没有意义，不考。**

### 0.1 题量分布（据此分配复习精力）

| 加强题数量 | 大致构成 |
|---|---|
| 3 道 | 2 道补充论据 + 1 道搭桥 |
| 4 道 | 3 道补充论据 + 1 道搭桥 |
| 5 道 | 4 道补充论据 + 1 道搭桥 |

- 问"前提/假设"的题通常只考 **1 道**，其中约 90% 是搭桥、10% 是必要条件。
- 一套题里 5 道论证题，常见构成：1 道搭桥、1 道"傻瓜题"、1—2 道特殊题型（因果类、实验类）、1—2 道需要对比择优。

> 结论：**补充论据是基本盘，搭桥是必拿分，必要条件是低频补丁。**

## 1 加强题识别与总打法

### 1.1 提问方式

| 类型 | 表述 | 对应方法 |
|---|---|---|
| 普通加强 | 最能**加强 / 支持 / 赞同 / 证明**上述论断（结论、观点）的是 | 补充论据 |
| 前提类 | 上述论断成立的**前提 / 假设 / 必要条件**；需要补充的**前提**；暗含的**前提**；**加强论证** | **搭桥**（无搭桥→必要条件） |
| 反面 | **不能**加强上述论断的是 | 排除法（见第 5 节） |

> "前提/假设"是特殊问法，考特殊方法；"支持/加强"是普通问法，考补充论据。

### 1.2 通用四步法

1. **读提问**：加强、前提，还是"不能加强"。
2. **读题干**：找论点、论据，判断话题是否一致。
3. **做预设**：按问法确定加强方式。
4. **读选项**：匹配 + 对比择优。

### 1.3 三种加强方式

| 方式 | 加强的是什么 | 典型问法 | 力度 |
|---|---|---|---|
| **搭桥** | 论据→论点这条"桥" | 前提、假设 | 最强 |
| **必要条件** | 论点本身成立的前提 | 前提（无搭桥项） | 最强 |
| **补充论据** | 给论点补新证据 | 支持、加强 | 原因解释 > 举例 |

> 为什么"加强论点"不考？重复论点毫无信息量；"加强论据"也只是复述。命题人只考**补新论据**。

### 1.4 两条判定路径（选一条用熟）

**路径 A（快）——看问法**
- 问"前提/假设" → 搭桥（找差异词）
- 问"加强/支持" → 补充论据（只找论点关键词）

**路径 B（稳）——看话题**
- 只有论点 → 补充论据；若问"前提" → 必要条件
- 话题一致 → 补充论据
- 话题不一致 → 搭桥

> 两条路径结论通常一致。路径 A 的风险是"支持"题偶尔考搭桥（概率很小）；不放心用路径 B。

### 1.5 一张决策流程图（考场照此走）

```
读提问
├─ "不能加强" ─────────────→ 排除法：去掉所有能加强的
├─ "前提 / 假设 / 必要条件"
│   ├─ 论点、论据话题不一致 → 搭桥（去同存异）
│   ├─ 有明显翻译词 ───────→ 翻译搭桥（先翻译，再看箭头方向）
│   └─ 只有论点 / 无差异词 → 必要条件（没它不行）
│                             └ 论点为"方式+目的"：方式可行 / 目的能实现
└─ "加强 / 支持 / 证明"
    ├─ 话题一致 / 只有论点 → 原因解释 ＞ 举例
    └─ 话题不一致 ─────────→ 搭桥
```

## 2 加强之一：搭桥（力度最强）

**本节要点**：话题不一致时用；**去同存异**找差异词；**方向是论据→论点**；翻译题先翻译再补箭头。

### 2.1 什么是搭桥

**在论点与论据之间建立联系**，把论证的窟窿堵上。

> 论据"今天太热了" → 论点"今天适合看电影"　搭桥：**天热就该看电影**
> 论据"听课能学到解题技巧" → 论点"听课能提升成绩"　搭桥：**学到技巧就能提高成绩**
> 论据"文理科状元都在一中" → 论点"一中教学质量高"　搭桥：**有状元就说明教学质量高**

本质：话题不一致 → 论证有漏洞 → 削弱是点破漏洞，加强是**堵上漏洞**。

### 2.2 搭桥有方向：论据 → 论点

> ✅ 有状元 → 教学质量高
> ❌ 教学质量高 → 有状元（这是另一个命题，完不成论证）

**判断法**：把选项代入，看"论据 + 选项 → 论点"是否顺；或看箭头是否从论据指向论点。

### 2.3 去同存异：三步

1. 找论点、找论据；
2. **划掉相同词**（相同词不重要）；
3. 剩下的**差异词**必须同时出现在正确选项里，并建立联系。

**两个操作提示**
- 论据、论点**一长一短**时，**从短的一方入手**（短句差异词好锁定）。
- 关键词太多、分不清"同"和"异"时，直接**选项代入**，找同时含两侧差异词的选项。

### 2.4 题型特征

1. 提问为"**前提、假设**"——90% 以上的搭桥题这样问；
2. 论点与论据**话题不一致**；
3. 少数问"支持/加强"的题也考搭桥，此时用"话题是否一致"判断。

### 2.5 选项特征

**同时包含论点、论据的关键词（差异词），并肯定二者关系。**

> 反例：只含一侧关键词、反复说相同词、说"二者不一定有关"——都不是搭桥。

### 2.6 普通搭桥真题精析（真题 01—10）

#### 真题 01（2025 天津·牙龈卟啉单胞菌）→ D

- 论点："牙龈卟啉单胞菌**极有可能导致**小鼠患阿尔茨海默症"。
- 论据：喂后脑内 **Aβ 沉积增加**、**炎症更严重**。
- 去同存异：相同＝细菌、小鼠；差异＝"阿尔茨海默症" ↔ "Aβ 沉积 / 炎症"。
- A、C 只提阿尔茨海默症，B 三者皆无。
- **D**：β-淀粉样蛋白沉积是形成阿尔茨海默症的**重要一环** ✅

#### 真题 02（2026 天津·手写）→ D

- 论点："手写在**学习阅读和识别字母形状**方面更具认知优势"。
- 论据："手写增强多区域**功能连通性**"。
- 差异＝"阅读识别字母" ↔ "连通性"。
- **D**：连通性越强，阅读和识别字母形状的能力越强 ✅
- 注意：B"被试均能识别单词"加强的是实验本身，问"前提"时不选。

#### 真题 03（2026 广东·太空计算卫星）→ D

- 论点："将**广泛应用于应急安全、城市治理等领域**"。
- 论据："具备强大的**数据实时处理能力**"。
- C、D 都含两差异词；再比：论据是"数据的**处理**"，D"需要实时**处理**的数据" ✅（C 说"采集"）

#### 真题 04（2026 浙江·miR-205）→ D

- 论点："增强 miR-205 表达可使**细胞软化**并促进毛发生长"。
- 论据："细胞骨架**软化**时促使毛发再生"。
- 差异＝miR-205 ↔ 细胞骨架软化。
- **D**：miR-205 对软化细胞骨架起重要作用 ✅
- A 毛发软硬、B 基因手段、C 抑制增殖分化（背景词）均非差异词；本题关键词多，宜用**选项代入**。

#### 真题 05（2022 联考·发酵蔬菜）→ B

- 论点："可**改变人体免疫状态**，有望减少炎症"。
- 论据："增加**肠道微生物多样性**"。
- **B**：肠道微生物群**影响全身免疫系统** ✅

#### 真题 06（2025 重庆选调·食虫动物）→ B

- 论点："食虫动物可**减缓全球气候变暖**"。
- 论据："减少植物天敌，**对植物生长有正面影响**"。
- **B**：植物吸收二氧化碳释放氧气可减缓全球变暖 ✅（解释原理，连接差异）

#### 真题 07（2023 国考·杂草稻 PAPH1）→ C

- 论点："PAPH1 基因在杂草稻**抗旱性**中发挥关键作用"。
- 论据：消除该基因→钙、钾离子流速降低；过度表达→流速增加。
- 论据长、论点短 → **从论点出发**，论点差异词是"抗旱性"。
- A、B、D 均未落在"抗旱性" → **C**：钙钾离子流速越高，杂草稻的抗旱性越强 ✅

#### 真题 08（2022 联考·吃辣）→ B

- 论点："**吃辣**可以促进造血干细胞动员"。
- 论据：伤害感受神经调控动员；CGRP 可增强动员。
- 差异＝"吃辣" ↔ "伤害感受神经"。
- **B**：辣味是一种痛觉，会**激活伤害感受神经** ✅
- C 谈消化液、胃肠蠕动，与论据链无关。

#### 真题 09（2025 国考·PM2.5）→ A

- 论点："癌症死亡风险增加**可能与 PM2.5 有关**"。
- 论据："PM2.5 会导致脏器的**炎症和氧化应激反应**"。
- 差异＝"炎症/氧化应激" ↔ "癌症"。
- **A**：脏器的炎症和氧化应激反应是明确的**致癌危险因素** ✅

#### 真题 10（2022 天津·法国移民）→ A

- 论点："发现了**法国人**大规模移民英国的证据"。
- 论据：青铜时代早期到晚期，英格兰和威尔士的**早期欧洲农民血统**比例从 30% 升到 36%。
- 差异＝"法国人" ↔ "早期欧洲农民血统"。
- **A**：迁徙的法国人拥有一定比例的早期欧洲农民血统 ✅

### 2.7 翻译类搭桥（真题 11—12）

**特征**：出现"如果…那么…""只有…才…""所有…都…"，先翻译再补前提。

| 结构 | 论据 | 论点 | 补什么 |
|---|---|---|---|
| 箭头**前**一致 | 甲→乙 | 甲→丙 | **乙→丙**（论据词→论点词） |
| 箭头**后**一致 | 甲→乙 | 丙→乙 | **丙→甲**（论点词→论据词） |

**口诀**：**箭头前一致，论据词→论点词；箭头后一致，论点词→论据词。**

**为什么**：补的项必须能与论据"穿串"——甲→乙 与 乙→丙 可串；与 甲→丙 串不起来。

示例：论据"考上→请吃饭"，论点"考上→破费" → 补"请吃饭→破费"；论据"下雨→不出去"，论点"起风→不出去" → 补"起风→下雨"。

#### 真题 11（2023 联考·志愿文学）→ A

- 论据：①志愿文学→志愿者；②志愿者→不脱离生活 ⇒ 志愿文学→不脱离生活。
- 论点：这本小说→不是志愿文学；逆否：不脱离生活→不是志愿文学。
- 需补"这本小说→脱离生活" ✅（反向无法串联）

#### 真题 12（2024 浙江·美术馆）→ D

- 论据：艺术阅读或版画；艺术阅读→不参加书法；小苏参加书法。
- 推理：小苏书法 ⇒ 没参加艺术阅读 ⇒ 参加版画实践。
- 论点：小苏参加手工剪纸 ⇒ 需"版画实践→手工剪纸"。
- C 是"剪纸→版画"（方向反）；**D**"不参加剪纸的都不参加版画"＝**版画→剪纸** ✅
- 记忆：**"不……不……"后推前**。

### 2.8 搭桥的方向与择优

- 只有一个选项含差异词 → **不管方向**，直接选。
- 多个选项含差异词 → 比方向（谁能与论据穿串）。
- 搭桥项必须"肯定有联系"，不能是"不一定/无关"。

### 2.9 搭桥 vs 拆桥（一张表分清）

| | 搭桥（加强） | 拆桥（削弱） |
|---|---|---|
| 目的 | 证明论证**成立** | 证明论证**不严谨** |
| 操作 | 找差异词并**建立**联系 | 找差异词并**断开**联系 |
| 方向 | **有方向**：论据→论点 | **无方向**：A≠B 即 B≠A |
| 常见问法 | 前提、假设 | 削弱、质疑 |
| 表述 | 肯定"有联系/是一回事" | "不必然/不是一回事" |

## 3 加强之二：必要条件

**本节要点**：没它不行；问"前提"先搭桥，**无搭桥项**才用它；论点若为"方式+目的"，另走"可行/有效"。

### 3.1 什么是必要条件

**没它不行**：选项不成立，论点就成立不了。

> 论点"老师是我的女神"
> A. 老师是个女的 ✅（不是女的，绝不可能是女神）
> B. 老师爱吃火锅 ❌（不爱吃火锅，不影响是女神）

**否定代入法**：设选项为假，看论点是否还站得住；站不住 → 必要条件。

- 论点"多吃芹菜有助于控压"；A"芹菜中利于控压的营养物质**能被人体吸收**" ✅；B"对肠胃有刺激性"（副作用）；C"更多人靠药物"（无关）。
- 论点"裁掉效率低的员工"；必要条件是"**有区分效率高低的方法**"。

### 3.2 搭桥 vs 必要条件（分工）

| | 搭桥 | 必要条件 |
|---|---|---|
| 加强的是 | **论证关系**（论据→论点） | **论点本身** |
| 是否看论据 | 必须看（找差异词） | 不看论据，只看论点 |
| 何时用 | 问"前提"，优先 | 问"前提"，**无搭桥项**时 |
| 考频 | 约 90% 的前提题 | 约 10% |

> 二者力度相同。实战：问"前提"先按搭桥找差异词；找不到搭桥项，再想"没它不行"。
> 另外注意：问"前提/假设"时，若选项只是在"加强实验"（如样本、测量无误），通常不选——它不是论点成立的前提。

### 3.3 必要条件真题精析（真题 13—14）

#### 真题 13（2025 事业单位·集中营业区）→ C

- 论点："设置集中营业区，**这样就能够缓解占道经营的交通堵塞**"。
- 前文只是"有问题、引居民不满"的背景，**没有论据** → 只有论点 → 必要条件 / 方式+目的。
- 论点＝方式（设集中营业区）+ 目的（缓解拥堵）：加强方式可行 / 目的能实现。
- A 不收费、B 放得下、D 能多赚钱 → 都要再推"小摊贩会去"。
- **C**：小摊贩**会前往该处摆摊** ✅
- 易错：D 实现的是"**别的**目的"（让摊贩多赚钱）。

#### 真题 14（2026 上海·亚洲象）→ A

- 论点：缓解人象冲突**需结合栖息地连通等长期手段**。
- 论据：大象若形成固定农田觅食习性，即使有食物源基地仍会因"**路径依赖**"进入人类区域。
- 无差异词，搭桥生硬 → 必要条件 / 普通加强。
- **A**：大象觅食主要受**既往觅食路径**影响，而非食物可获得性 ✅
- B 不必覆盖全部活动区域；C"提升偏好"没说好到不来农田；D 与栖息地连通无关。

### 3.4 方式 + 目的（加强版）

**加强两招**：① **方式可行**；② **目的能实现**。

**两个易错点**
1. **花钱 ≠ 不可行**：只有涉及**老百姓的钱/普及**才考虑成本；国家公共建设花钱不算问题。
2. **目的别找错**：论点的目的是"缓解拥堵"，选项说"让摊贩多赚钱"就是别的目的。

## 4 加强之三：补充论据（最常考）

**本节要点**：问"加强/支持"、只有论点或话题一致时用；**解释原因（整体）＞ 举例（部分）**；答案必有论点关键词。

### 4.1 两种形式

| 形式 | 含义 | 性质 |
|---|---|---|
| **解释原因** | 说明论点**为什么**成立（原理、机制） | 整体 |
| **举例支持** | 举一个**具体例子**证明论点 | 部分 |

> 论点"多吃芹菜有助于高血压患者控压"
> A. 芹菜中的营养物质能被吸收（必要条件）
> B. 老明爱吃芹菜，多年高血压得到控制（**举例**）
> C. 芹菜中的丁基苯酞类物质能抑制血管平滑肌紧张、减少肾上腺素分泌，从而降压（**解释原因**）

### 4.2 适用条件

1. **只有论点**；
2. **论点与论据话题一致**；
3. 提问为"**支持/加强**"。

### 4.3 力度

**搭桥 ≈ 必要条件 ＞ 原因解释 ＞ 举例支持。**
原因解释是整体、例子是部分 → **整体优于部分**。
不要选复述论点的选项；但若它是**唯一**含全部论点关键词的，只能选它。

### 4.4 正确答案特征

**与论点关键词一致，或同义替换。**
- "新技术促进神经科学" → "新技术可测量神经元活动"
- "城市线级与青年时间贫困率正相关" → "线级越高通勤越长，挤压可支配时间"
- "汉长安城成为唐长安城一部分" → "渭南内城被划入唐长安城禁苑"
- "人类嗅觉退化" → "嗅觉中枢在大脑皮层占比减少"

> **只盯论点关键词**，缺关键词的直接排除，不必逐字读。

### 4.5 补充论据真题精析（真题 15—24）

#### 真题 15（2024 山西·海平面上升）→ D

- 论点："海平面上升**理应成为该组织的重要议题**"。
- A 未提海平面、B 只提上升快、C 只提其他议题降级。
- **D**：海平面上升是威胁且让各种威胁成倍增加，**该组织应发挥关键作用** ✅

#### 真题 16（2026 国考·合成数据）→ C

- 论点："合成数据的使用会**影响 AI 的准确性**"。
- A 隐私、B 复杂性、D 泛化能力 → 都不是"准确性"。
- **C**：合成数据会**放大源数据的错误或偏差**，"失之毫厘，差之千里" ✅

#### 真题 17（2026 四川·腌制菜）→ C

- 论点："腌制菜中的**亚硝酸盐**是食道癌高发主因，建议少吃"。
- B 提"高盐食物诱发癌症"、C 提"亚硝酸盐→强致癌"。
- 择优：①核心词是"**亚硝酸盐**"，B 未提；②C"极强致癌"更绝对；③B 把"腌制菜"扩成"高盐食物"，范围跑偏。
- **C**：亚硝酸盐与胃中蛋白质分解物反应，生成**极强致癌性**的亚硝胺 ✅

#### 真题 18（2025 重庆选调·鸟类体型）→ B

- 论点："鸟类体型变小是**适应气候变暖**的结果"。
- A 比"温暖 vs 寒冷"的静态差异，未提温度变化；C、D 未提"体型"。
- **B**：全球变暖过程中，鸟类通过**改变体型大小**以适应 ✅
- 说明：B 近似复述论点，只因其**唯一同时含两个关键词**才选；这是"择优"而非"完美"。

#### 真题 19（2026 国考·平台企业）→ B

- 论点："平台企业**金融化**加深，使**劳动者权益**保护问题突出"。
- B 与 D 都谈对劳动者不利，三个维度 B 更优：
  1. **整体 > 部分**：B"平台企业" ＞ D"**部分**平台企业"；
  2. **越绝对越好**：B"增加就业不稳定性" ＞ D"限制在多平台就业"；
  3. **越接近论点**：B"塑造轻资产形象、摆脱劳动密集型标签"正是"金融化"的内涵。
- **B** ✅（三原则择优样板题）

#### 真题 20（2025 江苏·AI 内容质量）→ C

- 论点："AI 输出内容质量会**断崖式下降**"。
- A"站不住脚"（现在不行）、C"污染训练数据"（现在和将来都不行）、D"垃圾信息"（不看就没影响）。
- **C**：虚假垃圾内容回流**污染训练数据** ✅（最严重，对应"断崖式"）

#### 真题 21（2024 湖北选调·角质酶 T）→ B

- 论点：角质酶 T 可在**两天内**将 **PBAT** 分解至消失。
- 关键词三件套：角质酶 T、48 小时、PBAT。
- A 缺两天与 PBAT；C 缺两天且"循环利用"题干未提；D 说筛选困难。
- **B**：产生 4 种碎片或颗粒，**都在 48 小时内降解消失** ✅（展开解释过程，不算复述）

#### 真题 22（2025 湖北选调·珠峰）→ D

- 论点："这是珠峰成为世界最高峰的**一个原因**"，"这"指"河流改道、**侵蚀带走大量岩石土壤**"。
- A"地壳释放"≠上升；B"隆升 50 米"是另一项研究（举例），且不能说明成为最高峰；C"有影响"太模糊。
- **D**：侵蚀带走岩石土壤，珠峰因附近地壳质量减少而**缓慢上升** ✅（原理强于举例）

#### 真题 23（2022 四川下·书报亭）→ B

- 论点："**恢复书报亭十分必要**"。
- 题干大半在讲"中学生来信、青少年"，那是论据/背景。
- A 说退出必然（削弱）、C/D 谈报纸杂志与青少年（未提书报亭）。
- **B**：书报亭有很强社区服务功能，是居民获取信息的重要渠道 ✅
- 教训：**不能因题干篇幅长，就把论据里的词当论点关键词。**

#### 真题 24（2023 四川·智能客服）→ D

- 论点："**人工客服不能缺位**"。
- A、B、C 全在谈智能客服痛点，**都没提人工客服**。
- **D**：两者并非互相取代，**人机协同**能更好回应诉求 ✅

### 4.6 小结

1. 只有论点 / 话题一致 → 优先**解释原因、举例**。
2. 看清**论点的主体和话题**，别被长论据带跑。
3. 正确答案：**论点关键词或同义替换**。
4. 择优：**整体 ＞ 部分；必然 ＞ 可能；越接近论点越好**。

## 5 特殊提问：不能加强

- **问"不能加强"**：削弱与无关都可，**排除所有能加强的选项**。
- 不预设，逐项判"能否加强"。
- 补充：遇到特殊提问，若拿不准方法，**优先试搭桥，其次必要条件**（命题人常在此处做文章）。

#### 真题 25（2026 国考·物种研究）→ D

- 反对者论点："科学研究**重点突破**比'一视同仁'更有意义"。
- A 选择性专门研究使作物增产、B 重点研究更易揭示规律、C 某些物种研究有特殊号召力 → 均加强。
- **D**：普通树袋熊论文 5000 多篇，**更濒危**的昆士兰毛吻袋熊不到 1000 篇 → 与"应重点研究重要对象"相反/无关 ✅
- 说明：本题论点含比较，但"不能加强"题允许出现不含比较的选项，属命题不严谨，按排除法处理即可。

## 6 力度与择优总表

| 维度 | 结论 |
|---|---|
| 按方式 | 搭桥 ≈ 必要条件 ＞ 原因解释 ＞ 举例 |
| 按范围 | 整体 ＞ 部分 |
| 按语气 | 越绝对/越明确越好（"极强致癌"＞"诱发癌症"） |
| 按贴合 | 论点关键词一致 ＞ 范围更大 ＞ 范围更小/跑题 |
| 按必然性 | 必然 ＞ 可能 |
| 特殊 | 复述论点/论据最弱，通常不选；唯一含关键词时选 |

### 6.1 三组易混对比

| 对比项 | 区别 |
|---|---|
| **搭桥 vs 拆桥** | 一个建立联系、一个有方向；一个断开联系、无方向（见 2.9） |
| **原因解释 vs 举例** | 解释原理是整体，举例是部分；**整体 > 部分**（见 4.3） |
| **加强"越绝对" vs 日常结论"从弱"** | 论证题越绝对越好；日常结论题越委婉越好（"可能"优先） |

## 7 高频陷阱清单

1. **只谈论据不谈论点**：长题干里选项复述论据（书报亭、智能客服、无人机）。
2. **目的找错**：方式"设集中营业区"，目的"缓解拥堵"，选项却说"让摊贩多赚钱"。
3. **花钱当不可行**：成本高不影响可行性；只有涉及百姓负担才考虑钱。
4. **搭桥方向反了**："教学质量高→有状元"。
5. **只含相同词**：反复说"手写""太空计算卫星"，没连差异词。
6. **偷换核心词**：论点"准确性"，选项说"泛化能力""复杂性"。
7. **范围被放大**：论点"腌制菜"，选项变"高盐食物"。
8. **诉诸权威**：专家**主观认为**不算；专家**研究得出**的可以。
9. **必要当充分**：选"没它不行"，不是"有它就行"。
10. **只加强实验**："被试都能识别单词"，问前提时不选。
11. **比较错位**：只谈比较一方或换对象（"不能加强"题除外）。
12. **无关新概念**："被子植物""避险""循环利用"。

## 10 一页速记

1. **问"前提/假设"→ 搭桥**；**问"加强/支持"→ 补充论据**；搭桥找不到 → **必要条件**。
2. **搭桥 = 去同存异**：划掉相同词，答案必须含**差异词**并建立联系。
3. **搭桥有方向**：论据 → 论点；翻译类：**箭头前一致，论据词→论点词；箭头后一致，论点词→论据词**。
4. **必要条件 = 没它不行**：否定代入，选项为假则论点不成立。
5. **补充论据**：解释原因（整体）＞ 举例（部分）。
6. 正确答案：**论点关键词或同义替换**；缺关键词直接排除。
7. **无论据多长，以论点为核心**，别被篇幅带偏。
8. **方式+目的**：方式可行 / 目的能实现；**花钱≠不可行**；**目的别找错**。
9. 三原则：**整体＞部分、越绝对越好、越接近论点越好**。
10. **不能加强**＝排除法；与日常结论"从弱原则"正好相反。
