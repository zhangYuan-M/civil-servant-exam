# 判断推理 ·「组合排列」完整讲义

> 整理自：2026.06.16 精讲精练-判断8（徐来）

---

## 0 专题地图与考情

```
组合排列 = 两组及以上对象 + 对象之间的关系 → 求匹配/排序
│
├─ 一、排除法 ← 题干条件确定 + 选项信息完整
│   └─ 读一句、排一句（找"谁是谁"和"谁不是谁"）
│
├─ 二、代入法 ← 题干条件不确定 / 特殊问法
│   ├─ 假设选项为真，代入题干验证
│   ├─ 技巧：每个人均一对一错 → 最小信息假设
│   └─ 技巧：一人全对、一人全错、一人一对一错 → 最大信息假设
│
└─ 三、推理法 ← 不符合排除、代入特征时
    ├─ 起点：确定信息（谁=谁 / 谁≠谁）
    ├─ 手段：列表、顺藤摸瓜
    └─ 场景：排序间隔、圆桌方桌方位
```

**考情**

| 考试 | 题量 |
|---|---|
| 省考联考 | 一般 1 道（近两年可能 1—2 道，大概率 0—1 道） |
| 国考地市级、行政执法类 | 一般 5 道（**材料题**，一段材料带 5 问） |
| 国考副省级及以上 | 1—2 道 |
| 事业单位 | 参照副省级 |

> 近两年组合排列偏难。**关键不是算，而是选对方法、找对破题点。**

---

## 1 题型识别

**两个特征同时具备**：
1. **两组及以上对象**（人、地点、时间、颜色、课程……）；
2. 给出**对象之间的关系**（谁比谁大、谁不在哪、谁和谁相邻）。

例：甲、乙、丙三人，一位来自东京、一位来自巴黎、一位来自土耳其。已知"丙比东京人年龄大，甲和巴黎人不同岁，巴黎人比乙年龄小"——两组对象（人、城市）+ 关系 → 组合排列。

**常见变体**
- 排序：1—6 号货架、一排座位、名次先后。
- 匹配：人—专业—书、人—课程、人—颜色。
- 方位：圆桌/方桌，左右相邻、相对。
- 真假：每人说两句话，一对一错。

---

## 2 方法选择（先定方法，再动笔）

### 2.1 决策流程

```
读题
├─ 有特殊问法？
│   ├─ "可能 / 不可能"、"符合 / 不符合" ─────→ 代入法
│   └─ "补充 / 添加以下哪项可以推出" ───────→ 代入法
├─ 无特殊问法，看题干条件
│   ├─ 条件不确定（有真有假、只猜对一半）──→ 代入法
│   └─ 条件确定
│       ├─ 选项信息充分完整 ─────────────→ 排除法
│       └─ 选项信息不充分 ───────────────→ 推理法
└─ 都不符合 → 推理法（从确定信息入手）
```

### 2.2 三种方法对照

| 方法 | 触发条件 | 操作 | 速度 |
|---|---|---|---|
| **排除法** | 条件确定 + 选项完整 | 读一句、排一句 | 最快 |
| **代入法** | 条件不确定 / 特殊问法 | 假设选项真，逐项验证 | 中等 |
| **推理法** | 以上都不符合 | 找确定信息，列表顺推 | 最慢但通用 |

> 口诀：**确定又完整，排除；不确定或特殊问，代入；都不行，推理。**

### 2.3 "选项信息完整"怎么判断

| 类型 | 例 | 能否排除 |
|---|---|---|
| 完整 | A. 甲是北京人，乙是重庆人，丙是上海人 | ✅ 每个选项都给出全部对应 |
| 不完整 | A. 甲是北京人　B. 丙是上海人 | ❌ 只说了一个人 |
| 不完整 | A. 法务部排第一　B. 销售部排第五 | ❌ 只说了一个位置 |

## 3 排除法

### 3.1 操作：读一句、排一句

**两个方向同时用**
- 快速确定"**谁是谁**" → 帮助选。
- 快速确定"**谁不是谁**" → 帮助排。

**教学例**：甲、乙、丙对应东京、巴黎、土耳其。

| 题干 | 推出 | 作用 |
|---|---|---|
| 丙比东京人年龄大 | 丙 ≠ 东京人 | 排除"丙—东京"的选项 |
| 甲和巴黎人不同岁 | 甲 ≠ 巴黎人 | 排除"甲—巴黎"的选项 |
| 巴黎人比乙年龄小 | 乙 ≠ 巴黎人 | 排除"乙—巴黎"的选项 |

> 年龄比较类题目，"比……大/小"永远只能推出"**不是同一个人**"，不能直接定人。

### 3.2 真题精析

#### 真题 01（2023 重庆选调·三个小朋友）→ C

- 条件：①男生左边的两人中至少一个女生；②女生右边的两人中恰好一个女生；③气球右边两人中至少一个鲜花；④鲜花左边两人中恰好一个鲜花。
- 条件确定、选项完整（每个选项都是三人的完整排列）→ **排除法**。
- 由②排除 B（女生右边没有女生）；由③排除 D（气球在最右，右边没有鲜花）；由④排除 A（鲜花左边全是气球，没有鲜花）。
- **C**：气球女、鲜花女、鲜花男 ✅

#### 真题 02（2024 重庆选调·演讲比赛）→ C

- 评委甲：秦、沙**只能进一个**（恰好一个，不能都进也不能都不进）。
- 评委乙：秦不进 → 楚不进（逆否：楚进 → 秦进）。
- 评委丙：只有秦或沙不进，楚才进（楚进 → 秦不进 或 沙不进）。
- 条件确定、选项完整 → 排除法：
  - A 三人都进 → 违反甲；
  - B 秦、沙都不进 → 违反甲；
  - D 秦不进但楚进 → 违反乙；
- **C**：秦进，沙、楚不进 ✅

> 提醒："只能进一个"＝恰好一个；"至少一个"＝1 或 2。

### 3.3 排除法的边界

- 只适用于"**条件全真 + 选项完整**"。
- 一旦题干出现"只猜对一半""有真有假""可能/不可能"，**立即换代入法**，不要硬排。

## 4 代入法

### 4.1 何时用

1. **题干条件不确定**：有真有假、每人只猜对一半、一人全对一人全错。
2. **特殊问法**：
   - "可能 / 不可能"
   - "符合 / 不符合"
   - "补充 / 添加以下哪项可以推出"
3. **问法带附加条件**：如"如果丁是 2022 年结对的，那么……"，先看附加条件再代入。

> 注意区分：
> - "**不能推出**"＝不知道、不确定（不是"一定错"），不能当"不可能"处理。
> - "**不可能**"＝一定错。

### 4.2 两个提速技巧（先判断题型再用）

| 题型特征 | 技巧 | 原理 |
|---|---|---|
| **每个人均一对一错** | **最小信息假设法**：找只出现 1 次的信息，假设它为真 | 出现次数最少的信息约束最少，假设后能连锁推出 |
| **一人全对、一人全错、一人一对一错** | **最大信息假设法**：找出现次数最多的信息，假设它为真 | 出现最多，被反复提及，最可能是答案 |

> 分不清题型、或出现"两人一对一错"等变体 → **老老实实代入**，代入法最通用。

### 4.3 真题精析

#### 真题 03（2024 深圳·诈骗案）→ A

- 甲只说了一半真话（不知哪半真），条件**不确定** → 代入。
- 甲："不是我，也不是丁"；乙："如果是我，那么丙没参与"；丙："乙和丁必有一人"；丁："只有甲参与，戊才参与"（戊→甲）；戊："至少三人参与"。
- 代入 A（甲、乙、戊）：甲一对一错；乙（乙在、丙不在）真；丙（乙在、丁不在）真；丁（戊在、甲在）真；戊（3 人）真 → 全符合 ✅
- 其余选项均有一项不符。

#### 真题 04（2023 事业单位·樊胡凌）→ D

- 三人各在一区，赵、钱、孙各猜两句，**都只猜对一半** → 代入。
- 代入 A：赵两句全错；B：赵两句全对；C：赵、钱一对一错，但孙两句全错。
- **D**（樊 E、胡 F、凌 G）：赵、钱、孙均一对一错 ✅
- 提速：最小信息假设——"樊在 E"只出现 1 次，假设为真，则"樊 F""樊 G"都错，得"凌 G、胡 F" → D。

#### 真题 05（2021 联考·五种水果）→ C

- 五人各说两种水果，每人只对一半 → 代入。
- 代入 A（①香蕉、②苹果）：小李两句全错；B（②猕猴桃、③梨子）：小李两句全错。
- **C**（③苹果、④梨子）：五人恰好一对一错，且①—⑤一一对应 ✅
- 提速：①只出现 1 次（最小信息），假设"①是香蕉"为真，逐步推出完整对应。

#### 真题 06（2023 浙江选调·看画）→ A

- 管理员说：一人全对、一人全错、一人一对一错 → 条件不确定。
- 代入 A（莫奈）：甲一对一错、乙全错、丙全对 ✅ 完全符合。
- 代入 D（三人之外）：乙、丙均一对一错，不符合"一全对、一全错、一对一错" ❌
- 提速：最大信息假设——"莫奈"出现 3 次，假设画是莫奈所作，直接选 A。

#### 真题 07（2019 青海·树）→ 柏树

- "只有一个人两个判断都对，一个人一对一错，一个人全错" → **最大信息假设**。
- "柏树"出现 3 次，为最大信息 → 这棵树是**柏树**。

#### 真题 08（2021 广东·花田）→ 月季

- 同一题型 → 最大信息假设。
- "月季"出现 3 次 → 花田里种的是**月季**。

#### 真题 09（2022 上海·五位数学家）→ D

- 每人只说对一半（**每个人均一对一错**）→ 最小信息假设。
- "5 号"只出现 1 次，假设"5 号是希尔伯特"为真，连锁推出：朱前半句错 → 3 号非闵可夫斯基；倪前半句错 → 2 号闵可夫斯基；张前半句错 → 3 号黎曼；韦前半句错 → 4 号外尔；方后半句错 → 1 号黎曼不成立，剩下 1 号＝**高斯** ✅

#### 真题 10（2024 国考·友好城市）→ A

- 问"哪两个城市**可能**结对" → 代入。
- 6 城、3 年，每年一对；已知丁＝2022，甲、乙不在 2021，丁、戊不在 2023。
- 代入 A（丙、戊）：2022 已被丁占 → 丙戊不在 2022；戊不在 2023 → 丙戊只能在 2021；乙不能在 2021、2022 → 乙在 2023；甲只能与乙 → 甲乙 2023，己 2022 ✅ 自洽。
- B、C、D 均出现"某对无处可放"的矛盾。
- 提醒：**附加条件一定要看仔细**，先填表再代入。

#### 真题 11（2024 事业单位·选派）→ C

- 问"**不符合**要求"＝不可能 → 代入。
- 条件：①张 → 赵或徐；②李、赵不能都去（＝至多一个）；③赵 → 徐不去（徐 → 赵不去）。
- 代入 C（张、李）：张去 → 需赵或徐同去，但赵、徐都没去 → 违反① ✅
- A、B、D 均满足全部条件。

#### 真题 12（2020 四川下·名次）→ A

- 问"根据下列哪项**能够推出**六号比一号名次低" → 结合选项代入。
- 由题干得：四号 ＞ 一号 ＞ 二号；二号 ＞ 三号；四号 ＞ 五号 ＞ 三号。
- A：六号 ＜ 二号 → 四 ＞ 一 ＞ 二 ＞ 六 ⇒ 一号 ＞ 六号 ✅
- 不必先完整梳理题干，直接代入最快。

### 4.4 代入法操作要点

1. **最多代 3 次**：问"不可能/不符合"，三个可能项会被排除。
2. 正确答案常靠后，但**复杂的通常只有一个**，遇到复杂项先跳过、回头再算。
3. 代入只看"**符合/不符合**"，不需要推完整张表。
4. 材料题先**列表**填确定信息，再代入。
5. 附加条件（"如果……"）先落表，别漏。

## 5 推理法

### 5.1 起点：确定信息

**确定信息**＝题干明确给出的"谁＝谁"或"谁≠谁"。
- 例："C 在 2 号货架""甲最左""小贺没时间"。
- 从确定信息出发，找**同时涉及该对象**的条件，顺藤摸瓜。

### 5.2 手段：列表 + 顺藤摸瓜

- 排序题**必须列表**（1—6 号、左—右），把确定信息填进去。
- 找"牵涉最多"的对象：它连接的条件最多，最容易连锁。
- 卡住时换一个确定信息，或从"间隔最大/限制最强"的条件入手。

### 5.3 特殊场景

**（1）排序与间隔**
- "间隔 2 人"＝位置差 3；"间隔 3 人"＝位置差 4；"间隔 1 人"＝位置差 2。
- 先放"间隔最大"的那组（占位最多，可能性最少）。

**（2）圆桌 / 方桌方位**
- **基准写在最下面**，所有人**面向桌子**坐，再定左右。
- "某人的左手边"＝该人左边相邻；"对面"＝隔一位。
- 常见关系：相对而坐、相邻而坐、左右手边。

**（3）一一对应**
- 已知"甲＝2 号"，则甲不在其他位置，2 号也不能是别人。
- 一人一岗、一岗一人，可直接排除大量可能。

### 5.4 真题精析

#### 真题 13（2026 浙江·专辑货架）→ A

- 6 张专辑（甲 A、B；乙 C、D；丙 E、F）放 1—6 号；A、C 不相邻；F、C 不相邻；**有且仅有一张甲的专辑在最边上**。已知 C＝2，E＝4。
- 问"可能为真" → 代入。
- 代入 A（B＝1）：A 不能 3 → A 在 5 或 6；F 不能 3 → F 在 5 或 6；B 已在最边 → A 不能在 6，故 A＝5、F＝6、D＝3 ✅
- B、C、D 均导致 A 与 F 抢 5/6 号而冲突。
- 推理法：C＝2 → A、F 都被"不相邻"排除 1、3 → A、F 必在 5、6 → 直接排 B、C、D。

#### 真题 14（2025 江苏·交换书）→ D

- 四专业各一人：丙＝历史、丁＝文学；交换后甲持社会学书、乙不持文学书；**每人所持不是本专业书**。
- 问"**不能推出**"→ 条件确定、选项不完整 → 推理。
- 甲持社会学书 → 甲不是社会学；专业不重复且文学是丁 → 甲＝经济学，乙＝社会学（A、C 可推出）。
- 文学书：乙不持、丁不持（本专业）、甲持社会学 → 只能**丙持文学书**（B 可推出）。
- 丁持历史或经济**不确定** → **D 不能推出** ✅
- 提醒："不能推出"是"不确定"，不是"一定错"。

#### 真题 15（2024 黑龙江公安·课程）→ C

- 5 门课（时政、信息、管理、法律、传媒），每组选 2 门且**至少一门是结业考试课程**；时政、信息无结业考试；甲没选信息；只有乙选传媒、只有丙选管理；四组课程不完全相同。
- 推理：结业课＝管理、法律、传媒。
- 甲没选信息、传媒、管理 → 甲＝时政＋法律。
- 乙必含传媒；丙必含管理。
- 丁不含传媒、管理 → 只能从时政、信息、法律中选 2，且须含法律（否则无结业课）→ 丁＝法律＋（时政或信息）；又不能与甲相同 → 丁＝**信息＋法律** ✅
- 方法：确定信息 → 列表 → 找牵涉最多的"甲"→ 顺藤摸瓜到"丁"。

#### 真题 16（2025 四川·方桌）→ A

- 四人围方桌，**相对而坐的是夫妻**；衣服颜色蓝、黄、粉、红各不相同。
- 条件：老陈在老杨左手边且不穿蓝；穿蓝者右手边是老胡；穿黄者坐老杨对面；穿黄者不是老胡。
- 方位：基准写最下（老杨），面向桌坐 → 老陈在左；黄在老杨对面（上）；黄不是老胡 → 老胡在右，上方是老高。
- 蓝者右手边是老胡 → 蓝者＝老杨（下），右手边为老胡。
- 于是老陈、老胡为红/粉，且二人相对 → **穿红与穿粉的是夫妻** ✅
- B、D 方位不符；C 谁穿红不确定。

## 6 考场流程与对照

### 6.1 30 秒定方法

1. 扫问法：有"可能/不可能/符合/不符合/补充" → **代入**。
2. 扫题干：出现"只猜对一半""有真有假""一人全对一人全错" → **代入**（配最小/最大信息技巧）。
3. 条件全真 + 选项完整 → **排除**。
4. 其余 → **推理**（找确定信息、列表）。

### 6.2 三方法速对照

| | 排除法 | 代入法 | 推理法 |
|---|---|---|---|
| 看什么 | 选项完整性 | 问法/条件确定性 | 确定信息 |
| 怎么动 | 读一句排一句 | 假设选项真，验证 | 列表顺推 |
| 风险 | 条件有假时失效 | 代 3 次费时 | 起点找错会卡住 |
| 提速 | 只找"不是谁" | 最小/最大信息假设 | 从牵涉最多者入手 |

## 7 陷阱清单

1. **条件有假还用排除法**：题干"只猜对一半"时排除必错，改用代入。
2. **把"不能推出"当"不可能"**：前者是"不确定"，后者是"一定错"（真题 14）。
3. **漏看附加条件**："如果丁是 2022 年结对的"这类条件必须先落表。
4. **间隔数错**："间隔 2 人"是位置差 3，不是差 2（自测 T2）。
5. **方位反了**：圆桌/方桌必须"基准写最下、面向桌坐"，左右别凭感觉。
6. **"只能进一个"当"至少一个"**：前者是恰好一个。
7. **"不能都去"当"只能去一个"**："不能都去"＝至多一个，可以都不去。
8. **一一对应漏用**：已知某人占某位，忘记排除该人其他位、该位其他人。
9. **最小/最大信息用反**：均一对一错用最小，一人全对一人全错用最大。
10. **代入顺序死板**：复杂项先跳过，往往只有一个是复杂项。
11. **列表不写**：排序题不列表，靠脑记必乱。
12. **选项信息不全仍用排除**：只能推理。

## 9 自测

**T1** 甲、乙、丙、丁四人分别来自英国、德国、美国。已知：①甲、乙至少 1 人来自英国；②乙、丙至少 1 人来自德国。如果甲、丙、丁至少有 2 人来自英美两国，则下列哪项**不可能**？
A. 甲来自德国　B. 乙来自德国　C. 丙来自英国　D. 丁来自英国

**T2** 甲、乙、丙、丁、戊、己、庚 7 人坐成一排：①乙在丙左边，间隔 2 人；②戊在丁右边，间隔 3 人；③庚在己左边，间隔 1 人；④甲在最左边；⑤戊不在最右边。己坐的位置是：
A. 左五　B. 左六　C. 左四　D. 左三

**T3** 粉蒸肉和蒸排骨至多做一样；如果不做粉蒸肉，就做梅菜扣肉或清炖肉；梅菜扣肉和清蒸鳜鱼至少做一样。结果做了蒸排骨，没做清炖肉。可以推出：
A. 做了梅菜扣肉　B. 没做梅菜扣肉　C. 做了清蒸鳜鱼　D. 没做清蒸鳜鱼

### 答案与要点

| 题 | 答案 | 要点 |
|---|---|---|
| T1 | **A** | 甲＝德 → 乙＝英 → 丙＝德，甲丙都德，甲丙丁最多 1 人来自英美，矛盾 |
| T2 | **A** | 甲＝1；丁戊占 5 格且戊≠7 → 丁＝2、戊＝6；乙丙差 3 → 乙＝4、丙＝7；庚己差 2 且剩 3、5 → 己＝5 |
| T3 | **A** | 做蒸排骨 → 不做粉蒸肉 → 梅菜或清炖；没做清炖 → 做梅菜；鳜鱼不确定 |

## 10 一页速记

1. **先定方法**：特殊问法/条件不确定 → 代入；条件确定+选项完整 → 排除；都不行 → 推理。
2. **排除法**：读一句、排一句；"比大小"只能推出"不是同一人"。
3. **代入法**：假设选项真，只看符合/不符合；最多代 3 次。
4. **最小信息假设**：每个人均一对一错。
5. **最大信息假设**：一人全对、一人全错、一人一对一错。
6. **推理起点**：确定信息（谁＝谁/谁≠谁），找牵涉最多的对象顺藤摸瓜。
7. **排序必列表**；间隔 2 人＝差 3，间隔 3 人＝差 4。
8. **圆桌方桌**：基准写最下，面向桌坐。
9. **一一对应**：占一位，则不在其他位，其他位也不容他人。
10. **问"不能推出"≠"不可能"**；附加条件先落表。
