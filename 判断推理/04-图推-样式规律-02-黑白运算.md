# 04-图推-样式规律-02-黑白运算

> **讲义对应**：精讲精练-判断 1（讲义 P29–34）
> **一句话**：轮廓与分割区域相同、**黑块数量对不上** → 同一位置做「颜色运算」，规则每题现找。

---

## 📌0. 三十秒判断流程

```
黑块（色块）题，先数数量
   ├─ 每幅数量相同 → 平移（位置规律）
   └─ 数量不同 → 黑白运算 ← 本节
        ↓
确认轮廓、分割区域是否相同（格子对齐才能运算）
        ↓
先用「大块面积」猜规则 → 再用「选项差异」逐格验证
        ↓
读出规则（黑+白=?、白+黑=?）→ 套到「？」处
```

> 一句话分界：**数量相同走位置，数量不同做运算。**

---

## 1. 图形特征

| 信号 | 说明 |
| --- | --- |
| **轮廓相同** | 外框形状一致（如都是正方形、都是「田」字格） |
| **分割区域相同** | 内部格子划分一致，位置能一一对应 |
| **黑块数量不成规律** | 比如 4、5、3 —— 数量对不上就排除了平移 |
| 常见于两组图 | 第一组给规则，第二组应用 |

---

## 2. 核心方法：同位置运算

把三幅图叠在一起，**同一格**的三个颜色做运算：

```
图1 的第 1 行第 1 格  +  图2 的第 1 行第 1 格  =  图3 的第 1 行第 1 格
```

读规则的方法：找几个「已知结果」的格子反推，例如

| 观察到的格子 | 可推出的规则 |
| --- | --- |
| 黑 + 黑 → 黑 | 黑+黑=黑 |
| 白 + 白 → 黑 | 白+白=黑 |
| 黑 + 白 → 白 | 黑+白=白 |
| 白 + 黑 → 白 | 白+黑=白 |

> 上面四行是**举例**，不是固定公式——每道题规则都不同，必须从题干现场读。

---

## 3. 两条铁律

1. **规则不背，现场找**：每道题的运算表都可能不一样，套用上一题必错；
2. **顺序有讲究**：`黑+白` 不一定等于 `白+黑`，遇到两个算不出的格子，先确认谁是「前图」谁是「后图」。

---

## 4. 两个提速技巧

### ① 对比选项找差异（基本功）

四个选项往往只差几格。先看**差异格**，再回题干找这一格的运算，一次排除一批。

### ② 大块面积一起看（辅助，随缘）

同一道题里，**相同的运算结果必须相同**。
如果「？」处有两格都是「白+黑」，它们的结果一定同色——可以直接排除结果不同的选项，甚至不用知道规则是什么。

> 能用就用，不能用就老老实实逐格对比。

---

## 5. 特殊形式（近年常考，务必认得）

| 形式 | 说明 |
| --- | --- |
| **不止黑白** | 可能是灰 + 白、白 + 阴影、灰 + 灰，甚至三种元素混合 |
| **小球参与运算** | 小球与小球、小球与白、小球与黑，都按同位置规则算 |
| **空格参与运算** | 如「黑 + 黑 = 空」，空缺也是一种「颜色」 |
| **黑块拼接** | 若干黑块拼成一整块，**轮廓与分割线被隐藏**，要能看出底层是格子，再按黑白运算 |

> 识别关键：只要**外轮廓与内部划分能对齐**，哪怕被黑色填满，也当黑白运算处理。

---

## 📌 6. 易错清单

- [ ] 数量不同还硬套平移
- [ ] 背规则、套上一题的运算表
- [ ] 忽略运算顺序（黑+白 ≠ 白+黑）
- [ ] 只盯黑白，没认出灰/阴影/空格
- [ ] 看不出「黑块拼接」其实有格子
- [ ] 挨个格算到底，不用「大块面积」省时间
- [ ] 找到规则却不回选项验证，导致看错格

---

## 📌 7. 三类图形规律分界（样式规律收口）

| 特征 | 走哪条路 | 关键动作 |
| --- | --- | --- |
| 元素组成**相同** | 位置规律（平移 / 旋转翻转） | 看中间判方向 / 找对称 |
| 元素组成**相似**（线条重复） | 样式规律·加减同异 | 挑 1–2 根线、求异优先 |
| 元素组成**相似**（色块、轮廓相同） | 样式规律·黑白运算 | 数数量、同位置运算 |
| 元素组成**不同** | 属性规律（对称、曲直、开闭） | 找「等腰」元素画对称轴 |
