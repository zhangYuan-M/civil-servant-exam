# 07-图推-数量规律-01-面

> 面 = **白色的封闭区域**。黑的不算，最外那圈也不算。
>
> 数量规律入口：元素组成不同 → **先看属性**（对称 / 曲直 / 开闭）；属性没规律，或数量特征一眼就明显 → 再数数量（面、线、笔画、点、素；角极少考，不在精讲范围）。

## 一眼识别：什么时候数面

- 图形被线条**分割**（一个框被切成好几块）
- **满眼窟窿**、封闭面明显
- 生活化、粗线条图形中间有空白（齿轮、飞机头）

## 怎么数：三条铁律

1. **只数白色封闭区域**，黑色不是面；
2. **不重复数**：有几个「窟窿」就是几个面，**最外层轮廓不算**；
3. 两块**连通**算 1 个面，中间被线条**封口**才分成 2 个。

整体面数量常考**等差**（3、4、5、6、7）或**恒定**；数出规律就直接选，别再细化。

## 整体数不出 → 三层细化

| 顺序 | 看什么 | 什么时候优先看它 |
| --- | --- | --- |
| ① | **相同面**的数量（双胞胎、多胞胎） | 图里有明显重复的小块 |
| ② | **三角形面**的数量 | 三角形扎堆出现 |
| ③ | **最大 / 最小面** | 有一块明显特别大或特别小 |

**细节**

- ② 只数三角形面；**四边形面几乎不考**，别为它纠结；
- ③ 看三样：**形状**（几边形）、**属性**（对称——轴 / 中心 / 轴+中心；曲直——直线面 / 曲线面；面本身封闭，不看开闭）、**与外框是否相似**；
- 规律明显就直奔那一层；看不出哪个明显，才按 ①→②→③ 试。
