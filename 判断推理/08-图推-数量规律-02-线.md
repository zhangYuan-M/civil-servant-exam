# 08-图推-数量规律-02-线

> 直线、曲线**分开数**；出现端点、日 / 田、五角星、圆切圆交 → 改数**笔画**。
>
> 现在纯数直线 / 曲线的题少了，**内外分开、曲直分开再做运算才是主流**。

## 什么是线

- **直线**：一个方向上连续延伸 = 1 条（「＋」= 2 条）
- **曲线**：平滑即 1 条（圆、弧各算 1 条）；**有明显拐点就断开算**（「m」= 2 条）
- 数的是**线**，不是线段

## 何时数线

| 图形特征 | 数什么 |
| --- | --- |
| 多边形、单一直线 | 直线 |
| 圆、弧、单一曲线 | 曲线 |
| 每幅图都有曲线 | 曲线数（出现率很高） |
| 每幅图都有曲有直 | 曲线数 → 直线数 → 两者运算 |

## 三种主流考法

1. **纯数**直线或曲线（现在较少）
2. **内外分开**：外框与内部分别数，常见「内部 = 外部」，也可能做加减运算
3. **曲直运算**：直线数 − 曲线数 = 常数（如都差 2）

> 有曲有直时的固定路线：**曲直性 → 曲线数 → 直线数 → 运算**。
> 讲义明确反对按奇偶分组。

## 笔画数（线的特殊考点）

**一笔画两个条件**

1. 线条之间**连通**
2. **奇点数为 0 或 2**

**奇点**：从该点出发有**奇数条**线。**端点也是奇点，别漏**。

| 情形 | 算法 |
| --- | --- |
| 连通图 | 笔画数 = 奇点数 ÷ 2 |
| 不连通 | 分开数笔画，**再相加** |

> 奇点数一定是偶数；数出奇数说明数错了。
> 记两个常用值：**4 个奇点 = 2 笔画，6 个奇点 = 3 笔画**。

**特征图**：五角星、日 / 田及其变形、圆相切 / 相交 / 套圈、多端点、非多边形被分割。

**去框法**：内部一笔画 + 外加一个框 → 仍是一笔画。
「日」字中间是**浪线**（不是横线），仍算「日」字变形，照样用去框法。

## 坑

- 忘记数端点
- 把平滑弧线拆成好几段
- 不连通图直接套「奇点 ÷ 2」
- 有笔画特征却先数交点（应先笔画，无规律再交点）
- 2–3 幅图有端点，还在数面

## 速记

> 直曲分开、内外分开、能运算；连通 + 0/2 奇点 = 一笔画；奇点 ÷ 2 = 笔画数。
