- 原因解释——题干**有矛盾**，问"为什么"。

# 一、原因解释

## 1 题型识别

| 要素 | 特征 |
|---|---|
| 提问 | 最能**解释** / **不能解释**上述现象的是 |
| 题干 | 存在**看似矛盾**的现象 |
| 本质 | 给矛盾找一个合理原因，**不判断论证对错** |

典型矛盾：
> "我每天只吃一顿饭，但是体重不降反升。"
> 按理少吃应变瘦，实际却变胖——这就是矛盾。

## 2 解题三步

1. **找转折词**：但、然而、反而、却、可是。
2. **找矛盾双方**：按理应怎样 ↔ 实际却怎样。
3. **选能同时解释双方的选项**，再对比择优。

以"每天一顿饭、体重反升"为例：

| 选项 | 能解释什么 | 判断 |
|---|---|---|
| A. 家庭条件不好，每天只买得起一顿饭 | 只解释"为什么吃一顿" | ❌ 缺一半 |
| B. 体重上升是因为脂肪变多了 | 只解释"为什么变胖" | ❌ 缺一半 |
| C. 节食不仅不能减肥，反而让人越来越胖 | 同时解释"吃一顿"和"还变胖" | ✅ |

> 铁律：**只解释矛盾的一半 = 没解释。**

## 3 核心考点：不降反增 / 不增反降

这是原因解释**最常考**的矛盾结构。

- "**不降反增**"：关键在"**反增**"，只解释"不降"的选项不能选。
- "**不增反降**"：关键在"**反降**"，只解释"不增"的选项不能选。

**经典案例（幼儿园接孩子）**
> 家长常晚接孩子 → 园方规定晚接要收费 → 按理家长会准时 → 结果晚接的家长**反而更多**。
> - "很多家长没时间准时接" → 只能解释"没下降" ❌
> - "收费不高，家长交钱后心安理得" → 解释"为什么更多" ✅（"更多"对应"反增"）

## 4 真题精析

### 真题 1（2024 重庆选调·股票交易量）→ D

- **矛盾**：某只股票价格大跌，下跌几周内交易量也急跌、远低于去年周均量；**然而**该股票全年交易量与去年相比并没有明显下降。
- 即：**某段时期大跌，全年却持平**。
- A 投资者喜欢低价买入：不知买入**数量**，且"人数/意愿"≠"交易量"。
- B 购买者数量与去年相同：同样说明不了交易量（一人可买多手）。
- C 交易量越大、年均价越低：题干未讨论价格与交易量的关系，跑题。
- **D**：2022 年某个时期交易量**高于**全年平均值 → 有低点也有高点，高低相抵，全年持平 ✅

> 考点：矛盾是"局部低、整体平"，答案要补出"另一段高"。

### 真题 2（2023 浙江选调·停车费）→ C

- **矛盾**：为提高市中心停车费以赶走长期占位车辆，政策实施一个月后，乱停车**未缓解，反而更严重**。
- 关键在"**反增**"。
- A 机动车与车位数量与去年持平：只能解释"没下降"。
- D 车位数量过少：同样只能解释"没下降"。
- B 修建了多处临时停车场：应有地方停，反而无法解释更乱。
- **C**：停车费涨幅较大，市民**宁愿乱停也不愿停在公共车位** → 原本停公共车位的人也不停了，乱停更多 ✅

> 考点：不降反增题，必须选能解释"增加"的选项。

### 真题 3（2025 深圳·防空系统）→ A（问"无助于解释"）

- **矛盾**：乙国宣称该系统拦截率 **90%**，且仍在服役；然而解密文件显示，十年前某次攻击中实际只拦截 **50%**。
- 问"**无助于**解释"，即选解释不了的一项。
- B 该次攻击火力异常集中，拦截弹药短时耗尽 → 能解释（有 90% 能力但没弹了）。
- C 绝大多数未被拦截的火箭弹落在**百公里外**荒野 → 能解释（系统拦截范围仅 5—70 公里，打歪了/超出范围）。
- D 90% 的拦截率来自**作战模型推论**而非真实战场数据 → 能解释（数据本身不实）。
- **A**：乙国因国力损耗**主动限制作战规模** → 限制的是"进攻"，与"防守拦截"无关 ✅（解释不了）

> 考点：①"无助于解释"要选**无关项**；②注意"拦截"是防守，不是进攻。

## 5 陷阱清单

1. **只解释一半**（最常见）：只说明"为什么没降"，没说明"为什么反增"。
2. **把"人数/意愿"当"数量"**：交易量、消费量类题目尤其要小心。
3. **答非所问**：解释的是另一个现象（如题干问乱停车，选项谈停车位够不够）。
4. **"无助于解释"看反**：问"不能解释"，要选无关/相反项，别选成能解释的。
5. **过度脑补**：需要额外假设才成立的选项，力度弱。
6. **数据类**：注意"总量、平均、比例"的区别，别把局部当整体。

## 6 速记

> **找转折 → 定双方 → 同时解释 → 择优**。
> 不降反增，解释"增"；不增反降，解释"降"。

# 二、日常结论

## 1 题型识别

| 要素 | 特征 |
|---|---|
| 提问 | 由此**可以推出** / **无法推出** / 最可能是研究人员的结论 |
| 题干 | **无明显逻辑关联词**（无"如果…那么""只有…才""所有…都"） |
| 本质 | 类似言语理解的**细节题**：只能推出题干说过的内容 |

**与翻译推理的区别**
- 有"如果/只有/所有/除非"等关联词 → 翻译推理，按箭头推。
- 没有关联词 → 日常结论，按"是否符合题干"判。

## 2 三原则

### （1）不选：逻辑错误、无中生有、偷换概念

| 类型 | 例 |
|---|---|
| **逻辑错误** | 题干"A 导致 B"，选项"B 导致 A"（因果倒置） |
| **无中生有** | 题干"某药对心脏病有好处"，选项"心脑血管疾病是困扰中老年人的重要疾病"——很对，但题干没说 |
| **偷换概念** | 见下 |

**偷换概念三组经典**
- "管理**问题**" → "管理**难题**"（解决不了的才叫难题）
- 海豚至少 32 **种** → 32 **类**（"种"与"类"范围不同）
- 百米**速度**最快 → **速率**最快（速度是单位时间位移，速率是迈腿频率）

> 天上不会掉馅饼：选项与题干**几乎一模一样**时，反而要警惕偷换。

### （2）慎选：比较关系、绝对化表达、程度词

- **比较关系**：题干没有比较，选项出现"更/最"就要谨慎。
- **绝对化表达**：最需警惕（"一定""必然""所有""唯一"）。
- **程度词**：题干程度与选项程度要对得上。

### （3）优选：从弱原则

- 优先选含"**可能**""**或许**""**有助于**"的表述。
- 经典题：从公安局走出一名穿警服的人 → "他**可能**是来办事的" ✅（而不是"他一定是警察"）。

## 3 五大坑王

> **更、最、越、首、极**

- "更、最、越、首"隐含**比较**，要看题干有没有比较。
- "极"是**程度**词，说话太满，通常不选。

## 4 操作顺序

| 题干长度 | 做法 |
|---|---|
| 短（1—2 行） | 先读题干，再读选项 |
| 长（3 行以上） | **直接选项代入**，逐项排除（读完题干容易忘） |

## 5 真题精析

### 真题 1（2023 北京·荔枝 DNA）→ A

- 题干：某段 DNA 序列在特早熟品种中缺失、晚熟品种中不缺失；"妃子笑"是杂合缺失，其花期正好介于两者之间。
- 问"哪项**最可能**是研究人员的结论"。
- A 特定 DNA 序列的缺失情况，**可能**是导致荔枝不同花期形成和成熟早晚的重要因素 → "可能"符合从弱原则 ✅
- B "解码基因组"题干未提（只做了研究）；C "市场占有度"未提；D "口味""关键因子"未提且程度过深。

### 真题 2（2025 湖北选调·服务贸易）→ C

- 题干：2024 年 1—7 月服务贸易进出口总额同比增长 14.7%；知识密集型服务出口增长较快；数字化、科技化、便利化、高附加值化趋势明显。
- A "高水平对外开放"未提；B "国际竞争力全面提升"未提；D "崭露头角"与"总量大"矛盾。
- **C**："量增质优"——"量增"对应总额增长，"质优"对应高附加值化趋势 ✅

## 6 陷阱清单

1. **无中生有**：选项说得很对，但题干没有（最常见）。
2. **偷换概念**：问题/难题、种/类、速度/速率。
3. **绝对化**：一定、必然、所有、唯一。
4. **强加比较**：题干未比较，选项出现"更/最"。
5. **因果倒置**：把" A 导致 B"读成"B 导致 A"。
6. **过度推理**：由"部分"推"全部"，由"可能"推"必然"。

## 7 速记

> **不选**：错、无、偷；**慎选**：比、绝、程；**优选**：弱。
> 长题干，选项代入；短题干，先读文段。

# 三、考频与总速记

## 1 考频

| 考试 | 原因解释 | 日常结论 |
|---|---|---|
| 国考副省级及以上 | 0—1 道 | 0—1 道 |
| 国考地市级、行政执法类 | 基本 0 道 | 基本 0 道 |
| 省考联考 | 约 1 道 | 约 1 道 |

> 结论：**性价比不高，但不能空白**。听一遍方法 + 刷 10 道题即可，不必深挖。

## 2 两题型对照

| | 原因解释 | 日常结论 |
|---|---|---|
| 问法 | 最能/不能解释 | 可以/无法推出 |
| 题干 | 有矛盾现象 | 无逻辑关联词 |
| 核心 | 同时解释矛盾双方 | 符合题干、从弱 |
| 最常见坑 | 只解释一半 | 无中生有、偷换概念 |
| 一句话 | 找"反"的那一半 | 别选"很对但没说"的 |

## 3 一页速记

1. 原因解释：**转折词 → 矛盾双方 → 同时解释**。
2. **不降反增解释"增"，不增反降解释"降"**。
3. 原因解释不判论证对错，**能解释即可**。
4. 日常结论：**不选**逻辑错误/无中生有/偷换概念。
5. **慎选**比较、绝对、程度；**优选**"可能"。
6. 五大坑王：**更、最、越、首、极**。
7. 长题干**选项代入**，短题干先读文段。
8. 与论证题相反：日常结论**越委婉越好**，论证题**越绝对越好**。
