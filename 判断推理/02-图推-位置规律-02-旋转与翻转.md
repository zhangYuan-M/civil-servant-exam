# 02-图推-位置规律-02-旋转与翻转

> **讲义对应**：精讲精练-判断 1（讲义 P17–22）
> **一句话**：元素组成相同、又没有格子可平移 → 先找**对称**，找不到对称再算**旋转**。

---

## 📌 0. 三十秒判断流程

```
元素组成基本相同？
   ├─ 有格子（9/16/25 宫格）→ 先想平移
   └─ 无格子 / 两组图 / 九宫格 → 旋转、翻转
        ↓
找与「？」对称的那幅图
   ├─ 竖轴对称 → 左右翻转
   ├─ 横轴对称 → 上下翻转
   └─ 找不到对称 → 按「方向 + 角度」算旋转
        ↓
代入选项，剩两项时对比差异
```

> 顺序很重要：**有对称就直接看对称，不要先算旋转**——这是本考点最快的路。

---

## 1. 图形特征

| 特征 | 说明 |
| --- | --- |
| 元素组成基本相同 | 仍然是**位置规律**的家族，与平移同源 |
| 没有格子 / 没法平移 | 两组图、九宫格出现最多 |
| 图形「整体在转」或「像照镜子」 | 转 = 旋转，照镜子 = 翻转 |

---

## 2. 旋转：方向 + 角度

| 要素 | 内容 |
| --- | --- |
| **方向** | 顺时针 / 逆时针 |
| **角度** | 30°、45°、60°、90°、180°；**45° 和 90° 最常考** |
| 常见考法 | 每幅图固定转同一角度；或「转 + 移」组合 |

**判定角度的小动作**：找图形里的一条「有方向的边」（如从斜边到直角画一个箭头），看箭头每次转了多少度，比整体硬看快得多。

### 两个加速器

1. **周期性**：图 1 和图 5 位置、方向一致 → 周期为 4 → 「？」应与图 2 一致，不必逐格推。
2. **分组看**：多个元素分开看，先挑最容易判断的那个（离外圈最近的、最特殊的）。

---

## 3. 翻转：两种，只看对称轴

| 类型 | 判定 | 直观理解 |
| --- | --- | --- |
| **左右翻转** | 关于**竖轴**对称 | 照镜子（左右互换） |
| **上下翻转** | 关于**横轴**对称 | 水面倒影（上下互换） |

**本质区别（很关键）**：

- **旋转**不改变图形的「手性」——能不能转过去，看外轮廓就能判断；
- **翻转**一定改变手性（左右手互换）——**转不出来的，才是翻转**。

所以当两个选项只差「镜像」时，用这条排除最稳。

---

## 4. 核心技巧：看对称

**两组图 / 九宫格考旋转翻转 → 直接找「谁与问号处对称」。**

| 情形 | 做法 |
| --- | --- |
| 「？」在第三幅 | 比较图 1 与图 3、或图 2 与图 3，谁对称就用谁 |
| 先左右还是先上下 | **先看左右对称，没有再看上下对称** |
| 九宫格 | 哪行简单先看哪行；第一行难，就先看第二行找规律，再回第一行验证 |
| 剩两个选项 | **对比差异**（如分叉的疏密、黑球位置），回题干找对应特征 |

> 口诀化：**「谁与『？』对称，就看谁；先左右，后上下。」**

---

## 📌 5. 易错清单

- [ ] 一上来就算旋转角度 —— 应该**先找对称**
- [ ] 分不清左右翻转和上下翻转 —— 记「竖轴=左右，横轴=上下」
- [ ] 把镜像当成旋转 —— 手性变了就是翻转
- [ ] 九宫格死磕第一行 —— 哪行简单看哪行
- [ ] 只找一个元素 —— 多个元素要**分开看**
- [ ] 剩两个选项靠感觉 —— 必须**对比差异**再回题干验证
- [ ] 忘了周期性 —— 图 1 与图 5 相同，答案常与图 2 一致

## 📌 6. 位置规律总表（把平移也串起来）

| 考点 | 识别信号 | 核心打法 |
| --- | --- | --- |
| **平移** | 有格子、元素基本相同 | 看中间判方向；绕圈 / 走直线；循环优先；找半圈一圈；多胞胎标号；换方向 |
| **旋转** | 无格子、整体在转 | 方向 + 角度（45°、90° 为主）；画箭头判角；周期性 |
| **翻转** | 无格子、像照镜子 | 竖轴=左右翻转，横轴=上下翻转；找与「？」对称者 |

**通用思维**：① 多个元素分开看；② 用一个规律排除两个选项，剩两个时对比差异。

---

## 📌 7. 口诀

> 组成相同想位置，有格先平移；
> 无格两组看对称，竖轴左右横轴上下；
> 先左右，后上下，谁与问号对称就看谁；
> 找不到对称再旋转，方向角度画箭头；
> 图一图五若相同，答案常在图二处；
> 剩两选项别犹豫，对比差异回题干。
