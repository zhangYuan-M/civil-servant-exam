# 判断推理 · 逻辑论证「削弱类」

> 整理自：2026.06.18 精讲精练-判断10、2026.06.19 精讲精炼-判断11（徐来）
> 说明：本讲义只覆盖**削弱**部分（加强/搭桥见后续专题）。所有真题均保留题源与答案，解析只留"为什么"。

---

## 0 专题地图

```
削弱 = 证明题干结论不成立 / 论证不严谨
│
├─ 一、否定论点 ← 最常考、力度最强（约八成题目的答案）
│   ├─ 只有论点 → 只能否论点
│   ├─ 论点、论据话题一致 → 优先否论点
│   └─ 特殊论点：方式+目的、含比较、含限定词
│
├─ 二、因果类（论点含"A 导致 B"）
│   ├─ 另有他因 ……… 考得最多，或然性
│   ├─ 因果倒置 ……… 必然性
│   ├─ 同果异因（C 导致 A 和 B）… 必然性
│   └─ 直接否（A 不导致 B、只有 C 导致 B）… 少考
│
├─ 三、拆桥（否定论证）← 话题不一致时用
│   ├─ 普通拆桥：论据推不出论点
│   └─ 特殊拆桥：整体与部分 / 物质与元素 / 动物与人 / 比例与基数 / 样本代表性
│
└─ 四、否定论据 ← 最弱、最少（多在"双方互怼"中出现）
```

**主线一句话**：先找论点 → 看论点论据是否"说一回事" → 一致就否论点，不一致就拆桥，都没有才否论据；论点带因果，优先想他因。

**顺序口诀**：否论点 → 拆桥 → 否论据。

## 1 论证基础

### 1.1 三要素

| 要素 | 含义 | 是否必有 |
|---|---|---|
| 论点 | 结论、观点 | **一定有** |
| 论据 | 支撑论点的依据 | 可能有 |
| 论证 | 论据证明论点的过程 | 隐含 |

例：**论点**"大家今年会上岸" ← **论据**"大家今天在学习"，中间默认"今天学习就会今年上岸"＝**论证**。

> 论点是核心，所以**永远先找论点**；找到论点，论据（一般在前后）就好找了。

### 1.2 找论点

**（1）提示词（覆盖 90% 以上题目）**

| 类别 | 词 |
|---|---|
| 结论引导 | 所以、因此、可见、结论是 |
| 解释引导 | 这表明 / 说明 / 意味着、由此推出 / 可知 |
| 观点引导 | 据此认为、研究人员（专家、学者）认为、XX 称、有人认为 |

**（2）首尾句原则**（考得少）
总分、分总、总分总结构，论点常在首句或尾句。前面列数据、举例子，最后一句总结——总结句即论点。

**（3）问啥找啥**（最重要）
问"最能削弱**反对者**的观点"，就直接锁定"这些反对者的理由是"**之前**那句；问"专家的建议"，就找"专家指出/提议"。

**（4）专业名词读不懂**
回到前文找它的**定义**。论点里带生僻概念的题（如"先验命题""首要问题"），命题人往往已在题干中给出定义，**用题干定义，不要脑补**。

**（5）转折之后是重点**
"但、然而、不过"之后常是论点；转折之前的内容要么与论点无关，要么与论点不一致，一般不是论据。

### 1.3 找论据

| 提示词 | 常见形式 |
|---|---|
| 由于、因为、鉴于、根据 | 原因、数据、事例、实验或调查内容 |
| 研究发现 / 结果显示 / 调查显示 | 实验过程、统计结果 |

### 1.4 论点以外的不都是论据

以下四类可**略读或不读**：

1. **下定义**——背景资料，只用来查专业名词。
2. **提问题**——只为引出结论。
3. **说现象**——多为铺垫。
4. **"但"之前**——转折前非重点。

> 分不清背景和论据也没关系，不影响做题。读不懂的内容不要纠结。

### 1.5 关键判断：话题是否一致

**操作**：圈出论点的关键词 → 回论据里找。

- 论据里有 → **话题一致** → 优先**否论点**
- 论据里没有 → **话题不一致** → 优先**拆桥**

例：论据"新能源车销量上升、媒体报道变多"，论点"销量上升得益于媒体报道"——两个关键词都在 → 一致。
反例：论据讲"肠道"，论点讲"心脏"——不一致。

> 实战补充：**80% 的削弱题可以不细读论据**，直接找论点、反着说；没有否论点项再考虑拆桥。

## 2 削弱总论

### 2.1 提问方式

| 类型 | 表述 |
|---|---|
| 正面 | 最能**质疑 / 反驳 / 削弱 / 反对 / 驳斥**上述论断（结论、观点）的是 |
| 目的式 | 最能**说明**上述观点**不成立**／上述建议**难以实现预期目标**的是 |
| 反面 | **不能**质疑上述论断的是（见第 7 节） |

> 不用背问法，本质都是"证明题干错"。

### 2.2 通用四步法

1. **读提问**：确定削弱 / 加强 / "不能削弱"。
2. **读题干**：找论点、论据，判断话题是否一致。
3. **做预设**：先想好答案长什么样。
4. **读选项**：带预设匹配；纠结时**对比差异**择优。

> 论证题不要靠语感。选项最爱在**主体、话题、限定词**三处挖坑。

### 2.3 四条路径与力度

| 路径 | 力度 | 考频 | 适用信号 |
|---|---|---|---|
| 否定论点 | **最强** | 最高 | 只有论点／话题一致 |
| 因果类 | 必然性 > 或然性 | 高 | 论点含"导致、是……的原因" |
| 拆桥 | 中 | 中 | 话题不一致、无否论点项 |
| 否定论据 | **最弱** | 最低 | 双方互怼、无否论点也无拆桥 |

### 2.4 预设模板（做题时脑子里先冒出这几句）

| 题干特征 | 预设答案长相 |
|---|---|
| 只有论点 | "论点不成立"（反着说） |
| 论点、论据话题一致 | "论点不成立"（反着说） |
| 论点、论据话题不一致 | "论据推不出论点"（点破漏洞） |
| 论点含因果（A 导致 B） | "还有 C 导致 B"／"B 导致 A" |
| 双方互怼 | "你那个论据是假的" |
| 论点是"方式+目的" | "做法不可行"／"达不到目的" |

## 3 否定论点（最常考、力度最强）

### 3.1 识别与适用

- **选项特征**：与论点表述的意思**相反**（让论点不成立）。
- **适用条件**：
  1. 文段**只有论点、无论据**；
  2. 论点与论据**话题一致**——否了论点等于同时否了论据，且论点更短、更好否。

> 为什么话题一致时不去否论据？论据往往又长又绕，否论点更省事、更直接。

### 3.2 两种否定方式

论点：粉笔的老师都爱发红包。

| 方式 | 表述 | 力度 |
|---|---|---|
| 整体否定 | 粉笔老师**都不**爱发红包 | 强 |
| 部分否定（举例） | 粉笔**徐来不**爱发红包 | 弱 |

- **整体 > 部分**，优先整体否定。
- 论点若限定为"**有的**粉笔老师爱发红包"，就不能用个例否定（很少考）。
- 反向表述要"对着来"：
  - "每天喝三杯水对人体好" → "每天喝三杯水对人体不好"
  - "长时间玩手机对眼睛不好" → "长时间玩手机对眼睛没有坏处 / 有好处"

### 3.3 三类典型干扰项

论点：粉笔的老师都爱发红包。

| 干扰项 | 选项 | 问题 |
|---|---|---|
| 话题不一致 | 粉笔老师喜欢**抢**红包 | 发→抢，偷换话题 |
| 主体不一致 | **阳光小学**的老师不爱发红包 | 偷换主体 |
| 不明确（诉诸无知） | 没人知道粉笔老师是否爱发红包 | 用"不知道"反驳，无效 |

**诉诸无知**是典型逻辑错误：用"我不知道"反驳别人的观点。
- 甲："今天天气很好"；乙："我哪知道今天天气好不好"——无效。

> 不必细分三类，认出"跟论点不是一回事"就是无关项。

### 3.4 选项主体 vs 论点主体

| 关系 | 能否选 | 例 | 说明 |
|---|---|---|---|
| **全同** | ✅ 最好 | 论点"人体"；选项"人体" | 完全对应 |
| **包含** | ✅ 可选（全同 > 包含） | 论点"欧洲人"；选项"人类" | 选项范围大＝解释整体 |
| **包含（反向）** | ✅ 可选 | 论点"喝红茶"；选项"每天喝两杯以上红茶的人" | 选项范围小＝举例 |
| **并列** | ❌ | 论点"人体"；选项"海洋高等哺乳动物" | 偷换主体 |
| **交叉** | ❌ | 论点"鸟类"；选项"体型较小的物种" | 是否包含未知 |

**真题例证**：

- **并列不可选**：论点"微塑料危害**人体**"，选项讲"**海洋高等哺乳动物**"（2025 深圳）→ 排除。
- **选项范围更大可选**：论点"农业兴起是**欧洲人**身高改变的重要因素"，选项讲"**人类**肉食比例"（2024 国考）→ 可支持。
- **选项范围更小可选**：论点"喝**红茶**与较低死亡风险有关"，选项"**每天喝两杯以上红茶的人**死亡风险降低 9%~13%"（2023 联考）→ 举例，可支持。
- **交叉不可选**：论点讨论"**鸟类**"，选项讲"**体型较小的物种**"（2025 联考）→ 不知是否含鸟类，排除。

> 易混点：只有论点明确限定主体为"人"时，"某动物"才是并列；若论点默认"所有生物"（如"多喝水可以降血压"），"某动物"就是举例，可以削弱。

### 3.5 警惕论点中的限定词

**三类限定词**：比较（更、最、越、首）、程度、时间。

- **比较类**：论点有比较 → 答案有比较；论点无比较 → 答案无比较。
- **边界类**：论点带什么限定，答案就得带什么限定；**放大、缩小、换档，一律算跑题**。

**核心原则**：

**（1）比较对象必须对得上**

- 题干比"电车成本 vs 油车成本"，选项比"换电池 vs 换新车"——都带"比较"，但不是一回事 → 无关项。
- 题干比 A、B，选项只说 B 如何 → 无法比较，排除。

**（2）"更、最、越、首"隐含比较**

- 2022 联考：论点"对抗全球变暖**最根本**的方法是种树"；削弱"对化石能源的依赖才是**根本原因**"✅
- 2023 辽宁：论点"**经常**喝咖啡有利于学习和记忆"；选项须落在"经常喝咖啡"上。
- 2019 联考：论点"**适当**锻炼有助于逆转心肌老化"；选项须提"适当锻炼"。

**（3）用题干定义，不脑补**
- 2026 上海：题干已定义"首要问题＝影响范围最广、紧迫性最强"。削弱应说"经济问题威胁更广、更紧迫"，而不是"更受重视"——"重视"题干没定义。

**（4）程度要对等**
- 2023 广东：论点"全球变暖远没到需要拯救地球的地步"；选后果最严重者（"20 年后 1/3 生态系统崩溃"），"速度增加""多次导致环境变化"程度不够。

### 3.6 择优四原则

1. **整体 > 部分**
2. **越接近论点越好**（关键词重合、同义替换）
3. **表述越绝对，力度越强**
4. **限定词要对应**（比较、时间、程度）

> 纠结时：对比两个选项的**差异词**，谁的差异词更贴近论点关键词，就选谁。
> 例：论点"读书可以治病，尤其治心病"——"缓解焦虑情绪"比"改变错误认知"更贴近"心病"。

### 3.7 特殊论点形式①：方式 + 目的

**特征**：论点是"应该做某事，以便达到某目的"（建议、提议、对策）。

**削弱方向**：
1. **做法不可行**（做不到）
2. **目的达不到**（做了也没用）

**关于"钱"的铁律**：

> **花钱可以否认"普及"，但不能否认"有效"。**

- 涉及**老百姓花费/普及**：钱可以削弱（"治疗费用三百万，老百姓承担不起"）。
- 涉及**国家公共建设**：钱不能削弱（国家本就有公共建设职能）。
- "成本高"≠"不可行"，也≠"无效"。

### 3.8 否定论点真题精析

#### 例 1（2025 深圳·微塑料）→ D

- 论点（"因此"后）：微塑料**不会**对人体产生危害。
- 论据：权威组织称"目前还没有足够数据全面了解微塑料对人类健康的影响"。
- 话题一致 → 否论点，预设"微塑料会对人体产生危害"。
- A 限塑禁塑、B 暴露浓度高、C 海洋哺乳动物（主体并列）→ 均未落在"人体有害"。
- **D**：微塑料成为**有害物质进入人体**的重要载体 ✅

#### 例 2（2025 四川·双减）→ B

- 只有论点："自己的孩子会因减负落后于其他同学"。
- A 个体差异、C 作业负担有害、D 学校提升教学质量——都没回答"会不会落后"。
- **B**：政策对孩子和其他同学影响**一样** → 不会落后 ✅（与论点最贴近）

#### 例 3（2024 湖北选调·霓虹脂鲤）→ B

- 论点：霓虹脂鲤通过狭窄开口前会**等待或排队，以维系社交距离**。
- 论据：实验观察（速度快慢、无物理接触）。
- A 游动速度、C 个体与群体行为、D 避险行为——均未落在"等待或排队的目的"。
- **B**：等待或排队**只是生物本能** ✅
- 记忆点："社交（后天）"与"生物本能（先天）"是一对矛盾词，用其一否另一个。

#### 例 4（2025 事业单位·燃气聚能环）→ D

- 只有论点："聚拢火焰，提高燃气燃烧效率"。
- A 产生一氧化碳（副作用）、B 需系统优化（未提聚能环）、C 达不到"燃气灶热利用效率"。
- **D**：氧气太少→**无法充分燃烧** ✅
- 对比：论点说"燃气效率"，C 说"燃气灶热利用效率"——偷换概念；D 更直接。

#### 例 5（2025 上海·先验命题）→ D

- 论点（"所以"后）："先验命题"其实**并不存在**。
- 论据："人类知识命题中的一切概念最终都起源自实际经验"。
- 定义：先验命题＝真假不需经验检验即可断定。
- A 只是"康德个人观点"（对错未知）、B 所有命题都不是先验（加强）。
- C 经验有限而命题无限（有的靠经验、有的不靠）、**D 概念可不借助经验而定义**（说明先验命题存在）✅
- D 更绝对、更贴近"不需要经验"，胜出。

#### 例 6（2026 上海·环境问题）→ B

- 论点："环境问题是当今世界**最需共同面对的首要问题**"。
- 题干定义：首要问题＝影响范围最广、紧迫性最强。
- A 技术差异、D 重视程度——与"首要"无关。
- **B**：经济问题对人类生存的威胁**比环境问题更广泛、更紧迫** ✅
- C"更受重视"是干扰：题干定义里没有"重视"。

#### 例 7（2023 广东·全球变暖）→ C

- 论点："近期的全球变暖**远没有到**需要'拯救地球'的地步"。
- 预设：全球变暖很严重、需要拯救。
- A 变暖与海平面上升加速、D 历史上多次导致环境巨变——程度不够。
- **C**：按目前趋势，20 年后超 1/3 生态系统**濒临崩溃** ✅（最严重，"目前"对应"近期"）

#### 例 8（2023 联考·脂肪含量）→ C

- 论点："脂肪含量过少的人，死亡风险会增高"（A 导致 B）。
- 直接否论点无答案 → 用**同果异因**：
- **C**：脂肪含量过少和死亡风险高**都是疾病带来的**，疾病是共同原因 ✅（把因果变并列）

## 4 因果类（论点含因果关系）

### 4.1 识别

**只看论点**是否含因果：

| 提示词 | 例 |
|---|---|
| ……**是**……**的原因** | "缺觉"是导致第二天没精神的原因 |
| ……**导致 / 使得 / 有助于**…… | 就寝关门窗会降低睡眠质量 |
| ……**增加 / 降低 / 加强 / 减轻**…… | 改善工作环境可以提高生产率 |
| 这是**由于**…… | —— |

> 注意：加强题里因果论点和普通论点没有区别；**因果类的特殊打法只在削弱时用**。

### 4.2 四种打法

论点：A 导致 B。

| 打法 | 表述 | 性质 | 考频 |
|---|---|---|---|
| ① 直接否论点 | A 不导致 B；只有 C 导致 B | 必然 | 低（太简单） |
| ② 同果异因 | C 导致 A 和 B（A、B 变并列） | 必然 | 低 |
| ③ **因果倒置** | B 导致 A | 必然 | 较高 |
| ④ **另有他因** | 除 A 外，还有 C 导致 B | **或然** | **最高** |

> 力度：①②③ 均为必然性削弱，力度相同；④ 是干扰、或然性，弱于前三者，但最常考。
> 实战顺序：**先扫他因，再看因果倒置**，其余基本不考。

### 4.3 因果倒置：三步判定

因果关系有一个不可违反的规则：**因必须先于果**。

```
题干说 A 导致 B  ⟹  时间上：A 先发生 ──→ B 后发生
```

所以只要选项说“**B 先发生，A 后发生**”，就证明 A 不可能是 B 的原因，原来的因果关系一定不成立。这就是因果倒置属于**必然性削弱**、力度最强的原因：它直接违反因果关系的定义。

```
题干：A ──→ B     （A 在前）
选项：B ──→ A     （B 在前）  ⇒ 因果倒置 ✅
```

1. 选项**同时出现**因、果两个关键词；
2. 看**时间先后顺序**（不是翻译的箭头方向）；
3. 顺序**颠倒** → 因果倒置。

- "落后导致挨打"（先落后后挨打） → "**挨打使得落后**"（先挨打）✅
- "喝可乐让我胖了" → "**胖了才喝可乐**" ✅（"才"是高频标志，先胖后喝）
- "个高的才去打篮球"：时间上先有个高 → 是因果倒置的典型句式。
- 选项与题干时间**一致** → **加强项**，排除。

**真题演示**

| 题干论点 | 因果倒置项 |
|---|---|
| 改善工作环境 → 提高生产率 | 舒适环境是对**生产率高的员工**的酬劳 |
| 精神鼓励 → 提高生产率 | 表扬是**生产效率高的员工**获得的回报 |
| 长期过敏 → 产生不良情绪 | **原本焦虑倾向**的儿童，免疫系统更易过敏 |

### 4.4 另有他因：认准"三同"

**本质**：干扰因素 / 实验中的控制变量——承认结果，但指出还有另一个原因。

| 条件 | 说明 | 常见表述 |
|---|---|---|
| 同一主体 | 与题干同一批人/同一车型 | "参与研究的**那些人**""**这些**喝可乐的人" |
| 同一时间 | 与题干同期 | 复现题干年份、"近年来""同一时期" |
| 不同原因 | 引入 A 之外的新原因 C | "还……""同时……" |

**正例 / 反例**：

- 论点"每天做 40 道判断题让人快乐"；选项"**这些人还做了**言语题" → 他因 ✅
- 选项"每天做 20 道**资料分析也会**让人快乐" → 无关（不同事、未同时发生）❌
- 题干"全球变冷导致战争"；选项"**全球变暖**导致战争" → 无关（二者不可能同时成立）❌
  - 正确他因："在全球变冷的那几年，正好赶上石油危机，国家为抢资源而开战" ✅

**他因选项的常见长相（真题）**

| 题干论点 | 他因项 |
|---|---|
| 早期人类活动造成反刍动物种群衰减 | **同一时期**大型猫科动物繁盛，大规模捕杀反刍动物 |
| 人类猎取导致土家狗灭绝 | 人类定居的**同时**，也带来了新的可能是其天敌的物种 |
| 气候变化加剧中亚荒漠化 | **1960—2020 年**不合理采矿、过牧、过垦同样加剧荒漠化 |
| 工具使用减弱咀嚼导致人类脸型变化 | **200 万年前**人类食物类型变化，加速了脸型变化 |

> 规律：**选项复现题干的时间节点**，基本就是命题人递来的他因。

### 4.5 隐含因果关系（"买东西"题型）

**特征**：两者比较 → 各有优点 → 其中一个卖得好 → 结论"消费者更愿意买具备某优点的那个"。
**隐含**：正是这个优点导致卖得好。
**打法**：**他因**——是**别的优点/别的原因**导致卖得好。

- 2022 国考：R 型清洗方便、W 型噪音小，R 型销量更好 → 结论"更喜欢易清洗的"。
- 2023 联考：HEV 操作便捷、PHEV 续航强，HEV 销量高 → 结论"更愿买操作便捷的"。
- 削弱："HEV **制造成本更低、售价更便宜**" ✅
- 排除项："两者都噪声小、都舒适" → 排除他因，属**加强** ❌

### 4.6 因果类真题精析

#### 例 9（2026 天津·过敏）→ B

- 论点："长期过敏的儿童，**更可能产生**不良情绪，引发交际和心理问题"（"产生"提示因果）。
- A 只说分散注意力，未落到心理问题。
- **B**：**原本**有焦虑倾向或情绪调节差的儿童，免疫系统更易过敏 → 先有情绪问题，后有过敏 ✅ 因果倒置（必然性，力度最强）
- C：先过敏、后恐惧 → 与题干时间一致，**加强**
- D：讨论"治病"，题干讨论"得病" → 无关

#### 例 10（2022 天津·免疫性别差异）→ D

- 论点：免疫功能的性别差异**可能是导致**临床表现差异的原因。
- A 住院概率、B 证据增多、C 类似病毒 → 均未落在"免疫功能"。
- **D**：参与研究的**大多数男性**有酗酒、抽烟等**长期**不良习惯 → 同一主体、同一时间、不同原因 ✅ 他因

#### 例 11（2023 联考·混动汽车）→ C

- 论点："消费者更愿意购买**操作更便捷**的混合动力电动汽车"（隐含：便捷→卖得好）。
- A 讨论 PHEV（车型不一致）、B 是否属新能源、D 两者都舒适（排除他因＝加强）。
- **C**：HEV **制造成本更低、售价更便宜** → 他因（价格导致卖得好）✅

## 5 否定论据（力度最弱）

### 5.1 做法

把**论据**反着说。

> 论点"小明一定很帅"，论据"小明长得像吴彦祖"
> A. 小明不帅 → 否**论点**
> B. 小明长得**不**像吴彦祖 → 否**论据**

### 5.2 适用信号

1. **双方互怼**：题干出现两个相反观点（买/不买、行/不行、省钱/不为省钱）。此时否论点往往只剩一个词，题目太简单，命题人改考否论据。
2. **兜底**：有论据，但找不到否论点、也找不到拆桥时，退而否论据。

### 5.3 三者的辨析

| 选项涉及 | 判定 |
|---|---|
| 只涉及**论点**关键词（反向） | 否论点 |
| 只涉及**论据**关键词（反向） | 否论据 |
| **同时**涉及论点、论据关键词并断开联系 | 拆桥 |

- 例：论据"今天天气好" → 论点"出去玩"
  - "天气不好" → 否论据
  - "不出去玩" → 否论点
- 否论据可以只否**其中一部分**（题干论据长、选项短是常态）。

### 5.4 真题精析

#### 例 12（2025 江苏选调·高铁运快递）→ D

- 论点："利用高铁运输快递**能够有效提升**地面通行效率"。
- 论据："快递运输车辆在早晚高峰频繁上路，是造成拥堵的重要原因之一"。
- 想否论点（"不能提升效率"）——没有对应选项：
  - A 建设成本高 → 钱不等于无效
  - B 岗位调整、C 站内拥挤 → 未提"通行效率"
- **D**：快递车**已避开早晚高峰**，主要在平峰配送 → 论据不成立 ✅
- 附带铁律：**成本高 ≠ 不可行**；只有涉及"普及/老百姓负担"时，钱才可以削弱。

#### 例 13（2023 深圳·电动车省钱）→ A

- 题干两个相反观点："有人认为买车是为省钱" vs "因此，并非为省钱" → **双方互怼**。
- 论点：人们购买电动汽车的目的**并非**为了省钱。
- 论据两条：①多年后必须换电池；②为装充电桩必须买固定车位 → 总成本高于油车。
- **A**：多数车主用公共充电桩，**并没有购买固定停车位** → 否掉第②条论据 ✅
- B 是易错项：它拿"换电池"与"买新车"比较，与题干的"电车 vs 油车成本"比较**对象不同** → 无关。
- C 生活理念、D 油价下降 → 均未回答"是否为了省钱"。

#### 例 14（2016 河南·玫瑰花）→ D

- 小王说法："其他可能性都被排除，剩下的可能性再荒谬也是真的"。
- **D**：小王**不可能穷尽**所有可能性 → 直接否掉其论据 ✅（"穷尽可能性"是典型的可攻击论据）

#### 例 15（2015 吉林·产假）→ B

- 反对者论据：产假太长 → 增加企业负担 → 增加女性就业难度 → 不可行。
- **B**：延长产假的成本由**财政或社保基金**承担 → 否掉"增加企业负担"这一论据 ✅

## 6 拆桥（否定论证）

### 6.1 本质

论据推不出论点，**点破论证的漏洞**。

> 论点"小明特别帅"，论据"小明身材好"
> 拆桥："身材好**推不出**特别帅"——既不否定"帅"，也不否定"身材好"，只否定**二者之间的必然联系**。

拆桥的特点是"**论证不严谨**"：身材和脸不是一回事；逛公园不代表天气好；判断学得好不代表是好学生。

### 6.2 选项特征

**同时包含论点和论据的关键词，并否定二者之间的必然联系。**

论点"我很幸福"，论据"我很有钱"，以下都是拆桥：
- 有没有钱和幸不幸福**没有必然关系**
- 有钱的人**也会不**幸福
- 有钱**不是**衡量幸福的**唯一**指标

> 注意：A、B、C 三个若同时出现，要先看提问是不是"不能削弱"。

### 6.3 何时考虑拆桥

1. **没有**否论点的选项（最常见）；
2. 论点与论据**话题不一致**（驴唇不对马嘴：论据讲"肠道"，论点讲"心脏"）；
3. 设问为"削弱**论证**"（理论优先，实际仍可能考否论点）。

> 实战更常用的是第 1 条：先扫一遍有没有否论点项，没有就拆桥。
> 找答案时**奔着答案去**，不要在选项里逐字死读。

### 6.4 拆桥与否论点的关键区别（易错核心）

| | 否论点 | 拆桥 |
|---|---|---|
| 目的 | 证明**论点错** | 证明**论证过程不严谨** |
| 表述要求 | 必须**明确、确定** | 只需"**不必然**" |
| 能否用"不一定" | ❌ 不能（属不明确项） | ✅ 可以 |

- 论点"烹饪至少发明于 160 万年前"，论据"160 万年前人类已会**用火**"
  - 拆桥："会用火**不一定**会烹饪" ✅
  - "不能确定人类何时开始烹饪" → 否论点否得**不够明确** ❌
- 论点"我很幸福" → 否论点必须说"我不幸福"，不能说"有钱不一定幸福"。

### 6.5 五种特殊拆桥

#### ① 整体与部分

**特征**：论据是"部分"，论点是"整体"（上半年→全年；某峰→全地区；某群体→全部）。

**拆桥两招**：
1. **部分占比很小**——"上半年销量在全年销量中占比很小"
2. **其他部分不这样**——"下半年销量远低于预期"

**力度坑**：
- "**其他**月份都不这样" ✅ ＞ "3 月份不这样" ❌（后者代表性未知）
- 原则仍是**整体 > 部分**。
- 错误表述："1 月份有国补"（不知其他月份有没有）；"只有 1 月份有国补"（可能 1 月把全年的量都卖了）——必须落在**销量占比**上。

**真题例**：论据"珠峰 5000 米以上冰川要融化" → 论点"喜马拉雅地区冰川都要融化"；削弱"**喜马拉雅山其他部分**没有明显融化" ✅（"珠峰 4000—5000 米"范围谁大谁小未知，排除）。

#### ② 物质与元素（"时髦"拆桥）

**特征**：论据"某物质中的某元素有效" → 论点"该物质有效"。

**拆桥**：元素在物质中**含量极低**，或**要吃极多**（夸张剂量）。

| 论据 | 论点 | 削弱 |
|---|---|---|
| 槲皮素能治幽门螺杆菌 | 吃洋葱能治 | 实验用槲皮素与洋葱中浓度差异较大 |
| 丙烯酰胺有致癌性 | 喝咖啡致癌 | 咖啡中丙烯酰胺含量明显低于致癌剂量 |
| 茶皂素能抑制脂肪酶 | 喝茶能减肥 | 按同比例一般人一天要吃**五公斤**干茶叶 |
| 丙烯酰胺是 2A 级致癌物 | 大蒜炝锅致癌 | 致癌临界点＝短时间吃 **32.7 公斤**炝锅蒜 |

> 口诀：**抛开剂量谈效果，都是耍流氓。**
> 剂量必须夸张到"正常人不可能"，"一公斤"这种选项不要选（命题人自己都觉得不严谨）。

#### ③ 实验主体差异（动物 ≠ 人）

**特征**：论据是"小鼠/动物实验"，论点是"对人有效/让人长寿"。
**拆桥**："动物实验有效，是否对人体有效仍需临床试验。"

**真题**：NMN 小鼠实验（寿命延长 20%）→ 论点"NMN 产品可让人长寿"；削弱"动物实验有效，但**是否对人体有效需经临床试验认证**" ✅
**前提**：论点必须落到"人"；若论点只说动物，则不能这样拆。

#### ④ 比例推结论 → 基数不同

**特征**：论据用"占比"比较，结论说"更危险/更受欢迎/更多"。
**拆桥**：**基数（总量）不一样**，占比高可能只因基数大。

**真题**（2021 江苏）：着火事故中乘用车占 69.6%，专用车次之、公交最低 → 结论"乘用车安全性最低"；削弱"专用车、公交车**保有量不到总量 10%**"。
**验证（赋值法）**：设总量 100 辆（专用车+公交 10 辆、乘用车 90 辆），事故 30 起（乘用车 21 起≈23%，专用车+公交 9 起≈90%）→ 结论反转。
**操作**：凡"用比例下结论"，先查基数；可用赋值/赋比例秒解。

#### ⑤ 调查样本不具代表性

**特征**：论据"调查显示……"，结论"某地区/所有人都这样"。

| 题干 | 削弱 |
|---|---|
| 近万名受访者中多数选择冰雪旅游 → 正成为 H 地区越来越多人的选择 | 受访者**几乎都是喜爱冰雪旅游的年轻人**（2024 国考） |
| 57% 被调查者明年有奢侈品消费计划 → 明年消费能力很强 | 该刊物**读者比一般消费者更富有**（2023 四川） |

**实验类三考法**：**他因**（最多）＞ 对照组 ＞ 主体差异。
- 出现"实验前被试之间还有什么差异"→ 他因。

### 6.6 拆桥的多种说法（同一题都对，无力度差别）

以"茶皂素—喝茶—减肥"（2022 山东）为例，三种拆桥都成立：
1. **茶皂素 ≠ 喝茶**（物质与元素）
2. **抑制脂肪酶 ≠ 减肥**（概念跳跃）
3. **老鼠 ≠ 人**（主体差异）

### 6.7 拆桥真题精析

#### 例 16（2026 国考·白垩纪）→ C

- 论点："**现代**陆地生态系统的高度复杂性，是这种古老协同机制延续和演化的结果"。
- 论据："**白垩纪**陆地生态系统由多要素协同演化，形成稳定格局"。
- 两条思路：
  - 思路 1：白垩纪 ≠ 现代 → 拆桥。
  - 思路 2：直接找否论点项——A、B 只讲白垩纪，C 讲"现代"且"**与白垩纪显著不同**"，D 未提现代。
- **C** ✅：现代复杂性主要受随机扰动、自组织演化等影响，与白垩纪显著不同。
- 教训：读不懂就**奔着答案**找，别在选项里越读越费劲。

#### 例 17（2025 湖北选调·烹饪）→ C

- 论点："烹饪至少发明于 160 万年前"；论据："160 万年前人类已**会用火**"。
- 差距：**用火 ≠ 烹饪**（用火也可能取暖、造工具）→ 拆桥。
- **C**：会用火**不一定**会烹饪 ✅
- 易错：
  - A"不一定能确定何时开始烹饪"、D"尚无定论" → 不明确，否论点/否论据**不合格**
  - B"200 万年前可能已失去生食特征" → 时间更早，是**加强**
- **本题是全章最该吃透的一道**：同一句"不一定"，在否论点里是废话，在拆桥里是正解。

#### 例 18（2022 联考·大蒜炝锅）→ D

- 论点："大蒜炝锅致癌"；论据：炝锅产生丙烯酰胺，丙烯酰胺是 2A 级致癌物。
- 物质与元素 → 拆桥，找"含量低/要吃极多"。
- **D**：致癌临界点＝短时间吃 **32.7 公斤**炝锅蒜 ✅
- C"2A 级指证据有限"是下定义，不能削弱（常识坑：证据有限也是证据，2A 已属较强）。

#### 例 19（2022 事业单位·NMN）→ B

- 论点："NMN 产品可让人长寿"；论据：小鼠实验（70 岁状态回到 20 岁、寿命延长 20%）。
- A 是产品宣称（诉诸宣传）、C 认证情况、D"盲目服用"（极端用法）。
- **B**：动物实验有效，但**是否对人体有效需临床试验** ✅ 拆桥（鼠≠人）

#### 例 20（2021 江苏·新能源车）→ D

- 论点："乘用车安全性**大大低于**专用车和公交车"；论据：着火事故中乘用车占 69.6%。
- 先扫否论点：只有 C 涉及两者比较，但"伤亡人数"不等于"事故率"（每车人数不同）→ 不是否论点。
- 转拆桥：**比例缺基数**。
- **D**：专用车和公交车保有量**不到总量 10%** ✅
- 赋值一算即知，结论正好反了。

## 7 特殊提问：不能削弱

- **问"不能削弱"**：加强与无关都可，**排除所有能削弱的选项**，剩下即答案。
- 若加强与无关同现，优选加强（更不能削弱），但极罕见。
- 不要预设，逐项判"能否削弱"。
- 同类还有"不能加强""不能质疑"——一律用**排除法**。

**真题**（2026 浙江·玉米穗行数）→ D

- 论点：看穗行数（正好 12 行＝非转基因，多于 12 行＝转基因）即可判断是否转基因。
- A 技术难以改变穗行数 → 削弱（行数都一样）
- B 转基因不影响外观 → 削弱（看不出差别）
- C 穗行数受遗传和环境多重影响、同品种也有波动 → 削弱（12 行不靠谱）
- **D**：穗行数由基因决定、小花成对排列，故**始终为双数** → 12 和 14 都是双数，说明不了什么，**无关项** ✅

## 8 力度与择优总表

| 维度 | 结论 |
|---|---|
| 按对象 | 否论点 > 拆桥 > 否论据 |
| 按必然性 | 必然（否论点、因果倒置、同果异因）> 或然（他因） |
| 按范围 | 整体 > 部分；"其他部分都不" > "某一个部分不" |
| 按贴合 | 关键词一致/同义替换 > 范围更大 > 范围更小/跑题 |
| 按语气 | 越绝对，力度越强 |
| 按主体 | 全同 > 包含 > 并列/交叉（后两者不可选） |
| 按比较 | 论点有比较→答案有比较且对象一致；论点无比较→答案无比较 |
| 跨维度 | 他因与否论据不在同一维度，考试一般不比较 |

> 补充：拆桥的力度低于直接否论点；但拆桥**不否定论点**，只否定推理过程，所以"拆桥可以削弱，但不能否决论点"。

## 9 高频陷阱清单

1. **副作用**：论点"吃药治感冒"，选项"吃药刺激胃"——没谈疗效。
2. **换病**：论点治感冒，选项治胃炎。
3. **得病 vs 治病**：疫苗是防病，用"病人注射后无变化"削弱无效。
4. **"盲目服用/滥用"**：只说极端用法，不驳正常结论。
5. **只提比较中的一方**：论点 A 比 B，选项只说 B。
6. **比较对象错位**：题干比"电车 vs 油车"，选项比"换电池 vs 换新车"。
7. **偷换主体**：论点"人体"，选项"海洋哺乳动物"（并列）。
8. **偷换概念**：论点"燃气效率"，选项"燃气灶热利用效率"。
9. **不确定表述**：否论点里出现"不一定/没有定论"→ 无效；拆桥里出现 → 有效。
10. **钱不等于无效**：成本高不能否定"有效"；只有涉及普及/百姓负担时钱才可以削弱。
11. **无关新概念**：出现题干从未提及的名词（如"被子植物""避险"）。
12. **实验类先想他因**："实验前被试之间还有差异"。
13. **为反对而反对**：只重复相反立场、不给理由（如"你才是神经病"），主体不一致、无逻辑。
14. **选项读不懂时**：先看它有没有论点关键词，别硬读整句。

## 11 自测与答案

**T1** 研究者让五组受试者面对动感不同的交通标志并测反应速度，发现动感强的标志让人反应更快，建议把交通警告牌全部换成动感强的。以下哪项最能表明该建议**难以实现预期目标**？
A. 换牌工程庞大、成本巨额
B. 受试者中有人驾龄不长、甚至不会开车
C. 司机了解动感标志的实际意义后，反应速度又降回从前水平
D. 画面上的人看起来在跑，容易让人联想到行人突然经过

**T2** 有报道称牛蛙体内含裂头蚴、广州管圆线虫等可在人体寄生的寄生虫，食入会严重影响健康。以下哪项最能削弱？
A. 高温烹饪后牛蛙身上的寄生虫会被全部杀死
B. 淡水虾蟹含肺吸虫，感染后会咳血、呼吸困难
C. 实验室解剖生态养殖牛蛙，未发现裂头蚴
D. 牛蛙身上还有只寄生牛蛙、不传染人的寄生虫

**T3** 公众对糖危害的讨论增多，白糖销量明显下降。这说明公众对糖危害的警觉导致了白糖销量下降。以下哪项最能削弱？
A. 盐和醋的销量近年不断攀升
B. 现在人均白糖消费量是 10 年前的 80%
C. 减少白糖摄入后，一些嗜甜者出现睡眠障碍

| 题 | 答案 | 要点 |
|---|---|---|

## 12 一页速记

1. **先找论点**；论点以外不都是论据，下定义、提问题、"但"之前可略读。
2. 论点论据**一回事 → 否论点**；**不是一回事 → 拆桥**；都没有 → 否论据。
3. **否论点最强**：反着说、整体优先、贴关键词、语气越绝对越好。
4. **主体**：全同、包含可选；并列、交叉不可选。
5. **限定词**：比较、程度、时间必须对上；论点有比较，答案才有比较。
6. **因果类先想他因**（同主体、同时、不同因），再想**因果倒置**（因果同现＋时间颠倒，"才"是信号）。
7. **拆桥只要"不必然"**，否论点必须"明确错"——这是两类题的分水岭。
8. 特殊拆桥五张脸：**部分推整体、元素推物质、动物推人、比例缺基数、样本无代表性**。
9. **不能削弱**＝排除法，加强和无关都留。
10. 纠结就**对比差异**：谁更贴论点、谁范围更大、谁说得更绝对。
