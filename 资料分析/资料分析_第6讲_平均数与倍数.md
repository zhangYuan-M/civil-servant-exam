# 资料分析 · 第 6 讲：平均数与倍数

> **讲义**：P281～P299（平均数、倍数）｜ **主讲**：邓健 ｜ **授课**：2026.03.13
>
> **本讲定位**：上一讲的"比重"是 **A/B**，这一讲的"平均数"也是 **A/B**，"倍数"还是 **A/B**。
> **同一个骨架，三种外壳。** 学完这一讲，你会发现前两讲的公式其实是**同一个公式**——这是本讲最值钱的地方，也是老师说的"把每一类都记得清清楚楚，放一起才不会乱"。

---

## 先看全局

### 1. 两个关键字

| 模块 | 关键字 | 长什么样 |
|---|---|---|
| **平均数** | **平均每**（人均 / 单价 / 亩产 / 每件） | "平均每人多少元""每件多少钱" |
| **倍数** | **倍** | "A 是 B 的多少倍""A 比 B 多几倍" |

### 2. 一张表看清"三家共用一套公式"

| 题型 | 现期 | 基期 | 两期（升降/差值） |
|---|---|---|---|
| **比重**（第 5 讲） | `A/B` | `A/B × (1+b)/(1+a)` | `a vs b`；`A/B × (a−b)/(1+a)` |
| **平均数**（本讲） | `A/B` | `A/B × (1+b)/(1+a)` | `a vs b`；`A/B × (a−b)/(1+a)` |
| **倍数**（本讲） | `A/B` | `A/B × (1+b)/(1+a)` | 无 |

> **三个结论（非常重要）**
> 1. **基期公式完全一样**：`A/B × (1+b)/(1+a)`。
> 2. **升降判断完全一样**：`a > b` 升、`a < b` 降、`a = b` 不变（**带正负号比**）。
> 3. **倍数没有"两期"考法**——要么求现期倍数，要么求基期倍数。

### 3. 本讲地图

```
平均数（关键字：平均每）
├─ 一、现期平均数（重点必考）
│   ├─ 分子分母：后/前；单位法兜底
│   ├─ 多数据求平均：削峰填谷
│   └─ n 年之和 → 反过来看平均数
│
├─ 二、基期平均数（几乎不考）
│   └─ A/B × (1+b)/(1+a)（同基期比重）
│
└─ 三、两期平均数（常考）
    ├─ 比较（升降）：a vs b
    └─ 计算
        ├─ 增长量 = A/B × (a−b)/(1+a)   ★必须算，不能"定大小"
        └─ 增长率 = (a−b)/(1+b)         ★唯一分母是 1+b

倍数（关键字：倍）
├─ 一、现期倍数（多）：A/B
│   ├─ A 比 B 多几倍 = A/B − 1
│   └─ A 超过 B 的 n 倍 = A > n×B
└─ 二、基期倍数（少）：A/B × (1+b)/(1+a)
```

## 一、现期平均数

### 1.1 识别与公式

> **识别：求现在（时间与材料一致）+ "平均每"（人均、单价、亩产、每件…）**

```
平均数 = 总数(A) ÷ 个数(B)
```

**它和比重是同一个结构**：都是 `A/B`。**区别只在于"B 是什么"**——比重里 B 是"总体"，平均数里 B 是"个数"。

---

### 1.2 分子分母怎么定

#### 方法一：**后 ÷ 前**（最快）

> **"平均每"后面那个量是分子，前面那个量是分母。**

| 说法 | 分子（后） | 分母（前） |
|---|---|---|
| **人均**收入 | 收入 | 人数 |
| 平均**每所学校**的人数 | 学生人数 | 学校数量 |
| 平均**每件**商品售价 | 售价（钱数） | 件数 |

> 例："人均收入"——**收入在"均"后**，人在"均"前 → `收入 ÷ 人数`。

#### 方法二：**看单位**（兜底）

> **题干或选项里带单位，单位对应的那个量就是分子。**

- 选项是"**家**"→ 分子是"企业数"
- 选项是"**万元**"→ 分子是"金额"
- 选项是"**人**"→ 分子是"人数"

> 例："人均收入 30 **万**" → "万"是钱的单位 → **分子是收入**。

#### 方法三：**生活常识**（校验）

> 算完问自己一句：**这个数合不合理？**
> "平均每件案件帮助 1.1 人"合理；"平均每件案件帮助 1.1 件"就荒谬。

**【速算】** 截位直除（第 1 讲）。

### 1.3 例题（现期平均数）

#### 例 1　【基本型】

**【例 1】（2024 广东）**

> 2022 年，G 省法律援助机构共组织办理法律援助案件 195779 件，帮助受援群众 212993 人。
> 问：2022 年，G 省平均每件法律援助案件帮助受援群众：

A. 小于 1.1 人　B. 在 1.1 到 1.2 人之间
C. 在 1.2 到 1.3 人之间　D. 大于 1.3 人

**【解】**
```
平均数 = 后/前 = 群众 ÷ 案件 = 212993 ÷ 195779
```
**选项差距小**（1.1 / 1.2 / 1.3 挨得很近）→ **截三位**：

```
212993 ÷ 196 ≈ 1.09
```
→ 小于 1.1 → **选 A**

**【提醒】** **不要图省事把分母当成 2**（`212993/200000 ≈ 1.06`）——虽然这题碰巧也能选对，但**差距一小时的题就会错**。
> **选项差距小 → 至少截三位**，这是铁律。

---

#### 例 2　【分子要先减】

**【例 2】（2025 国考）**
> 2023 年第五批次公示的专精特新"小巨人"企业共 3671 家，分布于全国 300 个城市中，其中上市企业 134 家。
> 问：这些城市平均每个有多少家第五批次公示的专精特新"小巨人"**非上市**企业？

A. 不到 11 家　B. 11-12 家之间　C. 12-13 家之间　D. 超过 13 家

**【解】**
```
分子 = 非上市企业 = 3671 − 134 = 3537
分母 = 城市数 = 300
平均数 = 3537 ÷ 300 ≈ 11.8
```
→ 11-12 之间 → **选 B**

**【提醒】** **三个坑，一个都不能漏**：
1. **"非上市"** → 分子要先减掉 134；
2. **"第五批"** → 材料里可能有多批数据，别拿错；
3. **单位是"家"** → 家对应企业，所以企业是分子（**单位法定分子**）。

---

#### 例 3　【排序题：先判量级，再比细节】

**【例 3】（2025 联考）**
> 2017—2020 年全国亿元以上商品交易市场的摊位数量与成交额：
> 2017 年成交额 550 亿元、摊位 4.5 万个；2018 年 399 亿元、4.1 万个；2019 年 438 亿元、4.0 万个；2020 年 348 亿元、3.4 万个。
> 问：2017—2020 年全国亿元以上商品交易市场每个摊位平均成交额由高到低排序正确的是：

A. 2017、2019、2018、2020
B. 2017、2020、2019、2018
C. 2018、2020、2019、2017
D. 2017、2019、2020、2018

**【解】** 平均数 = 成交额 ÷ 摊位：

| 年份 | 计算 | 约值 |
|---|---|---|
| 2017 | 550 ÷ 4.5 | **≈122** |
| 2018 | 399 ÷ 4.1 | **≈97** |
| 2019 | 438 ÷ 4.0 | ≈110 |
| 2020 | 348 ÷ 3.4 | ≈102 |

→ **2017 > 2019 > 2020 > 2018** → **选 D**

**【提醒】** **排序题的正确姿势：先找"及格线"，再比细节。**
> 第一反应应该是"**有没有超过 100**"——**只有 2018 年没到 100**，所以 2018 必然垫底，一步排除 A、C。
> 剩下 B、D 的区别只在"2019 和 2020 谁大"，这时才需要真算（`438/4 ≈ 110` vs `348/3.4 ≈ 102`）。
>
> **用一条"阈值"砍掉一半选项，永远比从头算四个分数快。**

### 1.4 削峰填谷：多个数求平均

> **题目**：给出 5 个数，求它们的平均数。
> **思路**：**挑一个"中间好算的值"当基准，看每个数相对它的差，累加后除以个数。**

**原理**：
```
平均数 = 基准值 + (各数相对基准的差之和) ÷ 个数
```

**【示例 1】** 求 99 和 101 的平均数：
```
取基准 100 → 差是 −1 和 +1 → 和 = 0 → 平均 = 100 + 0/2 = 100
```

**【示例 2】** 求 98、99、97、105 的平均数：
```
取基准 100 → 差是 −2、−1、−3、+5 → 和 = −1
平均 = 100 + (−1)/4 = 100 − 0.25 = 99.75
```

> **这个方法的妙处**：把"5 个数相加再除 5"变成"5 个小数字相加再除 5"，**数字小了，心算就行**。

---

### 1.5 逆向思维：n 年之和 → 看平均数

> **题目问"5 年之和是否超过 X"时，等价于问"平均每年是否超过 X/5"。**
> 因为 `5 年之和 > X` ⟺ `平均数 > X/5`。

**为什么好用？**
> 多个大数直接相加，**进位极容易错**；而"和门槛 ÷ 年数"往往是个整数（比如 3 万亿 ÷ 5 = 6000），**一眼就能比**。

---

### 1.6 例题（削峰填谷 + 逆向思维）

#### 例 4　【判断题：年均是否超过某值】

**【例 4】（2025 广东）**

> 判断："2018—2023 年，国家铁路旅客年均周转量超过 12000 亿人公里"这一说法是否正确。

A. 正确　B. 错误

**【解】**
1. **先识别题型**：题干出现"**年均**周转量"，但**没有"增长"二字** → 求的是**6 年的平均数**，**不是年均增长量**（第 4 讲）。
2. **削峰填谷**：假设平均数就是 **12000**，在柱状图上 12000 处画一条横线。
3. **看高低**：明显**不足 12000 的柱子比超过的更多** → 平均数**不到 12000**。
4. → 说法错误 → **选 B**

**【提醒】** **这道题一步除法都不用**——在图上画一条线，看"多出来的面积"和"缺的面积"哪个大。

> **凡是"是否超过某个整数值"的判断，先想"能不能画条线看"**，这比算六个数快十倍。
>
> 年均增长量是 5；平均周转量是 6

#### 例 5　【削峰填谷的标准应用】

**【例 5】（2024 联考）**
> 表中所列国家中，2022 年全球创新指数排名前五位国家的平均创新指数是：（五个国家的指数分别为 64.6、61.8、61.6、59.7、58.0）

A. 58.54　B. 59.74　C. 60.84　D. 61.14

**【解】** 取**基准 60**（选项都在 60 附近）：
```
差距：+4.6、+1.8、+1.6、−0.3、−2.0
合计：+5.7
平均数 = 60 + 5.7 ÷ 5 = 60 + 1.14 = 61.14
```
→ **选 D**

**【提醒】** **基准怎么挑？看选项。** 四个选项都在 58~62，那 60 就是天然基准。
> **另外注意老师的一句警告**：**除法中不要用尾数法**。
> 本题 `5.7/5 = 1.14`，尾数恰好是 "14"，但换成 `17/5 = 3.4` 尾数就变了——**尾数法只能用在精确加减里，乘除法一律不用**。

#### 例 6　【5 年之和：两种解法】

**【例 6】（2026 天津）**
> 2019—2023 年，城乡居民基本医疗保险收入中的财政补助分别为 5733、5936、6272、6358、6613 亿元。
> 问：财政补助累计收入在以下哪个范围内？

A. 不到 2.8 万亿元　B. 2.8 万亿～3 万亿元
C. 3 万亿～3.2 万亿元　D. 3.2 万亿元以上

**【解】**

**方法一：凑整（快）**
```
5733 + 6272 ≈ 6000 + 6000
5936 + 6358 + 6613 = 6000×3 + 1000⁻
合计 ≈ 5 × 6000 + 1000⁻ ≈ 3.09 万亿
```

**方法二：逆向思维（更快，推荐）**
```
以 3 万亿为界 → 平均每年 6000
只有 5733 比 6000 少 200 多，其余四个都在 6000 附近或以上
→ 平均数 > 6000 → 总和 > 3 万亿 → 排除 A、B

以 3.2 万亿为界 → 平均每年 6400
四个数都不到 6400，只有 6613 略超
→ 平均数 < 6400 → 总和 < 3.2 万亿 → 排除 D
```
→ **选 C**

**【提醒】** **"求 5 年之和"不要真加**——直接看"平均数够不够 6000 / 6400"。
> **这是本讲最实用的一个思维**：`n 年之和 > X` ⟺ `平均数 > X/n`，而平均数只要**眼估**即可。

**【练习 1】（2023 国考）**

> 判断："2016～2020 年，通用超算服务市场累计规模超过 160 亿元"这一说法是否正确。

## 二、基期平均数

### 2.1 识别与公式

> **识别：求去年（时间在材料之前）+ 平均数**
> **公式：`A/B × (1+b)/(1+a)`（与基期比重完全一样）**

| 字母 | 含义 |
|---|---|
| A | 分子的现期量（"平均每"**后**面那个量） |
| B | 分母的现期量（"平均每"**前**面那个量） |
| a | 分子的增长率 |
| b | 分母的增长率 |

**【推导】**

```
基期平均数 = 基期分子 ÷ 基期分母
          = [A ÷ (1+a)] ÷ [B ÷ (1+b)]
          = A/B × (1+b)/(1+a)
```

**【方法】（和基期比重一模一样）**
> **① 算左边 A/B**（现期平均数）→ **② 看右边与 1 的大小** → **③ 选答案**
> 选不出来：**截三位 + 等比例放缩**（第 5 讲）

> **老师原话**：**"该考点很冷门"**——不用花太多时间，知道它和基期比重是同一个东西就够了。

### 2.2 例题

#### 例 7　【基期平均数：算左看右 + 等比例放缩】

**【例 7】（2023 湖北选调）**
> 2021 年，全国公共图书馆共为读者举办各种活动 202568 次，比上年增长 34.4%；参加人次 11892.49 万，增长 28.2%。
> 问：2020 年，全国公共图书馆为读者举办各种活动平均每次约有多少人参加？

A. 560　B. 587　C. 615　D. 643

**【解】**
```
A = 11892（参加人次），a = 28.2%
B = 202568（活动次数），b = 34.4%

① 左边：11892 ÷ 202568 ≈ 5.87%  → 换算成"每次多少人" = 587 人
    ← B 项（587）就是现期坑
② 右边：(1+34.4%)/(1+28.2%) = 1.344/1.282 > 1（因为 b > a）
③ 所以答案 > 587，且只大一点点
```

**估大多少**：分子比分母大 `6.2 个百分点`，所以右边 ≈ `1 + 6.2%/1.282 ≈ 1 + 4.8%`
```
587 × 1.048 ≈ 615
```
→ **选 C**

**【等比例放缩验证】** 截三位为 `587 × 134/128`：
```
分母 128 + 6 = 134；587 约是 128 的 5 倍 → 分子加 6×5 = 30
(587 + 30) × 134/134 = 617
```
→ 最接近 615 → **选 C**

**【提醒】** 本题有两个值得记住的点：

1. ~~**`(1+b)/(1+a)` 与 1 的差距，可以近似成 `(b−a)/(1+a)`**——本题就是 6.2/1.282 ≈ 4.8%，**比硬算比值快**。~~
2. **等比例放缩里"倍数取 4 还是 5"不重要**：取 4 倍得 611、取 5 倍得 617，**都指向 C**（615）。

### 📌 基期平均数小结

易错点

+ 基期平均数和基期比重的公式一样，都是`A/B * (1+b)/(1+a)`

## 三、两期平均数

> 分两块：**比较（只问升降）** 和 **计算（问具体多多少）**。
> **比较**和两期比重**完全一样**；**计算**有一个致命区别——**不能"定大小"**。

---

### 3.1 比较：平均数升降

#### （1）识别

> **两个时间 + 平均数 + 上升/下降（高于/低于/涨了/跌了）**

#### （2）结论（与两期比重相同）

```
a > b  →  平均数上升  现期大
a < b  →  平均数下降  现期小
a = b  →  平均数不变

a：分子的增长率（"平均每"后面那个量）
b：分母的增长率（"平均每"前面那个量）
```

> **比较时必须带正负号**：如 a = −3.2%、b = −5.1% → `−3.2% > −5.1%` → **上升**。

#### （3）生活化理解（老师的三口之家）

> 邓老师家三口人，**工资涨了、人数没变** → 人均收入**上升**（a > b）。
> 老板撤回涨薪，**老婆怀了二胎、收入没变** → 人均收入**下降**（a < b）。
> 一切都是做梦，**收入和人数都没变** → 人均收入**不变**（a = b）。

> **一句话**：**分子涨得比分母快，平均值就变大。**

#### （4）例题

**【例 1】（2024 新疆兵团）**
> 2023 年一季度，新疆煤炭进口 3.7 亿元，同比增长 79.6%；进口量同比增长 78.8%。
> 判断："2023 年一季度，新疆煤炭进口单价高于上年同期水平"这一说法是否正确。

A. 正确　B. 错误

**【解】**
```
单价 = 金额 ÷ 数量 → a = 79.6%（金额），b = 78.8%（数量）
a > b → 单价上升
```
→ 说法**正确** → **选 A**

**【提醒】** **"单价""均价"一律用"钱 ÷ 量"**——这是本讲最高频的一个主体。
> 判据只有一句：**钱的增速 > 量的增速，价格就涨。**  a>b 现期平均数大于基期平均数

---

**【例 2】（2025 上海）**
> 2024 年 1—7 月，海南离岛免税销售平均每件商品售价高于上年同期的月份有多少个？

A. 2　B. 3　C. 4　D. 5

**【解】**
```
平均每件售价 = 销售额(a) ÷ 销售件数(b)
"高于" ⟺ a > b
```
逐月带符号比较（**负得越小值越大**），满足 `a > b` 的有 **5 个** → **选 D**

**【提醒】** **本题的坑在"负数比较"**：
> 比如某个 a = −3.2%、b = −5.1%，看起来两个都在跌，但 `−3.2% > −5.1%` → **单价是涨的**。
> **"跌得少"就是"相对涨"**，这一步想不通，全题崩。

---

**【练习 2】（2025 联考）**
> 2024 年 1～6 月，T 市自行车出口均价同比下降的月份有几个？

A. 3　B. 4　C. 5　D. 6

**【解】**
```
出口均价 = 出口额(a) ÷ 出口量(b)
"下降" ⟺ a < b
```
**注意两件事**：
1. **时间是"1～6 月"，不要把"合计"那一行也算进去**；
2. 逐月比 a、b 即可。

满足的有 **5 个** → **选 C**

**【提醒】** **"合计/累计"那一行永远是干扰项**——它和"逐月"不是一个口径。
> 题目问"几个月"，就只看月份行。

### 3.2 计算：平均数的增长量

#### （1）识别

> **平均数 + 增长/下降 + 具体单位**（元、人、吨、万元/件…）

#### （2）公式（与两期比重差**长得一样**）

```
平均数的增长量 = 现期平均数 − 基期平均数
             =  A/B × (a−b)/(1+a)
```

#### （3）★ 关键区别：为什么**不能**"定大小"

> **这是本讲最容易被"惯性"害死的地方。**

| | 比重 | 平均数 |
|---|---|---|
| 本质 | 一个**百分数** | 一个**具体值**（如人均收入 30 万元） |
| 答案形式 | "提高了几个**百分点**" | "提高了**多少元**" |
| 能不能"定大小" | **能**（差 < \|a−b\|） | **不能** |

**为什么不能？**
> 比重的答案**本身就是百分数**，所以 `比重差 < |a−b|` 这个不等式**有意义**。
> 而平均数的答案**是带单位的钱/量**——`|a−b|` 是百分数，**两者量纲都不一样，没法比大小**。
>
> **所以：平均数的增长量，只能代公式算。**

#### （4）例题

**【例 3】（2025 国考）**
> 2023 年三季度，支付系统共处理支付业务 3358.88 亿笔，金额 3151.37 万亿元，同比分别增长 12.59% 和 6.97%。
> 问：2023 年三季度，支付系统平均每笔支付业务金额比上年同期：

A. 下降了不到 1000 元　B. 下降了 1000 元以上
C. 上升了不到 1000 元　D. 上升了 1000 元以上

**【解】**
```
平均每笔金额 = 金额(A, a) ÷ 笔数(B, b)
a = 6.97%（金额），b = 12.59%（笔数）

第一步：a < b → 下降 → 排除 C、D
第二步：现期平均数 = 3151.37万亿 ÷ 3358.88亿笔 ≈ 9382 元/笔
第三步：代公式
   增长量 = A/B × (a−b)/(1+a)
         = 9382 × (6.97% − 12.59%) / (1 + 6.97%)
         = 9382 × (−5.62%) / 1.0697
         ≈ 9382 × (−5.25%)
         ≈ −493 元
```
→ 下降约 493 元，**不到 1000** → **选 A**

**【提醒】** 注意这里的量级：`3151.37 万亿 ÷ 3358.88 亿` = `31513.7 亿 ÷ 3358.88 亿 ≈ 9.38`，再乘 `10⁴` 才是"元"——**单位换算是本题的隐藏坎**。
> 也可以只看相对变化：`9382 × 5.25% ≈ 492`，**不到 1000**。

### 3.3 计算：平均数的增长率 ★

#### （1）识别

> **平均数 + 增长/上升 + %**（注意是百分号，不是单位）

#### （2）公式（本讲最值得背的一个）

```
平均数的增长率 = (a − b) ÷ (1 + b)
```

**【推导】**
```
r = 增长量 ÷ 基期平均数
  = [A/B × (a−b)/(1+a)] ÷ [A/B × (1+b)/(1+a)]
  = (a−b)/(1+b)          ← A/B 约掉、1+a 约掉
  
  增速 =（现期 − 基期）÷ 基期 = 现期/基期 − 1
  现期平均数 	A/B
  基期平均数	   (A/B) × (1+b)/(1+a)
  现期 ÷ 基期	(1+a)/(1+b)
  增速	      (1+a)/(1+b) − 1 = [(1+a)−(1+b)]/(1+b) = (a−b)/(1+b) 
```

> **★★★ 记忆锚点**：**这是全部资料分析里，唯一一个分母是 `(1+b)` 的公式。**
> 其他所有"基期类/差值类"公式的分母都是 `(1+a)`。**看到分母是 1+b，就是平均数增长率。**

#### （3）例题

**【例 4】（2025 联考）**

> 2024 年 11 月全国烤烟当期出口额同比增长 69%，出口量同比增长 34.2%。
> 问：2024 年 11 月全国烤烟当期出口均价（出口均价 = 出口额/出口量）的同比增速大约是：

A. 不到 20%　B. 20%～30%　C. 30%～40%　D. 超过 40%

**【解】**
```
a = 69%（出口额），b = 34.2%（出口量）
平均数增长率 = (69% − 34.2%) ÷ (1 + 34.2%) = 34.8% ÷ 1.342
```
**只需判量级**：`34.8 ÷ 1.342 ≈ 25.9` → 落在 20%~30% → **选 B**

**【提醒】** 选项是"范围型"时，**只判首位**就够了：`34.8 ÷ 1.34` 首位商 2、次位商 5 → 25.9%，**不用算精确**。

**【例 5】（2024 联考）**
> 2023 年前 5 个月，天津口岸出口汽车约 17.2 万辆，同比增长 29.5%；总价值约 100.1 亿元，同比增长 40.2%。
> 问：2023 年 1～5 月，天津口岸出口汽车均价同比上涨：

A. 8%　B. 12%　C. 16%　D. 20%

**【解】**
```
均价 = 金额(a) ÷ 数量(b)
a = 40.2%，b = 29.5%

平均数增长率 = (40.2% − 29.5%) ÷ (1 + 29.5%)
             = 10.7% ÷ 1.295
             ≈ 8.3%
```
→ **选 A（8%）**

**【提醒】** **有一个"秒杀"思路**：`10.7% ÷ 1.295 < 10.7%`，而**四个选项里只有 8% 小于 10.7%** → 直接选 A，**连除都不用做**。
> **道理**：分母 `(1+b) > 1`，所以**结果一定小于 `a−b`**。
> **这条"必然变小"的性质，是平均数增长率题的天然筛选项。**

**【练习 3】（2019 国考）**
> 2017 年，A 省完成旅客周转总量同比增长 7.7%，增幅比前三季度提高 0.7 个百分点；完成客运总量同比增长 5.4%，增幅比前三季度提高 0.2 个百分点。
> 问：2017 年前三季度，A 省平均每人次客运旅客运输距离（旅客周转量/客运总量）同比：

A. 下降了不到 2%　B. 下降了 2% 以上
C. 上升了不到 2%　D. 上升了 2% 以上

**【解】** **本题的坑在时间**：问的是"**前三季度**"，材料给的是"**全年**"。

```
旅客周转量：全年 7.7%，比前三季度高 0.7 → 前三季度 a = 7.7% − 0.7% = 7.0%
客运总量：  全年 5.4%，比前三季度高 0.2 → 前三季度 b = 5.4% − 0.2% = 5.2%
```
> 这就是第 3 讲的"**高减低加**"：全年比前三季度高，前三季度更低 → 减。

```
平均数增长率 = (7.0% − 5.2%) ÷ (1 + 5.2%) = 1.8% ÷ 1.052 ≈ 1.71%
```
→ 上升不到 2% → **选 C**

**【提醒】** **本讲最容易错的一道题，错因是"用了全年数据"**：
> 如果直接拿 7.7% 和 5.4%，会算出 `2.3%/1.054 ≈ 2.2%` → **错选 D**。
>
> **两个动作必须做**：① 看清问的是哪段时间；② 用"高减低加"把增速倒推回来。

### 3.4 五种问法，一次分清

> **材料**：2024 年老邓公司总收入 80 亿，同比增长 20%；员工 9000 人，同比增加 9%。

| 问法 | 题型 | 怎么做 |
|---|---|---|
| ① 2024 年人均收入约为多少？ | **现期平均数** | `80亿 ÷ 9000人` |
| ② **2023 年**人均收入约为多少？ | **基期平均数** | `80/9000 × 1.09/1.20`，算左看右 |
| ③ 2024 年人均收入比去年**提高还是降低**？ | **两期比较** | `a=20% > b=9%` → **上升** |
| ④ 2024 年人均收入比去年提高了**多少元**？ | **增长量** | `80/9000 × (20%−9%)/(1+20%)` |
| ⑤ 2024 年人均收入比去年提高了**多少（%）**？ | **增长率** | `(20%−9%)/(1+9%)` |

> **一句话分辨**：
> **问"是多少"→ 现期；问"去年是多少"→ 基期；问"升还是降"→ 比 a、b；问"多少元"→ 增长量；问"百分之几"→ 增长率。**
>
> **看单位/百分号定④⑤，看时间定①②，看有无升降定③。**

## 四、倍数

> **关键字：倍。** 这一节最简单——**问法一目了然，一步直除**。
> **没有"两期倍数"的考法**，只有现期倍数和基期倍数两种。

---

### 4.1 现期倍数

#### （1）公式

```
A 是 B 的多少倍 = A ÷ B
```

**【速算】** 截位直除。

#### （2）★ 三种问法，一字之差

| 问法 | 算式 | 举例（A=330，B=66） |
|---|---|---|
| **A 是 B 的几倍** | `A/B` | `330/66 = 5` 倍 |
| **A 比 B 多（高）几倍** | `A/B − 1` | `5 − 1 = 4` 倍 |
| **A 超过 B 的 n 倍** | `A > n × B` | 判断 `330 > n×66` |

**逐条说清：**

**① "是几倍"**——直接除，送分。

**② "比……多几倍"**——**必须减 1**。
> 完整表述是"**A 比 B 多的部分，是 B 的几倍**"，即 `(A−B)/B = A/B − 1`。
> 说得太啰嗦，出题人就简化成"多几倍"——**本质就是算增长率 r**。

**③ "超过 B 的 n 倍"**——**"超过"就是"大于"**，**不减 1**。
> "我的体重超过 100 斤" = 体重 > 100 斤（**不封顶**）。
> "A 超过 B 的 3 倍" = `A > 3B`。

**判断练习**：1000 是否超过 190 的 5 倍？
```
190 × 5 = 950，1000 > 950 → 超过 ✓
```

> **速记**：**"是"直接除，"比多"减 1，"超过"只比大小。**

#### （3）例题

**【例 1】（2023 广东）**
> 2021 年广东农林牧渔业总产值 8305.8 亿元，2012 年为 4550.3 亿元。
> 问：2021 年广东农林牧渔业总产值约为 9 年前的多少倍？

A. 1.2　B. 1.4　C. 1.6　D. 1.8

**【解】**
```
9 年前 = 2021 − 9 = 2012 年
所求 = 8305.8 ÷ 4550.3 ≈ 1.83
```
**看选项**：首位都是 1，最接近的一对是 C（1.6）与 D（1.8），次位差 `8 − 6 = 2 > 1` → **差距大 → 截两位**
```
8305 ÷ 46 ≈ 180.5 → 1.8
```
→ **选 D**

**【提醒】** **"9 年前"要自己算年份**（2021 − 9 = 2012），材料里通常不会直接给你"9 年前"这个标签。

> 另外，`8305/4550` 接近 2 但不到 2 —— 可以用 `4550 × 2 = 9100` 做基准：`(9100 − 795)/4550 ≈ 2 − 0.17 = 1.83`，**比硬除快**。

---

**【例 2】（2026 浙江）**
> 2024 年化工新材料各细分产业规模：工程塑料和特种工程塑料 869.6 亿美元、高端聚烯烃 765.7 亿美元、聚氨酯材料 595.1 亿美元、氟硅材料 333.4 亿美元、电子化学品 210.3 亿美元、高性能纤维 160.2 亿美元（不含"其他材料"）。
> 问：2024 年全球产业规模最高的三类的产业规模之和，约是最低的三类的产业规模之和的多少倍？

A. 3.2　B. 4.7　C. 5.3　D. 6.1

**【解】** 表格恰好按从高到低排：
```
最高三类：869.6 + 765.7 + 595.1 ≈ 2230
最低三类：160.2 + 210.3 + 333.4 ≈ 704
倍数 ≈ 2230 ÷ 704 ≈ 3.17
```
→ **选 A（3.2）**

**【提醒】** 两个细节：
1. **"括号里的解释说明"必须看**——"不包括其他材料"这句话决定了"最低三类"从哪开始数；
2. **选项首位全不同（3/4/5/6）→ 差距大**，可以先各四舍五入再相加，**不用精确到小数点**。

**【例 3】（2024 联考）**
> 问：2013～2022 年，全国亿元以上食品饮料市场成交额**超过**烟酒市场 **3 倍以上**的年份有几个？

A. 6 个　B. 7 个　C. 8 个　D. 9 个

**【解】** "超过 3 倍"= `食品饮料 > 烟酒 × 3`，**逐年比大小**（不是除完再减 1）。
逐个判断后共 **7 个**年份符合 → **选 B**

**【提醒】** **"超过 n 倍"是判断题，不是计算题**——每年只需做一次乘法 `烟酒 × 3`，然后比大小。
> 如果误用"多几倍"（除以后再减 1），**答案会少好几个年份**。

**【例 4】（2025 联考）**
> 2023 年，我国东部地区纸及纸板产量占全国 68.2%，中部地区占 19.2%。
> 问：2023 年我国东部地区纸及纸板产量与中部地区相比约多：

A. 4 倍以上　B. 3～4 倍　C. 2～3 倍　D. 1～2 倍

**【解】**
```
"多几倍" = 东部/中部 − 1
材料只给了占比、没给具体产量 → 但总量相同 → 直接用比重算：
68.2% ÷ 19.2% − 1 ≈ 3.55 − 1 = 2.55
```
→ 2~3 倍 → **选 C**

**【提醒】** **这是本节最漂亮的一个技巧**：
> **总量相同时，两个部分量之间的倍数 = 两个比重之间的倍数。**
> 因为 `(总量×68.2%) ÷ (总量×19.2%) = 68.2%/19.2%`，**总量直接被约掉**。
>
> **考场上看到"只给占比、问倍数"，别慌——直接拿占比除。**

### 4.2 基期倍数

#### （1）识别与公式

> **识别：求去年 + "A 是 B 的几倍"**
> **公式：`A/B × (1+b)/(1+a)`（又是这个公式）**

> **老师原话**：**基期比重、基期平均数、基期倍数，三者公式和方法完全一样。**
> A 永远是分子现期量，B 永远是分母现期量，a 永远是分子增速，b 永远是分母增速。

**【方法】** 算左边（现期倍数）→ 看右边与 1 的大小 → 选答案；不行就截三位 + 等比例放缩。

#### （2）例题

**【例】（2024 联考）**
> 2022 年，铁路交通固定资产投资 7109 亿元，同比下降 5.1%；民航交通固定资产投资 1231 亿元，同比增长 0.7%。
> 问：2021 年铁路交通固定资产投资额是民航交通固定资产投资额的：

A. 5.1 倍　B. 5.5 倍　C. 6.1 倍　D. 7.2 倍

**【解】**
```
A = 7109（铁路），a = −5.1%
B = 1231（民航），b = +0.7%

① 左边：7109 ÷ 1231 ≈ 5.78
② 右边：(1+0.7%)/(1−5.1%) = 1.007/0.949 ≈ 1.061 > 1
③ 结果 ≈ 5.78 × 1.061 ≈ 6.13
```
→ **选 C（6.1）**

**【简便算法】** 右边只比 1 大一点点（约 6%），所以 `5.78 × 1.06 ≈ 6.13`，**不用精确算比值**。
> **判断"右边大约大多少"**：`b − a = 0.7% − (−5.1%) = 5.8%`，`5.8%/0.949 ≈ 6.1%`——**直接得修正系数 1.061**。

#### 练习 4　【用占比算倍数】

**【练习 4】（2021 广东）**
> 2020 年，在西部地区就业的农民工 6279 万人，占农民工总量的 22.0%；在东北地区就业的农民工 853 万人，占农民工总量的 3.0%。
> 问：2020 年，在西部地区就业农民工约比在东北地区就业农民工多多少倍？

A. 9.3　B. 8.3　C. 7.4　D. 6.4

**【解】**
```
"多几倍" = 西部/东北 − 1
总量相同 → 直接用占比：22.0% ÷ 3.0% − 1 = 7.33 − 1 = 6.33
```
→ **选 D（6.4）**

**【验证·用人数】** `6279 ÷ 853 − 1 = 7.36 − 1 = 6.36` ✓

**【提醒】** **本题两个考点叠在一起**：
1. **"多几倍"要减 1**——不减会算出 7.3，**正好是 C 项（7.4）的邻居**；
2. **总量相同，看占比**——用 22%/3% 比用 6279/853 快得多，而且不用碰四位数。

### 📌 倍数小结

基期比重、基期平均数、基期倍数，三者公式和方法完全一样。

## 五、公式总表 📌

| 题型 | 现期 | 基期 | 两期·升降 | 两期·差值 |
|---|---|---|---|---|
| **比重** | `A/B` | `A/B × (1+b)/(1+a)` | `a vs b` | `A/B × (a−b)/(1+a)`，**可定大小** |
| **平均数** | `A/B` | `A/B × (1+b)/(1+a)` | `a vs b` | 增长量 `A/B × (a−b)/(1+a)`，**不可定大小** |
| **平均数增长率** | —— | —— | —— | **`(a−b)/(1+b)`**（唯一分母 1+b） |
| **倍数** | `A/B`（"比多"减 1） | `A/B × (1+b)/(1+a)` | 无 | 无 |

**分子分母怎么定：**

| 题型 | 分子 A | 分母 B |
|---|---|---|
| 比重 | "占"**前**的量（部分） | "占"**后**的量（总体） |
| 平均数 | "平均每"**后**的量（总数） | "平均每"**前**的量（个数） |
| 倍数 | "是"**前**的量 | "是"**后**的量 |

---

## 六、易错清单 📌

1. **分子分母反了**：平均数看"后/前"，比重看"占前/占后"，倍数看"是前/是后"——**三套规则别混**。
2. **单位法兜底**：题干/选项带单位，**单位对应的量就是分子**。
3. **"是否超过某个整数值"**：先想"图上画条线"或"削峰填谷"，**别急着加六个大数**。
4. **"n 年之和"一律转成"平均数"**：5 年 3 万亿 ⟺ 每年 6000 亿。
5. **除法里不能用尾数法**（只有精确加减能用）。
6. **"年均周转量"不是"年均增长量"**：题干有没有"增长"二字，差着一个公式。
7. **"多几倍"要减 1**，"是几倍"不减，"超过 n 倍"只比大小。
8. **总量相同时，部分量的倍数 = 比重的倍数**。
9. **"合计/累计"那一行永远是干扰项**：问"几个月"就只看月份行。
10. **时间要看清**：问"前三季度"就别用全年的增速（要用高减低加倒推）。
11. **平均数的增长量不能"定大小"**：比重是百分数、平均数是具体值，**量纲不同，只能代公式**。
12. **平均数增长率的分母是 `(1+b)`**——全部公式里唯一的一个，**别写成 1+a**。
13. **负数比较带符号**：`−3.2% > −5.1%`，**跌得少就是相对涨**。
14. **"单价/均价"一律用"钱 ÷ 量"**。
