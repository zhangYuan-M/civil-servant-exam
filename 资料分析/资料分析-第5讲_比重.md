# 资料分析 · 第 5 讲：比重

> **讲义**：P271～P292（比重）｜ **主讲**：邓健 ｜ **授课**：2026.03.12
>
> **本讲定位**：**八节课里最重要的一节。**
> 前四讲都是"单一量"的计算（基期、增长率、增长量），从这一讲开始进入"**两个量的关系**"——而"关系"题最容易混。
> **一个关键字：占。** 学会它，你就掌握了资料分析里 20% 的题。

---

## 先看全局

### 1. 一个"占"字，三种题型

```
A 占 B 的比重  =  A ÷ B
  ↑        ↑
部分      总体
（分子）  （分母）
```

> **口诀：占前是分子，占后是分母。**
> 例："农村公路投资额**占**公路交通投资额的比重" → 分子 = 农村，分母 = 公路交通。

| 题型 | 识别关键词 | 难度 | 考试频率 |
|---|---|---|---|
| **现期比重** | 求**现在**（时间与材料一致）+ "占" | 简单 | **考得多** |
| **基期比重** | 求**去年** + "占" | 中等 | 考得少 |
| **两期比重** | 今年**比去年** + 比重 + **升降/几个百分点** | 技巧强 | **常考** |

### 2. 本讲地图

```
比重（关键字：占）
├─ 一、现期比重
│   ├─ 三公式：比重 = 部分/总体；总体 = 部分/占比；部分 = 总体×占比
│   └─ 饼状图专项：看大小 + 看比例（倍数 / 90°、180°）
│
├─ 二、基期比重
│   ├─ 公式：A/B × (1+b)/(1+a)
│   └─ 思维：算左边（A/B）→ 看右边与 1 的大小 → 选答案
│       └─ 选不出来：等比例放缩
│
└─ 三、两期比重
    ├─ 考法一  升降判断：a > b 上升；a < b 下降；a = b 不变
    └─ 考法二  差值计算：判升降 → 定大小（比重差 < |a−b|）→ 猜最小
```

### 3. 本讲答案汇总（做完再对）

| 模块 | 答案 |
|---|---|
| 现期比重 例1–例5 | **D C A D A** |
| 现期比重 例6–例7 | **B A** |
| 基期比重 例1–例3 | **D B A**（例3 见正文说明：按公式应为 **C**） |
| 两期比重 例1–例5 | **B B B A D** |
| 附：练习 1 / 2 / 3 | A / C / A |

## 一、现期比重

### 1.1 识别与三个公式

> **识别：问题时间与材料时间一致（求"现在"），句子里出现"占"。**

#### 三公式（一家人，互相倒）

```
比重 = 部分 ÷ 总体          ← 求占比
总体 = 部分 ÷ 占比          ← 求分母
部分 = 总体 × 占比          ← 求分子
```

**【三个小练习，先热手】**

| 题目 | 算式 |
|---|---|
| 男生 100 人，全班 500 人，男生占比？ | `100 ÷ 500 = 20%` |
| 男生 100 人，占全班 20%，全班多少人？ | `100 ÷ 20% = 500` |
| 全班 2000 人，女生占 60%，女生多少人？ | `2000 × 60% = 1200` |

> **注意**：这三个公式看起来太简单，但**考场上认不出"该用哪一个"，就是失分的开始**。
> 判断依据只有一个：**题目给的两个量里，缺的是谁。**

### 1.2 例题

#### 例 1　【求比重 + 单位陷阱】

**【例 1】（2026 浙江）**
> 2024 年，中国化工新材料产业规模达到 **1655.6 亿美元**，居全球第一位。其次是美国，化工新材料产业规模为 **1455.0 亿美元**。全球化工新材料产业规模 4550.3 亿美元。
> 问：2024 年，中美两国化工新材料产业规模之和占全球比重约为：

A. 52%　B. 57%　C. 63%　D. 68%

**【解】**
```
比重 = (1655.6 + 1455.0) ÷ 4550.3 = 3110.6 ÷ 4550.3
```
**看选项**：首位都是 5 或 6，最接近的一对是 C（63%）与 D（68%），次位差 8 − 3 = 5 **≤** 首位 6 → **差距小 → 截三位**
```
3111 ÷ 455 ≈ 6.84
```
→ **选 D（68%）**

**【提醒·两个坑】**

1. **单位必须统一**：表格里可能给出"亿元（人民币）"的数据，但涉及全球市场时，**国际通用美元**，必须用文字材料里的"亿美元"数据——**混用单位，答案会差几倍**。
2. **看清"之和"**：题目问的是中美**两国之和**，不是只算中国。

---

#### 例 2　【两个比重作差：同分母可合并】

**【例 2】（2026 国考）**
> 2024 年，全国集中式项目核发绿证 46.77 亿个。按项目类型划分：风电 19.07 亿个，常规水电 15.78 亿个，太阳能发电 8.03 亿个，生物质发电 3.81 亿个……
> 问：2024 年，全国集中式风电项目核发绿证数量占当年集中式项目核发绿证数量的比重，比太阳能发电项目的占比高约多少个百分点？

A. 16　B. 20　C. 24　D. 28

**【解】** 两个比重**分母相同**，可以直接合并分子：
```
所求 = 19.07/46.77 − 8.03/46.77
     = (19.07 − 8.03) ÷ 46.77
     = 11.04 ÷ 46.77
```
**看选项**：首位都是 2 或 1，最接近的一对是 B（20）与 C（24），次位差 4 − 0 = 4 **>** 首位 2 → **差距大 → 截两位**
```
11.04 ÷ 47 ≈ 23.5%
```
首位商 2、次位商 4 → **选 C（24）**

**【提醒】** **同分母的两个比重相减，先合并分子，再做一次除法**——这是本讲最省时的一个动作。
> 如果老老实实算两次除法再相减，**多花一倍时间，还多一次误差**。

#### 例 3　【求总体：部分 ÷ 占比】

**【例 3】（2025 联考）**
> 2023 年，数字经济核心产业全球发明专利授权量 88.79 万件，占全球发明专利授权量的 44.4%。
> 问：2023 年全球发明专利授权量约为多少万件？

A. 200　B. 184　C. 39　D. 20

**【解】** 给部分量 + 占比，求总体：

```
总体 = 部分 ÷ 占比 = 88.79 ÷ 44.4% ≈ 200 万件
```

**秒排**：除以小于 1 的数 → 结果 **> 88.79** → **排除 C（39）、D（20）**
**看首位**：88.79 ÷ 0.444 ≈ 200 → 首位商 2 → **选 A**

**【提醒·本题最大的坑是"主体范围"】**
> 图形材料的标题是"**数字经济核心产业**全球发明专利授权量"——前面多了"数字经济核心产业"这个限定词，**它只是全球的一个子集**。
> 如果没注意限定词，会误以为 88.79 就是全球总量，直接选 88 附近的数（没有这个选项，但会乱）。
> **看到"占全球的比重"，就要意识到"前面的数不是全球"。**

#### 例 4　【产业结构 = 占比；部分 = 总体 × 占比】

**【例 4】（2024 山东）**

> 2022 年全省实现地区生产总值 87435.1 亿元，比上年增长 3.9%。第一产业增加值 6298.6 亿元，增长 4.3%，三次产业结构为 **7.2：40.0：52.8**。
> 问：2022 年，第三产业增加值比第二产业增加值大约高：

A. 39870.4 亿元　B. 28678.7 亿元　C. 12130.7 亿元　D. 11191.7 亿元

**【解】** "三次产业结构"= 三个产业的**占比**（加起来 = 100）。
```
第二产业占比 40.0%，第三产业占比 52.8%
差值 = 87435.1 × (52.8% − 40.0%) = 87435.1 × 12.8%
```

**方法一：估（快，但要注意精度）**
```
12.8% ≈ 1/8 → 87435 ÷ 8 ≈ 10929
```
→ 与 D（11191.7）最接近，但**差 260**——如果旁边有 10900 这样的选项，就会错。

**方法二：拆分（准）**
```
12.8% = 12.5% + 0.3%
87435.1 × 12.5% = 10929.4
87435.1 × 0.3% ≈ 262
合计 ≈ 11191
```
→ **选 D（11191.7）**，完全吻合。

**【提醒·三个知识点】**
1. **"结构"就是"占比"**：`7.2：40.0：52.8` 说明第一产业 7.2%、第二 40%、第三 52.8%。
2. **`12.8% ≠ 1/8`**：1/8 = 12.5%，差的那 0.3% 就是 262 亿元——**选项差距小时，这 262 足以改变答案**。
3. **"增加值"不是"增长量"**：它是 GDP 里的一个经济指标（各产业的产出），**和增长率毫无关系**。这个坑在资料分析里反复出现。

#### 例 5　【利润率 = 利润 ÷ 收入；与阈值比大小】

**【例 5】（2025 重庆选调）**
> 中关村国家自主创新示范区十大行业中的第三产业行业中，2022 年利润率（利润总额/总收入）超过 20% 的有几个？

A. 1　B. 2　C. 3　D. 4

**【解】** 材料已给出定义：**利润率 = 利润总额 ÷ 总收入**（不是除以成本）。
逐个判 `利润 ÷ 收入 > 20%`：

| 行业 | 利润/收入 | 判定 |
|---|---|---|
| 电信、广播电视和卫星传输服务 | 利润为**负** | ✗ 直接排除 |
| 科技推广和应用服务业 | 利润为**负** | ✗ 直接排除 |
| 互联网 | 194.2 / 6995.6 < 10% | ✗ |
| 软件和信息技术服务业 | 1750.7 / 13827.4 < 20% | ✗ |
| 商务服务业 | 286.9 / 2100.3 < 20% | ✗ |
| 研究和实验发展 | 259.9 / 1101.3 ≈ **23.6%** | **✓** |
| 专业技术服务业 | 532.4 / 3835.7 < 20% | ✗ |

→ **只有 1 个** → **选 A**

**【提醒·三个提速点】**
1. **利润为负的直接排除**——2 个主体 1 秒出局。
2. **先跟 10% 比**：`收入 × 10%` 就是小数点左移一位，**能秒杀一大半**。
3. **"利润率"在资料分析里 = 利润 ÷ 收入**；数量关系里 = 利润 ÷ 成本。**两科不一样，别串。**

> 为什么资料分析用收入利润率？因为真实企业的成本太复杂（人力、租金、设备、税金、投资、亏损……），**而收入是清楚的**。

### 1.3 饼状图专项

> 饼状图题**几乎不算数**，考的是**看图能力**。两条思维就够。

#### （1）怎么读：默认排布规则

> 题目一般会指明每块对应的图案（黑色/白色/横线/竖线）。
> **如果没指明**：默认从**12 点方向**开始，按**数据给出的顺序**依次**顺时针**排布。
> 例：材料给 A、B、C、D、E 五个数据 → 从 12 点起，顺时针依次是 A、B、C、D、E。

#### （2）两条判读思维

**① 看大小关系**
> 量越大 → 占比越大 → **面积越大**。

**② 看比例关系**
> - **倍数**：A = 100、B = 50 → A 的面积应是 B 的 **2 倍**
> - **特殊角度**：`90° = 1/4`、`180° = 1/2`

> **这两条通常组合使用**：先用"谁最大/谁最小"排掉一半，再用"倍数/角度"定剩下的。

---

#### 例 6　【先定大小，再用角度】

**【例 6】（2026 国考）**
> 2024 年，我国自最不发达国家进口 5565.5 亿元。其中进口铜材 1469.6 亿元、原油 1364.2 亿元、金属矿砂 1221 亿元。
> 问：下列饼状图，最能准确反映 2024 年我国自最不发达国家进口值中，铜材（黑）、原油（横线）、金属矿砂（白）和其他（竖线）占比关系的是？

**【解】**
**第一步：看大小**
```
铜材 1469.6 > 原油 1364.2 > 金属矿砂 1221
```
→ 三块**依次变小**（差得很小，但顺序不能乱）→ 排除顺序不对的选项。

**第二步：算"其他"有多大**
```
其他 = 5565.5 − 1469.6 − 1364.2 − 1221 ≈ 1511
```
→ 四块分别是 **1470、1364、1221、1511**——**都在 1000⁺，大小非常接近**。
→ 如果某张图的"其他（竖线）"明显偏大，就是错的。

**第三步：用特殊角度定生死**
```
铜材占比 = 1469.6 ÷ 5565.5 ≈ 26.4%
```
**26.4% 略大于 1/4（90°）** → 找"黑色那块**刚刚超过直角**"的图 → **选 B**

**【提醒】** 本题的高明之处在于：**四块太接近，光看大小排不干净**，必须用"26.4% 略超 90°"这个精确特征。
> **饼状图的终极武器是"特殊角度"**——90°、180° 是图上唯一能精确判读的位置。

#### 例 7　【先定最大最小，再比次大】

**【例 7】（2026 天津）**
> 2023 年全国新能源乘用车销量中，10 万元以下（黑）83.3 + 43.2；10 万～20 万元（白）115.2 + 236；20 万～30 万元（横线）179；30 万元以上（竖线）91.4 + 26.1。
> 问：以下饼图中，最能准确反映各价位车型占比关系的是？

**【解】**
**第一步：按图案合并数据**
```
黑色（10 万以下）  = 83.3 + 43.2  ≈ 126.5
白色（10～20 万）  = 115.2 + 236 = 351.2  ← 最大
横线（20～30 万）  = 179
竖线（30 万以上）  = 91.4 + 26.1 ≈ 117.5  ← 最小
```

**第二步：定最大**
> 白色 351.2 遥遥领先（占总量的 45%），**面积应接近一半** → 排除白色不是最大的选项。

**第三步：定最小**
> 竖线 117.5 与黑色 126.5 **非常接近**，都远小于横线 179。
> → 竖线应该**略小于**黑色，两者面积相近 → 排除"竖线明显偏大/偏小"的选项。

→ **选 A**

**【提醒】** **一个数据可能由多项相加得到**（如"10 万元以下"包含两个子类）。
> 先按图例**归类求和**，再比较——**跳过这一步，后面全错**。

## 二、基期比重

### 2.1 识别与公式

> **识别：求"去年"的比重**（问题时间在材料时间之前，且出现"占"）。

```
基期比重 = A/B × (1 + b)/(1 + a)
```

| 字母 | 含义 | 记忆 |
|---|---|---|
| **A** | 分子的现期量（**部分**） | 占**前** |
| **B** | 分母的现期量（**总体**） | 占**后** |
| **a** | 分子的增长率 | 跟着 A |
| **b** | 分母的增长率 | 跟着 B |

> **最容易错的地方：右边是 `(1+b)/(1+a)`，分子分母交叉。**
> 记忆法：**上面（分子）放"分母的增长率"b，下面（分母）放"分子的增长率"a"**——**交叉对应**。

---

### 2.2 公式怎么来的（看一眼就够）

```
基期比重 = 基期的部分 ÷ 基期的总体
        = [A ÷ (1+a)] ÷ [B ÷ (1+b)]
        = A/B × (1+b)/(1+a)
```

> **不用背，只要记住一句话**：**部分除以自己的(1+a)，总体除以自己的(1+b)，然后相除。**
> 推导"了解即可，不耽误做题"

---

### 2.3 做题三句话（本讲最重要）

> **① 算左边**：先算 `A/B`（现期比重）
> **② 看右边**：判断 `(1+b)/(1+a)` 与 **1** 的大小关系
> **③ 选答案**：结合选项，**能选则选**

**为什么这么快？** 因为 `A/B` 就是**现期比重**，而它**一定在选项里**——那就是出题人设的"**时间陷阱**"。

> **判断规则（记住）**：
> - `a > b` → `(1+b)/(1+a) < 1` → **基期比重 < 现期比重**
> - `a < b` → `(1+b)/(1+a) > 1` → **基期比重 > 现期比重**
>
> **换句话说：基期比重往"现期比重"的哪一边偏，只看 a 和 b 谁大。**

### 2.4 例题

#### 例 1　【标准型：上下都截位】

**【例 1】（2026 广东）**
> 2025 年上半年，我国新批准建立国家标准物质 524 项，同比增长 78.8%。从研制单位类型看，企业申报标准物质 379 项，同比增长 86.7%。
> 问：2024 年上半年，我国新批准建立的国家标准物质中，企业申报的标准物质项目数约占：

A. 40%　B. 50%　C. 60%　D. 70%

**【解】**
```
A = 379（企业，a = 86.7%）
B = 524（总数，b = 78.8%）

所求 = 379/(1+86.7%) ÷ [524/(1+78.8%)]
     = 379/1.867 ÷ 524/1.788
```
**选项差距大**（40/50/60/70 首位全不同）→ 多步除法，**上下都截两位**：
```
38/19 ÷ (52/18) = 2 × 18/52 = 36/52 ≈ 69%
```
→ **选 D（70%）**

**【提醒】** 基期比重是**两次除法再相除**，如果硬算，一道题要 40 秒。

> **"上下都截两位 + 约分"是标准动作**：`379/1.867 → 38/19 = 2`，一步就化成了一个整数。
> 这就是第 1 讲"多步除法，分子分母都截"在这里的直接应用。

---

#### 引例　【先跑通"算左看右"的思维】

**【引例】**
> 2024 年全国 GDP 120 万亿，同比增长 5%。其中湖北 GDP 6 万亿，同比增长 8%。
> 问：2023 年湖北 GDP 占全国的比重？

A. 4.86%　B. 5%　C. 5.2%　D. 6%

**【解】**
```
① 算左边：A/B = 6/120 = 5%      ← B 项就是现期坑，排除
② 看右边：(1+b)/(1+a) = 1.05/1.08 < 1
③ 选答案：4.86% = 5% × 1⁻ → A 项
```
→ **选 A**

**【提醒】** 这题**一步除法都不用**：
> 现期比重 5% 一眼看出（`6/120 = 1/20`），右边小于 1，所以答案**必然比 5% 小**——**只有一个选项满足**。
>
> **这就是"分析"的价值：不算，也能选。**

### 2.5 进阶例题（b 要自己求 / 选项差距小）

#### 练习 1　【标准型】

**【练习 1】（2019 青海）**
> 2018 年 1～10 月，全国房地产开发投资 99325 亿元，同比增长 9.7%。其中住宅投资 70370 亿元，增长 13.7%。住宅投资占房地产开发投资的比重为 70.8%。
> 问：2017 年 1～10 月，住宅投资占房地产开发投资的比重约为？

A. 68.4%　B. 70.8%　C. 72.8%　D. 73.4%

**【解】**
```
① 左边：A/B = 70.8%      ← B 项是现期坑
② 右边：(1+9.7%)/(1+13.7%) < 1    （a = 13.7% > b = 9.7%）
③ 结果 < 70.8% → 只有 A（68.4%）满足
```
→ **选 A**

**【提醒】** **题目已经把 A/B 直接给你了**（"比重为 70.8%"）——连除法都省了。
> 这是基期比重题最常见的形式：**材料里现成给出"占……的比重为 X%"，问去年的比重。**

#### 例 2　【b 需要自己求：高减低加】

**【例 2】（2022 江苏）**
> 2020 年江苏省"三新"经济增加值 25177 亿元，比上年增长 5.6%，**比全省地区生产总值的增速快 1.5 个百分点**，占全省地区生产总值的比重为 24.5%。
> 问：2019 年江苏省"三新"经济增加值占全省地区生产总值的比重是：

A. 20.5%　B. 24.2%　C. 27.1%　D. 30.0%

**【解】**
```
a（三新增速）= 5.6%
b（GDP 增速）= 5.6% − 1.5% = 4.1%     ← 高减低加（第 3 讲）
① 左边：A/B = 24.5%                    ← C、D 排除
② 右边：(1+4.1%)/(1+5.6%) < 1          （a > b）
③ 结果比 24.5% 略小 → B（24.2%）
```
→ **选 B**

**【提醒】** 本题有**两层考点**：
1. **b 没直接给**，要用"比……快 1.5 个百分点"倒推（**比它快 → 它更低 → 减**）；
2. **"经济增加值"是经济指标，不是增长量**——这一点和第 4 讲的"增加值"坑是同一个。

#### 【例 2 拔高】选项差距小 → 等比例放缩

**【例 2 拔高】（同上材料，改选项）**

A. 20.5%　B. 24.2%　C. 21.1%　D. 22.8%

**【解】**
```
所求 = 24.5% × 1.041/1.056 < 24.5%
```
C、D、A、B **全都小于 24.5%** → **"看右边"失效了**（这一步很关键：不是所有题都能靠范围锁定）。

**改用等比例放缩**：
```
截三位：245 × 104/106
观察到 245 与 106 大约 2 倍多 → 令 106 − 2
分子同步减：245 − 2×2 = 241
原式 ≈ 241 × 104/104 = 241
```
→ 有效数字 241 → **选 B（24.2%）**

#### 例 3　【a < b 时，基期比重反而更大】

**【例 3】（2024 联考）**
> 2022 年，农村公路交通固定资产投资 4733 亿元，同比增长 9.7%；公路交通固定资产投资 28527 亿元，同比增长 15.6%。
> 问：2021 年农村公路交通固定资产投资额占公路交通固定资产投资额的比重为：

A. 15.7%　B. 16.5%　C. 17.4%　D. 19.5%

**【解】** 先定四个字母（**占前 = A、a；占后 = B、b**）：
```
A = 4733（农村公路），a = 9.7%
B = 28527（公路交通），b = 15.6%
```
**① 算左边**：`4733 ÷ 28527 ≈ 16.6%` ← **B 项（16.5%）就是现期坑**
**② 看右边**：`(1+b)/(1+a) = 1.156 ÷ 1.097 ≈ 1.054 > 1`
**③ 定方向**：基期比重 = 现期比重 × 1.054 → **比 16.6% 更大**
**④ 选答案**：比 16.6% 略大的只有一个 → **C（17.4%）**

**【验证】** `16.6% × 1.054 ≈ 17.5%` ✓ 与 C 项吻合。

> **【本题的教学价值：打破一个错误直觉】**
> 很多人有个惯性——"**求基期就一定比现期小**"。**这是错的。**
> 基期比现期大还是小，**完全由 a 和 b 谁大决定**：
> - `a > b` → 右边 < 1 → 基期比重**更小**（练习 1、例 2 都是这种）
> - `a < b` → 右边 > 1 → 基期比重**更大**（就是本题）
>
> **所以"算左边、看右边"这个动作不能省——它就是用来判方向的。**

> **【关于讲义参考答案】**
> 讲义这道题标注的答案是 A（15.7%），其解析写的是"`(1+9.7%)/(1+15.6%) < 1`，所以比 16.6% 小"。
> 但按公式，交叉对应的应是 **`(1+b)/(1+a) = 1.156/1.097 > 1`**——一旦 a、b 代反，方向就整个颠倒了。
> **建议你以公式为准**：把 `A=4733、a=9.7%、B=28527、b=15.6%` 代进 `A/B × (1+b)/(1+a)`，算得 17.5%。
> **这恰好说明本讲最危险的地方：a、b 认反，一步错、步步错。**

> **【顺带记住两个信号】**
> 1. **左边算出的现期比重，一定在选项里**——那是"时间陷阱"，**不是答案**（本题的 B 项、练习 1 的 B 项、例 2 的 C/D 项都是）。
> 2. **判断方向永远只看 a、b 谁大**，不要凭"基期/现期"的字面感觉。

### 2.6 等比例放缩（速算补充）

> **什么时候用**：选项差距小、截三位也不好算时（**涉及基期量时尤其好用**）。
> **怎么用**：观察分子和分母的**大致几倍**（找接近即可），**分子、分母同时加减相同倍数的数**，分数的值不变。

#### （1）原理

```
若 M = 3N，则 (3N + 3)/(N + 1) = 3(N+1)/(N+1) = 3     ← 结果不变
        (3N − 15)/(N − 5) = 3(N−5)/(N−5) = 3
```
> **一句话**：**分子是分母的 3 倍，分母加 1，分子就要加 3；分母减 1，分子就要减 3。**
> 生活化：1 个人吃 1 碗饭，3 个人就吃 3 碗——**比例不变，才是"等比例"**。

#### （2）三个示范

| 原式 | 观察 | 操作 | 结果 |
|---|---|---|---|
| `310/101` | 310 ≈ 3 × 101 | 令 101 − 1，分子 − 3 | `307/100 = 3.07` ✓（真值 3.069） |
| `673/107` | 673 ≈ 6 × 107 | 令 107 − 7，分子 − 6×7 | `(673−42)/100 = 6.31` |
| `708/114` | 708 ≈ 6 × 114 | 令 114 − 4，分子 − 4×6 | `(708−24) × 110/110 = 684` |

**【应用】** 基期量 `673 ÷ (1+6.96%) ≈ 673/107`：
A. 600　B. 620　C. 630　D. 724　→ 放缩得 631 → **选 C**

#### （3）三个高频疑问（老师原话）

**问：能不能让 `1.04 + 2`？**
> 不行。`(1+b)/(1+a)` 只有**一个分母 106**，把分子 104 加 2 就没法约分了。**必须动分母。**

**问：怎么能动分子 245？**
> 换个位置就明白了：`245 × 104/106 = 245/106 × 104`（乘法交换律）。
> 所以**只要是上下有比例关系，动谁都行**——但**要留着 104 去约分**，所以只能动 106 和 245。

**问：245 和 106 到底算 2 倍还是 3 倍？**
> **不纠结，都行。** 等比例放缩**精度非常高**，找个**差不多的倍数**即可，越接近越好。
> 按 2 倍算得 241，按 3 倍算得 239——**两个都能选出同一个答案**。

### 基期比重小结 📌

**识别**：求去年 + 占
**公式**：`A/B × (1+b)/(1+a)`（**A 配 a，B 配 b，交叉代入**）
**方法**：**算左边 → 看右边 → 能选则选；选不出再等比例放缩**

老师的原话：绝大多数题目靠分析就足够了，不要总想着去算答案，实在分析不出来才去计算。

## 三、两期比重

两期比重 = 现期比重与基期比重**相比**，分两个考法：**只问升降**（简单）、**问升降 + 几个百分点**（技巧强）。

---

### 3.1 考法一：升降判断

#### （1）识别

> **今年比去年 + 比重 + 上升/下降（高低/提高/降低）**

#### （2）结论（背下来）

```
a > b  →  比重上升
a < b  →  比重下降
a = b  →  比重不变

a：分子的增长率（部分的增速）
b：分母的增长率（总体的增速）
```

> **比较时必须带正负号**：如 a = −4.9%、b = 2.5% → `−4.9% < 2.5%` → **下降**。

#### （3）为什么（推导，看一遍就懂）

```
现期比重 = A/B
基期比重 = A/B × (1+b)/(1+a)

a > b  →  (1+b)/(1+a) < 1  →  基期比重 = 现期比重 × (1⁻) < 现期比重  → 上升
a < b  →  (1+b)/(1+a) > 1  →  基期比重 = 现期比重 × (1⁺) > 现期比重  → 下降
a = b  →  两者相等 → 不变
```

**生活化理解**：
> 假设你的收入从 100 万涨到 500 万，全家总收入从 110 万涨到 510 万。
> **别人没怎么涨，你涨了 5 倍** → 你占全家的比重当然**上升**。
> 判据就一句：**你（部分）涨得比全家（总体）快，你的份额就变大。**

#### （4）例题

**【例 1】（2025 四川）**
> 2022 年上半年，我国软件与信息技术服务业总收入同比增长 10.9%。其中，信息技术服务收入同比增长 12%。信息技术服务收入中，集成电路设计收入 1279 亿元，同比增长 15.2%。
> 判断："2022 年上半年，我国集成电路设计收入占信息技术服务收入的比重低于上年同期"这一说法是否正确。

A. 正确　B. 错误

**【解】**
```
比重 = 集成电路（a）/ 信息技术服务（b）
a = 15.2%，b = 12%
a > b  →  比重上升
```
题目说"**低于**上年同期" → **说法错误** → **选 B**

**【提醒】** 这类题**只考一句话**：`a` 和 `b` 谁大。
> 但要**找准两个主体**：分子是"集成电路设计收入"，分母是"**信息技术服务收入**"（不是"软件与信息技术服务业总收入"！）。
> **分母找错，b 就找错，方向就反了。**

**【例 2】（2025 联考）**
> 2024 年 7 月，规模以上工业发电量 8831 亿千瓦时，同比增长 2.5%。其中火电下降 4.9%，水电增长 36.2%，核电增长 4.3%，风电增长 0.9%，太阳能增长 16.4%。
> 问：2024 年 7 月，规模以上工业五种发电形式的发电量分别占规模以上工业总发电量的比重，较 2023 年 7 月**下降**的品种共有：

A. 1 种　B. 2 种　C. 3 种　D. 4 种

**【解】** 要比重**下降** → 需要 `a < b`。这里 `b = 2.5%`（总发电量的增速）。

| 品种 | a | 与 b 比较 | 是否下降 |
|---|---|---|---|
| 火电 | **−4.9%** | −4.9% < 2.5% | **✓** |
| 水电 | 36.2% | > 2.5% | ✗ |
| 核电 | 4.3% | > 2.5% | ✗ |
| 风电 | **0.9%** | 0.9% < 2.5% | **✓** |
| 太阳能 | 16.4% | > 2.5% | ✗ |

→ **2 种** → **选 B**

**【提醒·两个坑】**
1. **时间的坑**：要用"**2024 年 7 月**"的 2.5%，**不要错用"1～7 月"的 4.8%**（材料里两个数都有）。
2. **负数的坑**：火电 −4.9%，**带负号比**——它比 2.5% 小，所以**下降**（而不是"涨得少"）。

**【练习 2】（2021 四川）**
> 2019 年，我国电信业务收入 1.31 万亿元，比上年增长 0.8%。其中：固定数据及互联网业务收入 2175 亿元，增长 5.1%；移动数据及互联网业务收入 6082 亿元，增长 1.5%；固定增值业务收入 1371 亿元，增长 21.2%，其中 IPTV 业务收入 294 亿元，增长 21.1%；物联网业务收入增长 25.5%。
> 问：下列指标中，2019 年的数值高于 2018 年的有几项？
> ① 固定数据及互联网业务收入占电信业务收入比重
> ② 移动数据及互联网业务收入占电信业务收入比重
> ③ IPTV 业务收入占固定增值业务收入比重

A. 0　B. 1　C. 2　D. 3

**【解】** "2019 年高于 2018 年" = 比重**上升** → 需要 `a > b`。总体的 `b = 0.8%`。

| 项 | 分子 a | 分母 b | 判定 |
|---|---|---|---|
| ① | 5.1% | 0.8% | 5.1 > 0.8 → **上升 ✓** |
| ② | 1.5% | 0.8% | 1.5 > 0.8 → **上升 ✓** |
| ③ | IPTV 21.1% | 固定增值 21.2% | 21.1 < 21.2 → **下降 ✗** |

→ **2 项** → **选 C**

**【提醒】** 第 ③ 项是本题唯一的分水岭：**很多人下意识拿 IPTV 的 21.1% 去和总体的 0.8% 比**——那就错了。
> **它的分母是"固定增值业务"（21.2%），不是"电信业务收入"。**
> **一句话：分母换了，b 就要换。**

### 3.2 考法二：差值计算

#### （1）识别

> **比重 + 上升/下降 + 几个百分点**

三种常见问法（**内核完全一样**）：
- 占比**增加/减少**了几个百分点
- 比重**上升/下降**了几个百分点
- 比重比**上年同期**上升/下降了几个百分点

> **只要出现"比重 + 升降 + 百分点"三件套，就是本考法。**

#### （2）公式

```
两期比重差 = 现期比重 − 基期比重 = A/B × (a − b)/(1 + a)
```

**推导（了解）**：
```
A/B − A/B × (1+b)/(1+a) = A/B × [1 − (1+b)/(1+a)] = A/B × (a−b)/(1+a)
```

#### （3）两步法（考场版）

> **第一步：判升降** —— `a > b` 上升，`a < b` 下降
> **第二步：定大小** —— **比重差 < |a − b|**

**为什么"比重差 < |a−b|"？**
```
比重差 = A/B × (a−b)/(1+a)
其中 A/B < 1（比重必小于 1），1/(1+a) ≈ 1
所以 比重差 ≈ (a−b) × 一个小于 1 的数  <  (a−b)
```

> **这一步能砍掉一半选项**——因为出题人一定会放一个"等于 a−b"的选项当诱饵。

#### （4）方法失效时：猜最小

> **老师原话：判断完升降、排除一半后，直接选数值最小的，正确率约 90%。**

**为什么？** 从公式看，`A/B` 通常只有百分之十几到几十，再乘以 `(a−b)/(1+a)`，结果会**进一步变小**。
从事实上看，**一国的产业结构一年之内不会有翻天覆地的变化**——比重差本来就很小。

> **但如果选项是"不到 3 个百分点 / 3 个百分点以上"这种范围型**，就不能只靠"猜小"，要**代公式估一下**（见例 4、例 5）。

#### （5）三个预热练习

**【练习 A】** `a = 13.8%，b = 12.5%`
A. 增加 0.5 个百分点　B. 增加 1.3 个百分点
C. 减少 0.5 个百分点　D. 减少 1.3 个百分点

**【解】** `a > b` → **上升** → 排除 C、D。
比重差 `< |13.8% − 12.5%| = 1.3` → 排除 B（等于 1.3）→ **选 A**

---

**【练习 B】** `a = 8.5%，b = 9.5%`
A. 增加 3 个百分点　B. 减少 3 个百分点
C. 增加 0.3 个百分点　D. 减少 0.3 个百分点

**【解】** `a < b` → **下降** → 排除 A、C。
比重差 `< 9.5% − 8.5% = 1` 个百分点 → 只有 D（0.3）满足 → **选 D**

---

**【练习 C】** `a = 10%，b = −5%`
A. 增加 17 个百分点　B. 增加 1.3 个百分点
C. 减少 17 个百分点　D. 减少 1.3 个百分点

**【解】** `a > b` → **上升** → 排除 C、D。
比重差 `< 10% − (−5%) = 15` 个百分点 → **排除 A（17 > 15）** → **选 B**

> **注意这题**：a、b 一正一负时，**增速差要跨过 0**——`10% − (−5%) = 15%`，不是 5%。
> **带符号相减，是这类题的第二个易错点。**

---

#### （6）例题

**【例 3】（2023 广东）**
> 2022 年，我国电信业务收入 1.58 万亿元，比上年增长 8%。其中移动数据流量业务收入 6397 亿元，比上年增长 0.3%，在电信业务收入中占比约 40.5%。
> 问：与 2021 年相比，2022 年我国移动数据流量业务收入在电信业务收入中的占比：

A. 增加了约 3 个百分点　B. 减少了约 3 个百分点
C. 增加了约 13 个百分点　D. 减少了约 13 个百分点

**【解】**
```
a = 0.3%（移动）, b = 8%（电信）
第一步：a < b → 下降 → 排除 A、C
第二步：比重差 < 8% − 0.3% = 7.7 个百分点
选项只剩 B（3）和 D（13）→ 13 > 7.7，排除 D
```
→ **选 B**

**【提醒】** 秒杀逻辑：**先判升降排除一半，再用"小于增速差"排掉那个明显过大的**。
> 这题**两次判断就出答案，一次除法都没做**。

---

**【练习 3】（2023 国考）**
> 2021 年，H 省网上零售额 2948.2 亿元，同比增长 12.5%。其中实物商品网上零售额 2426.4 亿元，同比增长 10.1%。
> 问：2021 年，H 省实物商品网上零售额占网上零售额的比重比上年同期：

A. 下降了不到 3 个百分点　B. 下降了 3 个百分点以上
C. 上升了不到 3 个百分点　D. 上升了 3 个百分点以上

**【解】**
```
a = 10.1%（实物商品）, b = 12.5%（网上零售额）
第一步：a < b → 下降 → 排除 C、D
第二步：比重差 < 12.5% − 10.1% = 2.4 个百分点 < 3
```
→ **下降了不到 3 个百分点** → **选 A**

**【提醒】** 这题的选项是**"范围型"**（不到 3 / 3 以上），所以"定大小"直接锁定：
> 增速差只有 2.4，比重差**必然更小**，一定"不到 3"。

---

**【例 4】（2024 联考）**
> 2023 年，软件产品实现收入 29030 亿元，同比增长 11.1%。其中，工业软件产品实现收入 2824 亿元，同比增长 12.3%。
> 问：2023 年工业软件产品实现收入占软件产品收入的比重比上一年：

A. 上升不到 0.12 个百分点　B. 上升 0.12 个百分点以上
C. 下降不到 0.12 个百分点　D. 下降 0.12 个百分点以上

**【解】**
```
a = 12.3%（工业软件）, b = 11.1%（软件产品）
第一步：a > b → 上升 → 排除 C、D
第二步：比重差 < 12.3% − 11.1% = 1.2 个百分点
```
但选项的界是 **0.12**，而 1.2 比 0.12 大 10 倍 → **"定大小"失效**，必须代公式估：

```
比重差 = A/B × (a−b)/(1+a)
       = 2824/29030 × 1.2%/(1+12.3%)

先看 A/B：2824/29030 ≈ 9.7%   ← 不到 10%
所以：10⁻% × 1.2% ÷ 1.12 ≈ 0.12% × (1/1.12) < 0.12%
```
→ **上升不到 0.12 个百分点** → **选 A**

**【提醒】** **本题是"定大小失效"的典型**：
> 选项的分界线（0.12）比增速差（1.2）**小了 10 倍**，说明出题人**故意把 A/B 这个因子也考了进来**。
> **判断信号**：`选项的量级 ≈ 增速差 × 10%` → 说明要乘上 A/B 再估。

**【例 5】（2026 国考）**
> 2024 年上半年，中药提取物出口额 14.92 亿元，同比下降 14.28%；医药保健品出口总额 525.79 亿元，同比增长 1.96%。
> 问：2024 年上半年，中药提取物出口额占医药保健品出口总额的比重比上年同期：

A. 上升了 3 个百分点以上　B. 下降了 3 个百分点以上
C. 上升了不到 3 个百分点　D. 下降了不到 3 个百分点

**【解】**
```
a = −14.28%（中药提取物）, b = 1.96%（医药保健品）
第一步：a < b → 下降 → 排除 A、C
第二步：比重差 < 1.96% − (−14.28%) ≈ 16 个百分点
```
16 比 3 大得多 → **"定大小"失效**，代公式估：

```
A/B = 14.92/525.79 ≈ 2.8%      ← 远远不到 10%
(a−b)/(1+a) ≈ 16.24% ÷ 0.857 ≈ 18.9%

比重差 ≈ 2.8% × 18.9% ≈ 0.53%
```
→ 0.53% **远远不到 3** → **下降不到 3 个百分点** → **选 D**

**【提醒·估算的三层递进（老师原话）】**
> 1. 先看 `A/B` **有没有到 10%**：本题 2.8%，**远小于 10%**；
> 2. 那么 `10% × 16% = 1.6%`，而真实值比这个还小；
> 3. 就算再除以 0.8，也**顶多 2%**，**绝无可能到 3%**。
>
> **层层压缩，不用精算就能锁定 D。**

### 两期比重小结 📌

**两个考法，一条主线**

> | 考法 | 识别 | 方法 |
>|---|---|---|
> | **升降判断** | 比去年 + 比重 + 升降 | **比 a、b**（带符号） |
> | **差值计算** | 比重 + 升降 + **百分点** | **判升降 → 定大小（< \|a−b\|）→ 搞不定代公式 / 猜最小** |

## 四、如何分辨四种问法（本讲最容易混）

> **材料**：2024 年老邓收入 800 亿，同比增长 10%；老邓家总收入 1000 亿，同比增长 8%。

| 问法 | 题型 | 怎么算 |
|---|---|---|
| ① 2024 年老邓收入占家庭总收入的比重？ | **现期比重** | `800/1000 = 80%` |
| ② **2023 年**老邓收入占家庭总收入的比重？ | **基期比重** | `800/1000 × 1.08/1.10`，算左看右 |
| ③ 2024 年比重比**上年**提高还是降低？ | **升降判断** | `a = 10% > b = 8%` → **上升** |
| ④ 2024 年比重比**上年**提高了**多少个百分点**？ | **差值计算** | 判升降 → 定大小 → 代公式 |

> **一句话分辨**：
> **问"是多少"→ 比重；问"去年是多少"→ 基期比重；问"升还是降"→ 升降判断；问"几个百分点"→ 差值计算。**

#### 三种"坑"的识别

| 坑 | 长什么样 | 怎么破 |
|---|---|---|
| **时间坑** | 选项里出现"现期比重" | 看清问题问的是哪一年 |
| **主体坑** | 分母找错（如把"信息技术服务"看成"软件和信息技术服务业"） | 回到"占"字前后各是什么 |
| **正负坑** | a 或 b 是负数 | 带符号比较，别丢负号 |

## 五、本讲方法总表

| 题型 | 识别 | 公式 | 方法 |
|---|---|---|---|
| **现期比重** | 求现在 + 占 | `部分 ÷ 总体` | 截位直除；同分母可合并分子 |
| **求总体** | 给部分 + 占比 | `部分 ÷ 占比` | 先判大小（÷ < 1 的数会变大） |
| **求部分** | 给总体 + 占比 | `总体 × 占比` | 注意"结构 = 占比" |
| **饼状图** | 图形题 | —— | 定最大最小 → 比倍数 → 看 90°/180° |
| **基期比重** | 求去年 + 占 | `A/B × (1+b)/(1+a)` | **算左边 → 看右边 → 选不出就放缩** |
| **等比例放缩** | 选项差距小、算不动 | —— | 分子分母同倍数加减，比值不变 |
| **两期·升降** | 比去年 + 比重 + 升降 | —— | `a > b` 升、`a < b` 降、`a = b` 平 |
| **两期·差值** | 比重 + 升降 + 百分点 | `A/B × (a−b)/(1+a)` | **判升降 → 定大小（< \|a−b\|）→ 猜最小/代公式** |

## 六、易错清单

1. **"占"前是分子、"占"后是分母**——反了，全题报废。
2. **A 配 a、B 配 b**，公式里是 `(1+b)/(1+a)`，**交叉对应**，别顺手写成 (1+a)/(1+b)。
3. **基期比重的"A/B"就是现期比重，它一定在选项里**——那是坑，不是答案。
4. **分母找错，b 就找错**（例 2 的 4.8% vs 2.5%；练习 2 的 0.8% vs 21.2%）。
5. **a、b 是负数时要带符号比较**：`−4.9% < 2.5%` → 下降。
6. **"增加值"是经济指标，不是增长量**（第 4 讲就强调过，比重题里还会遇到）。
7. **单位要统一**：涉及全球市场用美元，别拿人民币数据硬算（例 1）。
8. **"结构"就是"占比"**：`7.2：40.0：52.8` 表示三个占比。
9. **12.8% ≠ 1/8**：差 0.3%，选项差距小时足以改变答案（例 4）。
10. **饼状图四块接近时，用"90°/180°"定生死**——这是图上唯一能精确判读的位置。
11. **差值计算的"定大小"不是万能的**：选项分界线远小于 `|a−b|` 时，要代公式估 A/B。
12. **两期比重的选项若是"范围型"（不到 X / X 以上），"猜最小"不完全可靠**，要估算。
13. **利润率在资料分析里 = 利润 ÷ 收入**，不是除以成本。
14. **"比去年快/慢 X 个百分点"要倒推 b**（第 3 讲的高减低加）。
