## 一、做题四步法（本讲总纲）

```
① 浏览材料（20 秒）→ 只看时间、结构、主体
② 读题 → 看时间、找关键词 → 定考点
③ 找数 → 代入公式 → 列算式
④ 看选项 → 能看出就选；看不出再按差距算
```

### 1.1 第 1 步：浏览材料（20 秒）

**什么时候要浏览？** 只看材料类型：

| 材料 | 要不要提前读 | 理由 |
|---|---|---|
| 表格 | **不用** | 行列标题一眼可见，直接找数 |
| 柱形图 / 折线图 | **不用** | 图例、坐标轴很明确 |
| **大段文字** | **要（20 秒）** | 找数难，必须先知道"哪一段讲什么" |

**文字材料怎么扫？三个动作：**
```
① 看时间（2024 年一季度）
② 看结构（第一段总述；后四段分别按 产业类型 / 领域 / 行业类别 / 区域）
③ 看主体（每段的"分……看"就是一个小标题）
```

**【第三篇示范】**
```
第一段：总体（营业收入、利润总额、利润率、新业态）
第二段："分产业类型看"  → 制造 / 批零 / 服务
第三段："分领域看"      → 核心 / 相关
第四段："分行业类别看"  → 9 个行业
第五段："分区域看"      → 东 / 中 / 西 / 东北
```
> 扫完之后，题目问"东部、中部"，**直接翻到第五段**——20 秒换来的是后面每道题省 10 秒。

> **注意"分……看"这个句式**：它就是文字材料的"目录"。
> **看到它就停下来，记一下这一段分了几类、分别是什么。**

### 1.2 第 2 步：读题定考点

> **关键词 → 题型**，这一步必须练成条件反射。

| 你看到的关键词 | 立刻想到 |
|---|---|
| 增长 **+ %** | 增长率（第 3 讲） |
| 增长 **+ 单位**（元/人/万件） | 增长量（第 4 讲） |
| 增长 **最快 / 最慢** | **增长率**比较 |
| 增长 **最多 / 最少** | **增长量**比较 |
| **占** | 比重（第 5 讲） |
| **平均每 / 人均 / 单价** | 平均数（第 6 讲） |
| **倍** | 倍数（第 6 讲） |
| 比……**上升/下降**几个**百分点** | 两期比重差 |
| 隔一年 / 年均 / 之和 | 特殊增长率（第 7 讲） |

**老师的一句口诀**：
> **"看时间、找关键词，确定考点，大脑开始检索公式和技巧。"**

#### ★ 长题干：两个逗号 = 先找主体

**【示范】第一篇第 3 题**
> "2024 年 3 月，我国东部地区固定电话用户数**最高的 4 个省市**，其 5G 用户数之和在以下哪个范围内？"

**题干格式是"时间，限定，问题"**——比常规的"时间，问题"多了一层限定。

> **判据**：**题干里出现两个逗号**，往往就是"先找到主体，再算其他指标"。
> 本题：先按"固定电话用户数"排序找出前 4 个省市（江苏、浙江、山东、广东），**再**去求它们的 5G 用户数之和。

> **这一步不看清，会直接拿"全国东部"或"某个省"去算**——数据完全对不上。

---

### 1.3 第 3 步：找数列式

> 找数本身不难，**难在"主体、时间、指标"三对得上**。

**三个"对不上"的典型：**
1. **主体错**：问"产值"却用了"只数"（第 7 讲练习 1）；
2. **时间错**：问"4 月"却用了"1～4 月"的数据（第 6 讲练习 3）；
3. **指标错**：问"城乡居民"却把"职工"也算进去（第二篇第 3 题）。

---

### 1.4 第 4 步：看选项定精度

```
能一眼看出 → 直接选
看不出来   → 看选项差距：差距大截两位，差距小截三位
```

**【第一篇第 2 题示范】**
```
所求 = 76251 ÷ 175886.3
选项是 40 / 42 / 44 这种"范围"，差距小
→ 分母截三位：76251 ÷ 176 ≈ 43.3%
→ C（42%~44%）
```
> **"熟练之后直接分母截三位列式"**——这是老师说的"条件反射"。

## 二、综合分析题：三条策略

> 综合分析 = "以下说法正确/错误的是"，四个选项各考一个知识点，**最费时**。

### 2.1 策略一：先 C、D，后 A、B

> **老师原话**："出题人精心设计四个选项，如果答案是 A 项，后几项会失去意义，所以 **C、D 项正确的概率稍高**。"

**但要留一句余地**：
> "也可能出题人会反套路——**可以优先看 C、D，但不是必须**。"

> **实战价值**：这条策略能帮你**节省 30~60 秒**（少判两个选项），而正确率不受影响。
> **它是个"启发式"，不是"定理"。**

### 2.2 策略二：遇难跳过

> 四个选项里如果有一个"要算三分钟"（比如需要先求基期、再乘、再比），**先做别的**。
> 做完全篇再回来——**很多时候根本不需要它**（前三个已经选出答案）。

### 2.3 策略三：选完就走，不做验证

> **老师原话**："不管是言语的语句填空还是判断的逻辑题，选出一个答案之后，如果做验证都很容易改错，包括综合分析，**改错的概率很大，且费时**。"

> **这条最反直觉，但最重要。**
> 做完就翻页——**验证的时间够你做完下一道题**，而验证带来的收益几乎为零。

### 2.4 一个新趋势：综合分析题在变少

> **2026 国考执法卷的四篇资料分析中，有三篇的第 5 题都不是综合分析**（改成了饼图、柱形图对应、折线图对应）。
> 但 **3.14 省联考中，综合分析题依旧存在**。

> **含义**：图表判断题（"以下哪张图/折线最能反映……"）的比重在上升，**这类题往往比综合分析快**——因为只需要看"形状对不对"，不用逐个验算。

## 三、本讲新增的六个技巧

> 前七讲的公式都能直接套，这一讲真正"新"的是这六个**做题层面的思维**。

### 3.1 肉馅思维：比较 A/(A+B) → 只看 A/B ★

**【场景】** 要比较"职工医保支出 ÷ 全国医保支出"的最大月份，而全国 = 职工 + 城乡。
```
比重 = A / (A + B)      A = 职工，B = 城乡
```

**【做法】** **不用算比值，直接看 `A/B`。**
> **`A/B` 越大，`A/(A+B)` 就越大。**

**【生活化理解·包子】**
> 什么样的包子好？**馅大皮薄**。
> - ①号：馅 60 克、皮 40 克 → 馅占 60%
> - ②号：馅 80 克、皮 20 克 → 馅占 80%
>
> 不用真算比重，**直接看"馅/皮"**：①是 1.5 倍，②是 4 倍 → **②号馅更大**。

**【数学证明（一眼就够）】**
```
A/(A+B) = 1 / (1 + B/A)
B/A 越小 → 分母越小 → 比值越大
而 B/A 越小 ⟺ A/B 越大
```
> **所以"比 A/(A+B)"等价于"比 A/B"，而且 A/B 只需要一次除法。**

**【应用到第二篇第 4 题】**
> 找"职工支出占全国支出比重最大"的月份 → **直接比"黑色柱子 ÷ 白色柱子"** → 明显 **10 月**最大。

> **这个思维可以推广**：凡是"某部分的占比"要**比较大小**（不是求具体值），一律改成"**部分 ÷ 其余部分**"。

---

### 3.2 接近 50% / 100% 时，用拆分比较

**【场景】** 两个分数都接近 50%，比大小不好判。

**【做法】** **看它和 50%（或 1）差多少。**

**【老师的引例】**
> 比较 `98/99` 和 `99/100`：
> ```
> 98/99  = 1 − 1/99
> 99/100 = 1 − 1/100
> ```
> `1/100` 更小 → **`99/100` 更大**。

**【应用到第一篇第 4 题】**
```
北京：2202 / 4077 = (2038 + 164)/4077 ≈ 50% + 4%
浙江：5022 / 9536 = (4768 + 200⁺)/9536 ≈ 50% + 2⁺%
```
→ **北京更大** → **选 A**

> **为什么好使？** 因为"和 50% 的差"往往是个很小、很好算的数。
> **`4077 的一半是 2038.5`**——一眼就能看出 `2202 − 2038.5 = 163.5`，`163.5/4077 ≈ 4%`。

---

### 3.3 多数加和 → 逆向看平均数

**【场景】** 问"累计收入第一次超过 1.5 万亿是哪个月"——要加 5~7 个大数。

**【做法】** **把"和"转成"平均数"**（第 6 讲讲过，这里再用一次）。

**【第二篇第 2 题】**
```
"到 7 月累计超过 1.5 万亿" ⟺ "7 个月平均每月超过 15000/7 ≈ 2143 亿"
```
然后**在柱形图上比一比**：
- 1 月、3 月是两个"峰"，可以补 4、5、6、7 月的"谷" → **能达到 2143**
- 若要求"到 6 月超过"，平均要 2500，**1 月的峰补不上 4、5、6 月的谷** → 达不到
- 若要求"到 5 月超过"，平均要 3000，**每个月都不到 3000** → 不可能

> **一个"加和"问题，变成了三次"比平均数"**，**一次加法都不用做**。

---

### 3.4 "当月 vs 累计" → 转化成混合增长率 ★

**【场景】** 问"当月同比增速快于当月累计同比增速的月份有几个"。

**【转化】** 这一步是本讲最巧的地方：
```
当月 + 1～上月 = 1～本月
→ 混合后居中：r(当月) 和 r(1～上月) 分列两边，r(累计) 在中间
```

**要判"当月 > 累计"**：
```
r(累计) < r(当月)
→ 因为 r(累计) 在两者之间，所以必然 r(1～上月) < r(累计) < r(当月)
→ 即"本月累计增速 > 上月累计增速"
```

> **一句话转化**：**"当月增速 > 累计增速" ⟺ "累计增速的折线在上升"。**
>
> 原本要比 12 组数（当月 vs 累计），**现在只要看**折线图有没有往上走。

**【第四篇第 3 题】** 看折线，累计增速比前一个月高的月份共 **7 个** → **选 C**

**【老师的生活化解释】**
> 3 人考试平均 70 分，加入小邓后平均分变成 80 分。
> **小邓的分数一定高于 80**——否则他没有能力把平均分从 70 拉到 80。
> 同理：**6 月的增速一定高于 6 月累计的增速**，否则拉不动。

### 3.6 常识辅助：会"猜"也是一种能力

> **老师明确说了三处可以用常识：**

| 场景 | 常识怎么用 |
|---|---|
| 医保数据（第二篇） | 职工医保每月缴费**稳定**；城乡医保**下半年集中缴费**，11 月、1 月、3 月是高峰 |
| 饼图（第一篇第 5 题） | **三块"各占 1/3"的图几乎一定是错的**——真实数据很少有这种巧合 |
| 人口（老师举例） | 选项 13/14/15/16 亿 → **秒选 14 亿** |

**【第一篇第 5 题的"排除法"示范】**
```
东部 7818.2、西部 5324.4、其他 17114.8 − 7818.2 − 5324.4 ≈ 3972
→ 三部分依次变小（45.7% / 31.1% / 23.2%）

A 项：三块几乎等大 → 排除（这种数据太"巧"，不会出现）
B 项：灰色和白色差不多 → 排除
C、D 项：都满足"依次变小"，区别在"斜线（东部）是否过半"
      7818.2 / 17114.8 ≈ 45.7% < 50% → 选 D
```
> **饼图的判读顺序**：**先看"等不等大"排掉荒谬的 → 再看"谁最大最小" → 最后用"是否过半 / 是否过 90°"定生死。**

> 每道题给出"**题眼 → 考点 → 关键动作**"，方便对照错题。

≈ 25300（2.5 万⁺），后面的几十加不到 2000

```

### 第二篇（柱形图 · 2026 国考）

| 题 | 题眼 | 考点 | 关键动作 |
|---|---|---|---|
| 1 | 支出超过收入的月份 | **图表比较** | 以 2000 为基准线划一刀：4、5、6、7 月支出在线上（满足），8 月要实算（1880 > 1830，满足），12 月要实算（2800 < 2900，不满足）→ **5 个月** → B |
| 2 | 累计第一次超过 1.5 万亿 | **多数加和 → 看平均数** | 1.5 万亿 ÷ 月数：5 月要 3000（不可能）、6 月要 2500（补不上）、**7 月要 2143（能补上）** → C |
| 3 | 城乡居民收入最高的季度 | **四选一比较** | 二三季度太矮直接排；一季度 3459 vs 四季度 3789 → D |
| 4 | 占比最大的月份 + 环比 | **肉馅思维 + 增长率** | 比"黑/白"，10 月最大；环比 `(1026−1054)/1054 ≈ −2.7%` → 减少不到 5% → D |
| 5 | 柱状图反映哪一指标 | **增量对应** | 9~12 月增量 `600⁺、300⁺、−300、200⁺` → 城乡收入 → C |

> **第 1 题的关键是"划一条 2000 的线"**：线上的都是"支出超收入"的候选，线下直接排。
> **只有 8 月和 12 月跨线，需要实算**——从 12 个月缩到 2 次加法。

### 第三篇（文字 · 2026 四川）

| 题 | 题眼 | 考点 | 关键动作 |
|---|---|---|---|
| 1 | 东部增量占全国增量 | **增长量占比** | 百化分：东部 `24759/12 ≈ 2063`，全国 `31057/13 ≈ 2389` → 86% → A |
| 2 | 比重比上年……几个百分点 | **两期比重差** | a=11.1% > b=8.5% → 上升；差 2.6pp 锁不死；`13.2% × 2.6%/1.111 ≈ 0.3%` → 不到 1pp → C |
| 3 | 增量从高到低 | **增长量比较** | ①现期遥遥领先 → 第一；②③"现期 10 倍 vs r 1⁺ 倍" → 看现期 → ③>② → B |
| 4 | 饼图 | **饼图判读** | 29.8% / 17.7% / 52.6%；**中、小、大**；黑与白近 2 倍关系 → B |
| 5 | 能推出的有几项 | **"能否计算"判断** | 不看数值，只判"数据够不够"：①靠利润率倒推 ✓ ②靠"快 3.4 个百分点" ✓ ③靠混合增长率 ✓ → 3 项 → D |

**【第 1 题的"考场思维"（第二个方法，更快）】**
```
所求 = (东部增量) / (全国增量)
     = [24759 × 9.2%/(1+9.2%)] ÷ [31057 × 8.5%/(1+8.5%)]
```
> **两个分母 `(1+9.2%)` 和 `(1+8.5%)` 很接近 → 直接约掉**：
> ```
> 所求 ≈ (24759/31057) × (9.2%/8.5%) ≈ 0.80 × 1.08 ≈ 86%
> ```
> **这就是"两个增长率接近时，可以只比 现期 × r"的思路。**

**【第 5 题的启发】** **"能否推出"类题目，不要算，只判"条件够不够"。**
> - ①有利润率关系 → 可以倒推基期利润；
> - ②有"快 3.4 个百分点" → 可以求 16 个行业的增速 → 可以求基期；
> - ③有"总分结构 + 总量 + 一个部分" → 混合增长率可求另一个部分。

### 第四篇（综合 · 2022 国考）

| 题 | 题眼 | 考点 | 关键动作 |
|---|---|---|---|
| 1 | 第二季度除风力之外的发电量 | **结构转换 + 减法** | 二季度总 = 450.8 − 228.6 = 222.2；风电 = 50.2 − 24.2 = 26 → 196.2 < 200 → A |
| 2 | 两个增速作差 | **增长率计算** | 总 r = 12/155 ≈ 7.7%；风电 r = 4/13.4 ≈ 30% → **低 22 个百分点** → D |
| 3 | 当月增速快于累计增速 | **混合增长率转化** | 等价于"累计增速折线在上升" → 数出 7 个 → C |
| 4 | 四个季度风电由高到低 | **结构转换 + 选项排除** | 一季度 24.2、二季度 26；**只需比"二 > 一"就能排除三个选项** → B |

**【第 4 题的"用选项"示范】**
> 直接看柱状图会得到"四 > 三 > 二 > 一"——**没有这个选项**。
> 因为柱状图是**累计值**，不是单季值。
>
> 算出"一季度 24.2、二季度 26" → **二 > 一** → 四个选项里只有 B 项满足 → **一步收工**。
>
> **排序题不一定要把四项都算出来——用选项能排掉的就先排掉。**

## 六、八讲总览（一张表收束全部）

| 讲 | 主题 | 识别关键词 | 核心公式 |
|---|---|---|---|
| 1 | **速算三大件** | —— | 尾数法 / 高算低看 / 截位直除 / 分数比较 |
| 2 | **基期与现期** | 问题时间在材料**之前** | 基期 = 现期 − 增长量 = 现期 ÷ (1+r) |
| 3 | **一般增长率** | 增长 **+ %** | r = 增长量 ÷ 基期 |
| 4 | **增长量** | 增长 **+ 单位** | 现期 ÷ (n±1)（百化分） |
| 5 | **比重** | **占** | A/B；A/B×(1+b)/(1+a)；A/B×(a−b)/(1+a) |
| 6 | **平均数与倍数** | **平均每 / 倍** | 同上 + 平均数增长率 (a−b)/(1+b) |
| 7 | **特殊增长率** | 隔一年 / 年均 / 之和 | r1+r2+r1r2；比倍数；居中+偏向+线段法 |
| 8 | **综合训练** | —— | **四步法 + 肉馅思维 + 结构转换** |

**三条贯穿八讲的主线：**

> **① 一切计算的终点都是 `A/B`**
> 比重、平均数、倍数、增长率、基期——**都是两个量的除法**，区别只在"分子分母是谁、要不要修正"。
>
> **② 一切"比较"都可以不精算**
> 分数比较（一大一小 / 看倍数）、比重比较（肉馅思维）、平均增长（看倍数）、混合增长（居中 + 偏向）。
> **能判方向的，绝不精确计算。**
>
> **③ 一切"特殊"都是时间或主体被切开了**
> 间隔 = 时间跳过一年；年均 = 时间跨多年；混合 = 主体被拆成几块。
> **认清"被切在哪"，公式自然就有了。**

## 七、易错清单（考前必扫）

1. **图形、表格不用提前浏览；大段文字必须扫 20 秒**（时间、结构、主体）。
2. **"分……看"是文字材料的目录**，扫到就停一下。
3. **题干两个逗号 → 先找主体再算**（第 1 篇第 3 题）。
4. **主体、时间、指标三对得上**——最常见的错不是算错，是找错数。
5. **累计数据不是单月/单季数据**，要作差（第 4 篇第 4 题）。
6. **比较 A/(A+B) 不要真算，看 A/B**（肉馅思维）。
7. **接近 50% / 100% 的分数，比"和它的差"**，不要硬除。
8. **多数加和 → 转成平均数**，配柱形图一眼判。
9. **"当月 > 累计" ⟺ "累计折线在上升"**（混合增长率的转化）。
10. **综合题先看 C、D**（启发式，不是定理）；**遇难跳过**；**选完就走，不验证**。
11. **饼图先排"各占 1/3"的荒谬图**，再用"是否过半 / 是否过 90°"定生死。
12. **"能否推出"类题不算数，只判"条件够不够"**。
13. **排序题善用选项**：能用一个大小关系排掉三个选项的，就别算四个。
14. **两个增长率接近时，可以把 `(1+rx)` 约掉，只比 `现期 × r`**。
