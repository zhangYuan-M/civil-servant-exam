## 先看全局

### 1. 三种"特殊"，特殊在哪

| 类型 | 特殊之处 | 一句话 |
|---|---|---|
| **间隔增长率** | **时间**上隔了一年 | 2020 年比 2018 年，中间跳过 2019 年 |
| **年均增长率** | **时间**上跨了多年 | 平均每年涨多少 |
| **混合增长率** | **主体**上有和差关系 | 整体 = 部分₁ + 部分₂，求整体的增速 |

> **一个共同的收尾**：都是求增长率，所以**最后都要回到 `r = 增长量 ÷ 基期`**。
> 区别只在于：前两者是"时间被切开了"，后者是"主体被拆开了"。

### 2. 本讲地图

```
特殊增长率
├─ 一、间隔增长率（常考，套路固定）
│   ├─ 公式：r = r1 + r2 + r1×r2  （和 + 积）
│   ├─ 速算三步：先加 → 再判乘积能否忽略 → 不能就百化分
│   └─ 两个延伸：间隔倍数（+1）、间隔基期（÷(1+r)）
│
├─ 二、年均增长率（常考比较，计算几乎不考）
│   ├─ 公式：(1+r)ⁿ = 现期/基期
│   ├─ 比较：n 相同 → 直接比"现期/基期"
│   └─ 计算：居中代入（不用开方）
│
└─ 三、混合增长率（必考重点）
    ├─ 识别：求增长率 + 无法直接算 + 有和差关系
    ├─ 口诀一：混合后居中（最小 r < 总体 r < 最大 r）
    ├─ 口诀二：偏向基期量大的（用现期近似代替）
    └─ 精确：线段法（距离与量成反比）
```

## 一、间隔增长率

### 1.1 识别

> 特征：现期和基期之间，隔了一年。
> 典型问法："2020 年比 2018 年增长百分之几？"

三种常见的"隔一年"
- 问 2021 年比 2019 年（中间隔 2020）
- 问 2020 年比 2022 年（中间隔 2021）
- 材料给 2023 年，求 2021 年

> 判据只有一个：从现期数到基期，中间要跨过"一个完整年份"。

---

### 1.2 公式（"笑脸公式"）

```
r间隔 = r1 + r2 + r1 × r2
```

| 字母 | 含义 |
|---|---|
| r1 | **今年**（现期）的增长率 |
| r2 | **去年**（中间那年）的增长率 |

**【推导】**
```
2020 年 = 2019 年 × (1 + r1)
        = 2018 年 × (1 + r2) × (1 + r1)

r = (2020 − 2018) ÷ 2018
  = [(1+r2)(1+r1) − 1]
  = r1 + r2 + r1×r2
```

> **为什么叫"笑脸公式"？** 画个图：两个增长率像"眼睛"（上面），它们的乘积像"嘴巴"（下面）——**上面相加，下面相乘**。

#### ★ 最容易错的一点：r2 是**哪一年**的？

> **求"2018 年比 2016 年"，用的是 2018 年的 r 和 2017 年的 r，不用 2016 年的 r。**

**为什么？**
> 增长率是**"现期相对基期"**的比例关系。
> - 2016 年的 r（=25%）描述的是"**2016 年比 2015 年**"，基期是 2015 年；
> - 而本题的基期是 **2016 年**，跟 2015 年**毫无关系**。
>
> 所以要用 **2017 年的 r**（它正好是"2017 年比 2016 年"），把 2016 年**串起来**。

> **一句话**：**r2 是"中间那一年"的增速，不是"基期年"的增速。**

---

### 1.3 速算三步

> 这个公式里，**"和"重要，"积"次要**——因为两个百分数相乘，结果会小一个数量级（`10% × 10% = 1%`）。

```
第 1 步：先算 r1 + r2，结合选项排除
第 2 步：判断乘积能否忽略——|r1|、|r2| 都 < 10% 时，乘积 < 1%，一般可略
第 3 步：不能忽略时，挑一个百化分
```

**【练习 1】** `8.5% + 36% + 8.5%×36% ≈`
A. 47.6%　B. 40.4%

**【解】** `8.5% + 36% = 44.5%`，加上一个正数 → **必然 > 44.5%** → **选 A**
> **一步加法，连乘法都不用碰。**

**【练习 2】** `5.6% + 6.3% + 5.6%×6.3% ≈`
A. 12.26%　B. 15.87%

**【解】** `5.6% + 6.3% = 11.9%`，加一个正数 → 必然 > 11.9%。
两个都小于 10% → **乘积不到 1 个百分点** → 结果在 **12%上下** → **选 A（12.26%）**

> **乘积怎么心算？** 两个百分数相乘 = **整数部分相乘，小数点左移两位**。
> `5% × 6% = 0.3%`、`7% × 6.1% ≈ 0.42%`、`15% × 6% = 0.9%`

**【练习 3】** `12% + 25% + 12%×25% ≈`
A. 39%　B. 40%

**【解】** `12% + 25% = 37%`，两个选项都满足"大于 37%" → **必须算乘积**。
两位数乘法不好口算 → **挑一个百化分**：
```
12% × 25% = 12% × 1/4 = 3%
结果 = 37% + 3% = 40%
```
→ **选 B**

> **注意**：百化分之后**只剩一个百分号**（把 25% 变成 1/4），所以 `12% × 1/4 = 3%`，**不用再移小数点**。

### 1.4 例题

#### 例 1　【正增长·小乘积】

**【例 1】（2024 重庆选调）**
> 2021 年，全国共投入 R&D 经费 27956.3 亿元，同比增长 14.6%，**增速比上年加快 4.4 个百分点**。
> 问：2021 年，全国 R&D 经费约比 2019 年增长了：

A. 22.1%　B. 24.8%　C. 26.3%　D. 31.3%

**【解】**
```
① 求 r2：2021 年比 2020 年"加快"，说明 2020 年更慢 → 减
   r2 = 14.6% − 4.4% = 10.2%      ← 高减低加（第 3 讲）

② r间 = 14.6% + 10.2% + 14.6%×10.2%
       = 24.8% + 乘积
        ≈ 24.8% + 1.5%
        ≈ 26.3%
```
→ **选 C**

**【提醒·两步走】**

1. **先算和 = 24.8%**，正好对应 B 项——**B 就是"只算加法"的坑**；
2. 乘积 `14.6% × 10.2% ≈ 1.5%`：
   - 看到 **10%** 就敏感：`14.6% × 10% = 1.46%`，**小数点左移一位**；
   - 或把 14.6% 看成 **1/7**：`1/7 × 10.2% ≈ 1.5%`。

---

#### 例 2　【负增长·负负得正】

**【例 2】（2024 联考）**
> 2022 年，全国累计新发理财产品 2.94 万只，同比**下降 38.23%**，**降幅比上年同期扩大 7.22 个百分点**。
> 问：2022 年全国新发理财产品只数与 2020 年相比约：

A. 下降 45%　B. 下降 57%　C. 下降 66%　D. 下降 69%

**【解】**
```
① 求 r2：降幅扩大 → 对降幅用高减低加 → 去年降幅 = 38.23% − 7.22% = 31.01%
   降幅要补负号 → r2 = −31%

② r间 = (−38%) + (−31%) + (−38%)×(−31%)
       = −69% + 乘积（负负得正，是正数）
        ≈ −69% + 12%
        ≈ −57%
```
→ **选 B（下降 57%）**

**【提醒·本题三个关键点】**

1. **r2 要先对"降幅"高减低加，再补负号**（`−31%`，不是 `+31%`）；
2. **r1、r2 都带符号代入**——`−38% + (−31%) = −69%`；
3. **乘积 `(−38%)×(−31%)` 是正的**，约 `40% × 30% = 12%`。
   > <u>算法的窍门：**左边看大一点、右边看小一点**</u>，`38% × 31% ≈ 40% × 30% = 12%`。
4. **D 项（−69%）就是"只算加法"的坑**——负增长时，乘积**不能忽略**（两个都是 30%+，乘积有 12 个百分点）。

#### 练习 1　【负增长·小乘积】

**【练习 1】（2017 国考）**
> 2015 年，我国生产时钟（含钟心）5.2 亿只，同比下降 3.7%，完成产值 162 亿元，同比下降 4.7%，**降幅扩大 1.3 个百分点**。
> 问：2015 年我国钟表全行业生产时钟的产值与 2013 年相比约：

A. 上升了 11%　B. 下降了 11%　C. 上升了 8%　D. 下降了 8%

**【解】**
```
① 主体是"产值"（不是只数！）→ r1 = −4.7%
② 降幅扩大 1.3 → 去年降幅 = 4.7% − 1.3% = 3.4% → r2 = −3.4%
③ r间 = −4.7% + (−3.4%) + 乘积
      |r| 都小于 10% → 乘积 < 1%，可忽略
      ≈ −8.1%
```
→ **选 D（下降 8%）**

**【提醒】** **本题有两个坑**：
1. **主体是"产值"不是"只数"**——材料里"5.2 亿只"和"162 亿元"并列，**看清问的是哪一个**；
2. **两个数都不到 10% → 乘积可忽略**，直接加就行<u>（`−8.1%` 已经足够定答案）。</u>

### 1.5 两个延伸（同一个公式，换个收尾）

#### 延伸①：间隔倍数

> **两步走**：
> ① 先求间隔增长率
> ② **间隔倍数 = 间隔增长率 + 1**（因为"倍数 = 增长率 + 1"，第 3 讲）

**【例】** 2020 年工资同比增长 25%，2019 年同比增长 20%，2020 年是 2018 年的多少倍？
```
r间 = 25% + 20% + 25%×20% = 45% + 5% = 50%
倍数 = 50% + 1 = 1.5 倍
```

#### 延伸②：间隔基期

> **两步走**：
> ① 先求间隔增长率
> ② **间隔基期 = 现期 ÷ (1 + 间隔增长率)**（就是第 2 讲的基期公式）

**【例】** 2020 年工资 400 元，同比增长 10%，2019 年同比增长 20%，2018 年是多少元？
```
r间 = 10% + 20% + 10%×20% = 30% + 2% = 32%
2018 年 = 400 ÷ 1.32 ≈ 303 元
```

#### 例 3　【间隔基期 + 一个漂亮的心算】

**【例 3】（2024 联考）**
> 2023 年，全国软件业务收入 123258 亿元，同比增长 13.4%，**较上年同期增长 2.2 个百分点**。
> 问：2021 年，全国软件业务收入约为：

A. 不到 9 万亿元　B. 9 万亿～10 万亿元
C. 10 万亿～11 万亿元　D. 11 万亿元以上

**【解】**
```
① r1 = 13.4%；r2 = 13.4% − 2.2% = 11.2%
② r间 = 24.6% + 13.4%×11.2% ≈ 24.6% + 1.5% = 26.1%
③ 间隔基期 = 123258 ÷ 1.26 ≈ 12.33万亿 ÷ 1.26 ≈ 9.78 万亿
```
→ 9~10 万亿 → **选 B**

**【心算技巧·老师给的】**
```
12.33 ÷ 1.26，注意 1.26 很接近 1.25 = 1/8
12.33 ÷ (1/8) = 12.33 × 8 ≈ 98.6 → 有效数字以 98 开头
即 9.8 万亿
```
> **但要注意方向**：`÷1.26` 比 `÷1.25` 小一点，所以**真实值略小于 9.86** → 9.8 左右 ✓

**【提醒·这条技巧可以推广】**
> **百化分不只在"求增长量"时用，它在任何乘除法里都通用。**
> 老师举了两个例子：
> - `14311 × 787`：看到 **143** 就想到 **1/7** → `1/7 × 787 = 112⁺` → 结果以 **112** 开头；
> - `345 ÷ 1.43`：看到 **143** 想到 **1/7** → `345 ÷ (1/7) = 345 × 7 = 2415` → 结果 **2000 多**。
>
> **看到熟悉的数字就条件反射地换成分数**——这是资料分析里最通用的一招。

易错点

+ 算法的窍门：左边看大一点、右边看小一点，`38% × 31% ≈ 40% × 30% = 12%`
+ "积"次要——因为两个百分数相乘，结果会小一个数量级（`10% × 10% = 1%`）
+ 看到熟悉的数字就条件反射地换成分数——这是资料分析里最通用的一招
  + 1/6=16.7%
  + 1/7=14.3%
  + 1/8=12.5%
  + 1/9=11.1%
  + 1/11=9.1%
  + 1/12=8.3%
  + 1/14=7.1%
  + 1/18=5.6%
  + 1/19=5.3%

> **识别**：中间隔一年
> **公式**：`r = r1 + r2 + r1×r2`（r2 是**中间那一年**的增速）
> **速算**：先加 → 双小于 10% 则乘积可略 → 否则百化分
> **两个延伸**：倍数 `+1`、基期 `÷(1+r)`

## 二、年均增长率

### 2.1 公式与 n 的确定

```
(1 + r年均)ⁿ = 现期量 ÷ 基期量
```

> **n = 年份差**（和"年均增长量"完全一样）。

**【为什么要用"幂"，不能用算数平均？】**
> 老师用复利解释：
> - **单利**：100 万，每年利息 10 万，存 3 年利息 30 万——**每年基数不变**；
> - **复利**：100 万，第 2 年是 `100×1.1`，第 3 年是 `100×1.1²`，第 4 年是 `100×1.1³`——**每年基数都在变**。
>
> **增长率是"比例关系"，每年基数不同，所以不能算算数平均。**
> "今年涨 10%、去年涨 20%，所以平均每年涨 15%"——**这是错的**。

#### n 的三种确定方式（同第 4 讲，再确认一遍）

| 情形 | 年份差 | 基期 |
|---|---|---|
| 一般情况（除江苏外） | `末年 − 首年` | 首年本身 |
| 五年规划 | **5** | 首年**往前推一年** |
| 江苏省考 | `末年 − 首年 + 1` | 首年**往前推一年** |

> 如 2018～2022 年：一般情况 n = 4（基期 2018）；江苏 n = 5（基期 2017）。
> "十三五"：n = 5，基期 2015。

---

### 2.2 比较（本考点的重点）

> **识别：年均增长最快 / 年均增速排序 / 年均增长率最高**

```
(1 + r)ⁿ = 现期/基期
```

> **当 n 相同时，直接比 `现期/基期`——倍数越大，年均增速越大。**
> **不需要开方，也不需要算 r。**

---

#### 例 1　【判断题：谁的年均增速快】

**【例 1】（2025 山东）**
> 判断："2019—2023 年，全国快递业务量年均增长率高于山东省内快递业务量"这一说法是否正确。（全国：2019 年 635 亿件、2023 年 1320 亿件；山东：2019 年 28.9 亿件、2023 年 70.7 亿件）

A. 正确　B. 错误

**【解】** n 相同（都是 4 年），**直接比倍数**：
```
全国：1320 ÷ 635 ≈ 2.08 倍
山东：70.7 ÷ 28.9 ≈ 2.45 倍      ← 28×2=56，28×3=84，明显过 2 倍
```
→ 山东的倍数**更大** → 山东年均增速更快 → "全国高于山东"**错误** → **选 B**

**【提醒·一个漂亮的比较法】**
> 判断 `70.7/28.9` 和 `1320/635` 谁大，不用真除：
> - `28.9 × 2 = 57.8 < 70.7` → 山东**超过 2 倍**；
> - `635 × 2 = 1270 < 1320` → 全国**刚过 2 倍**。
>
> **两边都用"2 倍"当基准，谁超出得多，谁的倍数大**——这比算两个商快得多。

#### 例 2　【排序：先定首尾，再比中间】

**【例 2】（2023 国考）**
> 将①甘肃、②广东、③上海、④浙江按 2016—2021 年集成电路产量年均增速（以 2016 年为基期）从高到低排列。

（甘肃 643/197；广东 539/219；上海 365/238；浙江 230/74）

A. ④①②③　B. ④①③②　C. ①④②③　D. ①④③②

**【解】** 分别看倍数：
```
甘肃：643 ÷ 197 ≈ 3.26
广东：539 ÷ 219 ≈ 2.46
上海：365 ÷ 238 ≈ 1.53
浙江：230 ÷ 74  ≈ 3.11
```
**先定首尾**：广东、上海明显最小（2 倍出头、1 倍多）→ **末两位是 ②③** → 排除 B、D。
**再比甘肃、浙江**：
```
甘肃 643/197 ≈ 643/200 = 3.2⁺
浙江 230/74  ≈ 3.11
```
→ 甘肃 > 浙江 → **① > ④** → **选 C（①④②③）**

**【提醒】** **当分母是"好算的数"时，直接除更快**：
> `197 → 200`（估大分母，结果偏小，实际 `3.2⁺`）；`230/74` 约 `3.11`。**两个都在 3.1~3.3，必须实算。**
>
> **排序题的老规矩：先定首尾（这题一步就排掉了 B、D），再纠结中间。**

#### 练习 2　【三类对比】

**【练习 2】（2024 联考）**
> 判断："2019-2022 年，中国储能锂电池出货量年均增速为 3 类锂电池中最快"这一说法是否正确。（储能 130/9.5；数码 48/36；动力 480/71）

A. 正确　B. 错误

**【解】** 基期 2019、现期 2022，n 相同 → 比倍数：
```
储能：130 ÷ 9.5 ≈ 13.7 倍
数码：48 ÷ 36  ≈ 1.3 倍
动力：480 ÷ 71 ≈ 6.8 倍
```
→ 储能 **13.7 倍**，遥遥领先 → 说法**正确** → **选 A**

**【提醒】** 又是那句话：**不能看斜率，只能看 `现期/基期` 的倍数**。
> 储能 13.7 倍、动力 6.8 倍——**差了整整一倍**，一眼就能定。

#### 练习 3　【四选一：找最快】

**【练习 3】（2026 上海）**
> 2021～2024 年期间，下列各项指标中，年均增长速度最快的是：

A. 传统通用航空企业数量（760/599）
B. 通用航空在册航空器总数（3232/3018）
C. 无人机运营企业数量（19979/12663）
D. 全行业注册无人机总数（217.7/83.2）

**【解】** 比倍数：
```
A：760/599  ≈ 1.27
B：3232/3018 ≈ 1.07   ← 最小
C：19979/12663 ≈ 1.58
D：217.7/83.2 ≈ 2.62   ← 最大
```
→ **选 D**

**【提醒】** **B 项的倍数只有 1.07，几乎没动**——这种"看着数字很大（3232）"的选项最容易骗人。
> 老师顺势补了一句：**"若问增长最慢的，答案就是 B。"**
> 同一组数据，正着问、反着问都要会——**考场上换一个字就是另一道题。**

### 2.3 计算（考得非常少）

> **考情**：国考**从未**考过年均增长率的计算；省联考近十年只考过 2 题。
> 讲义选的是广东真题（广东省考、深圳市考常考，但**广东的数资很简单**）。
> **知道方法即可，不用花太多时间。**

#### 方法：居中代入（不用开方）

```
先算 现期/基期 = X
再挑选项里"居中"的一个值 r，验证 (1+r)ⁿ 与 X 的大小
偏大 → r 取小；偏小 → r 取大
```

**【常用平方值，背下来】**

| (1+r)² | 值 |
|---|---|
| 1.1² | 1.21 |
| 1.2² | **1.44** |
| 1.3² | **1.69** |
| 1.4² | 1.96 |
| 1.5² | 2.25 |

> **(1+r)⁴ = [(1+r)²]²**——遇到四次方就拆成平方的平方。
> 如 `1.2⁴ = 1.44² ≈ 2.07`、`1.2³ = 1.44 × 1.2 = 1.73`。

---

#### 例 3　【居中代入】

**【例 3】（2025 广东）**
> 2021～2023 年，国家铁路旅客周转量年均增长率：（2021 年 9559 亿人公里，2023 年 14717 亿人公里）

A. 不到 15%　B. 在 15% 到 30% 之间
C. 在 30% 到 45% 之间　D. 超过 45%

**【解】** n = 2023 − 2021 = 2：
```
(1+r)² = 14717 ÷ 9559 ≈ 1.54
```

**方法一：查平方表**
```
1.2² = 1.44，1.3² = 1.69
1.44 < 1.54 < 1.69 → 20% < r < 30%
```
→ **选 B**

**方法二：居中代入**
```
代 30%：1.3² = 1.69 > 1.54 → r < 30% → 排除 C、D
代 20%：1.2² = 1.44 < 1.54 → r > 20% → 排除 A
```
→ **选 B**

**【提醒】** **方法一比方法二更快**——把 `1.1²~1.5²` 这五个数背下来，**连代入都省了**。

#### 练习 4　【同型】

**【练习 4】（2024 广东）**
> 2019～2021 年，全国县域农业农村信息化建设县均社会资本投入的年均增长率约为：（2019 年 2054，2021 年 3588）

A. 10%　B. 21%　C. 32%　D. 43%

**【解】**
```
(1+r)² = 3588 ÷ 2054 ≈ 1.75
1.3² = 1.69 < 1.75 < 1.96 = 1.4²
```
→ 30% < r < 40% → **选 C（32%）**

**【精确一点】** `1.32² = 1.7424`，比 1.75 略小 → r 略大于 32% → 仍是 C ✓

**【提醒·一个必须警惕的近似】**
> `1 + nr` 这个近似**限制很大**：本题总增长率约 75%，若用 `75%/2 = 37.5%`，比真值 32% **差了 5 个百分点**。
> **只有当年均增长率在 10% 以内时，`1+nr` 才可靠**（第 4 讲也提过）。
> **这题用近似会误选 D 的方向——所以必须用平方表。**

## 三、混合增长率（本讲重点）

### 3.1 识别：两个条件同时满足

> **① 求增长率，但数据无法直接计算**
> **② 主体之间有"和差关系"**

**【例】** 已知前三季度增长率、四季度增长率，求全年增长率——**没有全年数据，无法直接算**，但 `全年 = 前三季度 + 四季度`。

#### 三类最常见的和差关系

| 类型 | 例子 |
|---|---|
| **固定搭配** | 进口 + 出口 = 进出口；城镇 + 乡村 = 全国；房产 + 地产 = 房地产 |
| **时间累计** | 1～11 月 + 12 月 = 全年；一季度 + 二季度 = 上半年；1～2 月 + 3 月 = 1～3 月 |
| **逻辑型**（关键词是"**非**"） | A + 非A = 全部：实物 + 非实物 = 所有商品；规模以上 + 规模以下 = 全部；上市 + 非上市 = 全部 |

> **识别口诀**：**看到"非""以外""之外"，就是逻辑型混合。**

---

### 3.2 口诀一：混合后居中

```
最小 r  <  总体 r  <  最大 r
```

**【为什么？】**
> 男生的平均身高 180，女生的平均身高 170，全班平均身高**不可能**是 350。
> 它一定**在 170 和 180 之间**——这就是"混合"的本质。
>
> 思考：两个部分混合在一起（男生加女生）；首先女生平均身高170，当男生趋于无穷大，平均身高趋近180；当男生趋于0，平均身高趋于170

#### 两个补例（把方向练熟）

**【补例 1】** 2019 年进口增长 10%，出口增长 20%，进出口可能增长了多少？
A. 8%　B. 9%　C. 14%　D. 21%

**【解】** `进出口 = 进口 + 出口`，总体居中 → 在 10%~20% 之间 → **选 C（14%）**

**【补例 2】** 2019 年**进出口**增长 10%，**出口**增长 20%，**进口**可能增长了多少？
A. 8%　B. 12%　C. 14%　D. 21%

**【解】** 进出口是"整体"，10% 居中 → `r进口 < 10% < r出口 = 20%` → 进口 **小于 10%** → **选 A（8%）**

> **注意这两题的区别**：补例 1 是"已知两个部分，求整体"；补例 2 是"已知整体和一个部分，求另一个部分"。
> **方向正好相反——这是本考法最容易做反的地方。**

---

### 3.3 口诀二：偏向基期量大的

```
总体 r 会靠近"基期量更大"的那一方的 r
```

**【用溶液理解】**
```
100g 的 5% 溶液 + 100g 的 10% 溶液 → 混出来正好 7.5%（等量，取中点）
100g 的 5% 溶液 + 400g 的 10% 溶液 → 混出来靠近 10%（10% 的量多）→ 介于 7.5%~10%
```

**【用天平理解】**
> 两边一样重 → 平衡（居中）；右边重 → 往右倾斜（靠近右边）。

#### ★ 一个必须知道的修正

> **"量"严格来说是"基期量"，不是"现期量"。**
> 但**算基期太麻烦**，所以**一般用现期量近似代替**。
>
> **浓度和增长率并非同一个概念，但它们是同一种数学结构**：溶液法只是同一套加权平均定理的两个“实例”，由于结构相同，所以可以借用；
>
> 总体增长率在数学上是各部分的增长率按**基期量**加权。所以口诀中的“量”必须写成“基期量”，否则公式本身不成立；“用现期量近似”只是速度上的妥协，并非等价替换。
>
> **例外**：当两个增长率**差距极大**（比如一个是 +15%、一个是 −50%）时，**现期和基期的大小关系会反转**，这时必须看基期。
>
> 平均数：能代表整体平均情况的一个数

### 3.4 例题

#### 例 1　【时间累计型·判断】

**【例 1】（2024 国考）**

> 2023 年 3 月，我国机器人设备进口金额 2.4 亿美元，较上年增长 68.5%；1—3 月累计进口 6.9 亿美元，较上年增长 55.1%。
> 判断："2023 年 3 月，我国机器人设备进口金额同比增速快于 1～2 月同比增速"这一说法是否正确。

A. 正确　B. 错误

**【解】**
```
1～3 月 = 1～2 月 + 3 月
混合后居中：r(1~2月) < r(1~3月) = 55.1% < r(3月) = 68.5%
```
→ 3 月（68.5%）确实**快于** 1～2 月 → 说法**正确** → **选 A**

**【提醒·理解这个"拉扯"】**
> 3 月涨得快（68.5%），把 1～3 月拉到了 55.1%。
> **如果 1～2 月也涨 70%，那 1～3 月不可能是 55.1%**——所以 1～2 月一定**低于** 55.1%，也就更低于 68.5%。
>
> **一句话：混合值被"快"的那一方拉住，说明另一方更慢。**

---

#### 例 2　【时间累计型·求范围】

**【例 2】（2022 四川）**
> 2019 年 1～2 月，我国包裹寄递量比去年同期：（材料给一季度 −12.3%、3 月 −10.8%）

A. 下降了不到 10%　B. 下降了 10% 以上
C. 上升了不到 10%　D. 上升了 10% 以上

**【解】**
```
一季度 = 1～2 月 + 3 月
混合后居中：r(1~2月) < r(一季度) = −12.3% < r(3月) = −10.8%
```
→ 1～2 月的增速**比 −12.3% 更负** → 下降**超过 12.3%** → 下降 10% 以上 → **选 B**

**【提醒】** **负数比较是本题的坎**：
> `−12.3%` 和 `−10.8%`，**"负得越少，值越大"** → `−10.8% > −12.3%`。
> 所以三元排序是：`r(1~2月) < −12.3% < −10.8%`。
>
> **先排除 C、D**（求出来是负数，说明在下降），**再判"降了多少"**——超过 10%，选 B。

---

#### 例 3　【两个部分求整体·判范围】

**【例 3】（2025 江苏）**
> 2023 年，M 市东北片区接待过夜游客 1125 万人次，增长 38.2%；东南片区接待过夜游客 739 万人次，增长 70.1%。
> 判断："2023 年 M 市东北和东南片区接待过夜游客人次之和的增速不超过 54.2%"这一说法是否正确。

A. 正确　B. 错误

**【解】**
```
① 居中：38.2% < 总体 r < 70.1%
② 中点 = (38.2% + 70.1%) ÷ 2 = 54.15% ≈ 54.2%    ← 题目给的分界线正好是中点！
③ 偏向：东北 1125 万 > 东南 739 万 → 偏向量大的 → 靠近 38.2%
```
→ 总体 r **介于 38.2% 和 54.15% 之间** → **不超过 54.2%** → 说法**正确** → **选 A**

可以直接看现期量的原因：

|      | 现期       | 增速        | 谁基期大 |
| ---- | ---------- | ----------- | -------- |
| 东北 | 1125（大） | 38.2%（慢） | 基期大   |
| 东南 | 739（小）  | 70.1%（快） | 基期小   |

如果反过来，增速快的一方现期量也大，那么基期谁大就得先算一算（基期 = 现期 ÷ (1+增速)），不能直接看现期量。

**【提醒】** **这道题的设计很精妙**：

> 它把"中点 54.2%"直接放进了题干。**只要你能算出中点是 54.2%，就能立刻判断**——因为"偏向大的一方"意味着**一定小于中点**。
>
> **遇到"不超过/超过 X%"这种判断题，先算中点**：如果 X 就是中点，那答案就取决于"谁量大"。
>
> **能直接看现期量，关键在于这道题里“慢的一方现期更大”保证了基期大小关系不会翻转，并非因为现期量可以普遍代替基期量。**

#### 例 4　【贸易逆差·整体是"进口"】

**【例 4】（2024 国考）**
> 2023 年 3 月，我国机器人设备出口金额 0.7 亿美元，增长 110.3%；进口金额 2.4 亿美元，增长 68.5%。1～3 月：出口 1.9 亿美元、增长 62.1%；进口 6.9 亿美元、增长 55.1%。
> 问：2023 年一季度，我国机器人设备进出口贸易**逆差**比上年同期：

A. 下降了不到 30%　B. 下降了 30% 以上
C. 上升了不到 30%　D. 上升了 30% 以上

**【解】**
```
① 逆差 = 进口 − 出口  →  逆差 + 出口 = 进口
   所以"进口"是整体，"逆差"和"出口"是部分

② 居中：r逆差 < r进口 = 55.1% < r出口 = 62.1%
   → 逆差增速**小于 55.1%**

③ 偏向：逆差 = 6.9 − 1.9 = 5 亿；出口 = 1.9 亿
   → 逆差量更大 → 55.1% 更靠近逆差
   → 逆差增速与 55.1% 的距离 < 出口与 55.1% 的距离 = 7 个百分点
   → 逆差增速 > 55.1% − 7% = 48.1%
```
→ 逆差增速在 **48.1% ~ 55.1%** 之间 → **上升 30% 以上** → **选 D**

**【提醒·两个关键】**

1. **"逆差 = 进口 − 出口"要能立刻转成"逆差 + 出口 = 进口"**，这样才知道谁是"整体"；
   顺差反过来：`顺差 = 出口 − 进口`，`顺差 + 进口 = 出口`。
2. **第一步"居中"只能给出一个上界（< 55.1%），锁不死答案**——必须用"偏向"再压一次，得到下界 48.1%。
3. 它的增速算出来约 48%~55%，是正数，说明这个量比去年更大，所以是“上升”

   > **两个方向一夹，答案就锁定了。**

#### 练习 5　【"非"字型·范围判断】

**【练习 5】（2022 山东）**
> 2018 年，我国规模以上港口完成货物吞吐量 133 亿吨，同比增长 2.7%，其中外贸货物吞吐量 42 亿吨，同比增长 2.0%。
> 问：2018 年我国规模以上港口完成**非外贸**货物吞吐量同比增速：

A. 低于 1.5%　B. 在 1.5%～2.5% 之间
C. 在 2.5%～3.5% 之间　D. 高于 3.5%

**【解】**
```
① 货物吞吐量 = 外贸 + 非外贸  → 2.7% 是整体
② 居中：r外贸 = 2.0% < 2.7% < r非外贸
   → 排除 A、B（要求 > 2.7%）
③ 偏向：非外贸 = 133 − 42 = 91 亿吨 > 外贸 42 亿吨
   → 偏向量大的 → 2.7% 离非外贸更近
   → 非外贸与 2.7% 的距离 < 0.7（= 2.7 − 2.0）
   → 非外贸 < 2.7% + 0.7% = 3.4%
```
→ 落在 2.5%~3.5% → **选 C**

**【精确验证】** `42×2.0 + 91×x = 133×2.7` → `91x = 275.1` → `x ≈ 3.02%` ✓ C

#### 例 5　【线段法的入门：量之比 = 距离反比】

**【例 5】（2021 山东）**
> 2019 年 1～11 月，A 地区社会消费品零售总额同比增长 6.3%；1～12 月同比增长 6.7%。
> 问：2019 年 12 月，A 地区社会消费品零售总额同比增速约为：

A. 3%　B. 6%　C. 10%　D. 15%

**【解】**
```
① 居中：6.3% < 6.7% < r(12月)  → 排除 A、B
② 偏向：1～11 月的量远大于 12 月 → 6.7% 更靠近 1～11 月的 6.3%
   → C（10%）和 D（15%）都满足"比 6.7% 大"，需要**线段法**
```
**线段法：**
```
量：12 月 = 6500⁺ − 5900⁺ ≈ 600⁺；1～11 月 ≈ 5900⁺
量之比 ≈ 600 : 5900 ≈ 1 : 10
距离之比 = 量的反比 = 1 : 10
1 份 = 6.7% − 6.3% = 0.4%
10 份 = 4% → r(12月) ≈ 6.7% + 4% = 10.7%
```
→ 且**量之比不到 10:1**，所以右边距离**不到 4%** → 结果**不到 10.7%** → **选 C（10%）**

**【提醒】** 这题是"从口诀到线段法"的过渡：**口诀只能排除 A、B，剩下两个必须算。**

#### 例 6　【线段法 + 一个常识兜底】

**【例 6】（2021 联考）**
> 2020 年，东部地区互联网业务收入 11227 亿元，同比增长 14.8%。收入居前 5 名的广东、北京、上海、浙江、江苏共完成 10706 亿元，同比增长 15.1%。
> 问：2020 年，东部地区除这五个省市之外的省市互联网业务收入约比 2019 年：

A. 增长 9%　B. 增长 19%　C. 减少 9%　D. 减少 19%

**【解】**
```
① 东部 = 前5名 + 非前5名
② 居中：r非前5 < 14.8% < 15.1%   → 排除 B（19%）
```
**线段法：**
```
量：前5名 = 10706；非前5名 = 11227 − 10706 = 521 ≈ 500
量之比 ≈ 500 : 10706 ≈ 1 : 21
距离之比 = 21 : 1
1 份 = 15.1% − 14.8% = 0.3 个百分点
21 份 = 6.3 个百分点
r非前5 = 14.8% − 6.3% = 8.5%
```
→ **选 A（增长 9%）**

**【方法二·常识兜底】**
> 2020 年正是互联网蓬勃发展的时候，增长率**应该是正的** → 选 A。
> **在 A、C 之间（+9% 和 −9%），常识就能定。**

**【提醒】** **本题还有一个"地理常识"的坑**：
> 有人觉得"北京在北方，怎么算东部？"
> **资料分析的地区分类是经济区划，不是地理方位**：东部包括京、沪、苏、浙、粤等；东北是辽宁、吉林、黑龙江；西部是陕、藏等。
> **不用背，看材料给什么就是什么。**

### 3.5 线段法（混合增长率的精确算法）

> **什么时候用？** 口诀"居中 + 偏向"能解决 **90% 以上**的题；**锁不死答案时**才用线段法。

#### 两句口诀

```
① 部分在两边，总体在中间
② 距离和量成反比
```

#### 原理（3 分钟证明，看懂了更稳）

```
溶质守恒：A × a% + B × b% = (A + B) × x%     （a < x < b）

化简：A(a − x) + B(b − x) = 0
     B(b − x) = A(x − a)
     A/B = (b − x)/(x − a)

左边是"量之比"，右边是"距离之比"→ 距离与量成反比 ✓
```

#### 操作步骤（画一条线段）

```
        率写上面        距离
   a% —————— x% —————— b%
   A ——————— 混合 ————— B
        量写下面
```

> **四个数：两个率、两个量。已知三个，求第四个。**

#### 两个示范

**示范 1**：全年消费 4000 元、增长 5%；上半年 1000 元、增长 2%。求下半年增速。
```
量：上半年 1000，下半年 4000 − 1000 = 3000 → 量比 1 : 3
距离比 = 3 : 1
3 份 = 5% − 2% = 3% → 1 份 = 1%
下半年 = 5% + 1% = 6%
```

**示范 2**：上半年收入 5 万元、增长 12%；1～5 月 4 万元、增长 10%。求 6 月增速。
```
量：1～5 月 4 万，6 月 = 5 − 4 = 1 万 → 量比 4 : 1
距离比 = 1 : 4
1 份 = 12% − 10% = 2%
6 月 = 12% + 2%×4 = 20%
```

> **注意方向**：**谁量大，总体就靠近谁**——所以"距离比"里，**量大的一方距离小**。

### 混合增长率小结 📌

易错点

+ 进出口贸易
  + 逆差 = 进口 − 出口；顺差 = 出口 − 进口
+ 偏向
  + 如果反过来，增速快的一方现期量也大，那么基期谁大就得先算一算（基期 = 现期 ÷ (1+增速)），不能直接看现期量。
  + 当两个增长率差距极大（比如一个是 +15%、一个是 −50%）时，现期和基期的大小关系会反转，这时必须看基期。
  + 它的增速算出来约 48%~55%，是正数，说明这个量比去年更大，所以是“上升”

**识别**：求增长率 + 算不了 + 有和差关系（固定搭配 / 时间累计 / "非"字逻辑型）

| 步骤 | 工具                             | 能解决       |
| ---- | -------------------------------- | ------------ |
| ①    | **混合后居中**                   | 排掉一半选项 |
| ②    | **偏向基期量大的**（用现期代替） | 再排掉一部分 |
| ③    | **线段法**（距离与量成反比）     | 精确锁定     |

口诀**：**部分在两边，总体在中间；距离和量成反比。

## 四、本讲方法总表 📌

| 类型 | 识别 | 公式 / 方法 | 关键点 |
|---|---|---|---|
| **间隔增长率** | 中间隔一年 | `r = r1 + r2 + r1×r2` | **r2 是中间那一年**，不是基期年 |
| **间隔倍数** | 隔一年 + 求倍数 | 先求 r间，**+1** | 倍数 = r + 1 |
| **间隔基期** | 隔一年 + 求基期 | 先求 r间，**÷(1+r间)** | 同基期公式 |
| **年均增长率·比较** | 年均最快 / 排序 | 比 `现期/基期`（n 相同） | **不能看斜率** |
| **年均增长率·计算** | 年均增长率为…… | `(1+r)ⁿ = 现期/基期` | **居中代入**，背平方表 |
| **混合·居中** | 和差关系 | 最小 r < 总体 r < 最大 r | 先排一半 |
| **混合·偏向** | 同上 | 靠近基期量大的 | 一般用现期代替 |
| **混合·线段法** | 锁不死了 | 距离与量成反比 | 部分在两边，总体在中间 |

**常用平方表（年均增长率计算必背）**

| (1+r)² | 1.21 | 1.44 | 1.69 | 1.96 | 2.25 |
|---|---|---|---|---|---|
| **r** | 10% | 20% | 30% | 40% | 50% |

## 五、易错清单 📌

1. **间隔增长率的 r2 用错了年份**——要用"中间那年"的增速，不是"基期年"的。
2. **乘积能不能忽略**：`|r1|、|r2|` 都 < 10% 才可略；**有一个超过 10%，乘积就可能有几个百分点**。
3. **负增长时乘积是正的**（负负得正），别顺手写成负的。
4. **"只算加法"是最常见的坑**——很多题目的错误选项就是 `r1 + r2`。
5. **r2 求法**：看到"加快/回落/扩大/收窄"要先用**高减低加**（第 3 讲）。
6. **降幅求增长率要补负号**。
7. **间隔倍数记得 +1**、**间隔基期记得 ÷(1+r)**——别算完 r 就交卷。
8. **年均增速比较不能看斜率**，只能看 `现期/基期` 的倍数。
9. **年均增长率的 n 是"年份差"**，五年规划要前推一年。
10. **`1+nr` 近似只在 r < 10% 时可靠**——本题用它会差 5 个百分点。
11. **混合增长率先找"谁是整体"**：`逆差 + 出口 = 进口`（进口才是整体）。
12. **"已知整体和一个部分求另一个"时方向是反的**——部分一定在整体的**另一侧**。
13. **负数比较"负得越少值越大"**，别把 `−12.3%` 当成比 `−10.8%` 大。
14. **"量"严格来说是基期量**，一般用现期代替可以；但**两个增长率差距极大时会反转**。
