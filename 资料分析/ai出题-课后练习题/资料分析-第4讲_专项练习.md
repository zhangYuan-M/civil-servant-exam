### A 组　现期基期 · 直接减

#### 第 1 题　【尾数法】

**【题目】**
【材料】2024 年某市一般公共预算支出 864375 万元，2023 年为 812486 万元。
2024 年该市一般公共预算支出同比增加多少万元？
A. 51889　B. 51890　C. 51891　D. 51892

**【解】** 增长 + 单位（万元）→ 求增长量：
```
增长量 = 864375 − 812486
尾数：5 − 6 = −1 → 尾 9
```
四个选项末位分别是 9、0、1、2，**只有 A 是 9** → **选 A**

**【验证】** `864375 − 812486 = 51889` ✓

**【提醒】** 四个选项连号（51889~51892），**这就是典型的尾数法结构**——出题人把"末位"做成了唯一的区分点。
> **不要去列竖式**，5 秒能出答案的题，别做成 30 秒。

#### 第 2 题　【配对作差】

**【题目】**
【材料】2024 年上半年某市接待游客（万人次）：
一季度：1286、1342、1475；二季度：1568、1623、1704。
2024 年二季度该市接待游客比一季度多多少万人次？
A. 682　B. 742　C. 792　D. 852

**【解】**
```
所求 = (1568 + 1623 + 1704) − (1286 + 1342 + 1475)
```

**方法一：配对作差（推荐）**
```
1568 − 1286 = 282
1623 − 1342 = 281
1704 − 1475 = 229
合计 = 282 + 281 + 229 = 792
```
→ **选 C**

**方法二：先各自加总再相减**
```
二季度 = 4895；一季度 = 4103
4895 − 4103 = 792
```

**【提醒】** 两种方法都对，但**配对作差明显更快**：三个两位数相加，比两个四位数相减省一半脑力。
> 这类"两段比大小"的题，**先配对再算**是标准动作。

#### 第 3 题　【百分点作差·数个数】

**【题目】**
【材料】2024 年某市六个行业数字化率（%）：

| 行业 | 2024 年 | 2023 年 |
|---|---|---|
| 甲 | 42.6 | 38.4 |
| 乙 | 51.2 | 46.8 |
| 丙 | 38.9 | 36.1 |
| 丁 | 63.4 | 58.2 |
| 戊 | 47.5 | 44.3 |
| 己 | 55.1 | 52.9 |

2024 年这六个行业中，数字化率同比提高**超过 4 个百分点**的有几个？
A. 2　B. 3　C. 4　D. 5

**【解】** "率"的增量，单位是**百分点**，直接作差：

| 行业 | 差值 | 是否 > 4 |
|---|---|---|
| 甲 | 42.6 − 38.4 = **4.2** | **✓** |
| 乙 | 51.2 − 46.8 = **4.4** | **✓** |
| 丙 | 38.9 − 36.1 = 2.8 | ✗ |
| 丁 | 63.4 − 58.2 = **5.2** | **✓** |
| 戊 | 47.5 − 44.3 = 3.2 | ✗ |
| 己 | 55.1 − 52.9 = 2.2 | ✗ |

→ **3 个** → **选 B**

**【提醒】** 两个易错点：
1. **单位是"百分点"**，不是 "%"；
2. **"超过 4"是严格大于**——甲（4.2）、乙（4.4）都是险胜，但都算数；**丙（2.8）差得远，别因为"看起来差不多"就算进去**。

### B 组　年均增长量

#### 第 4 题　【年均增长量·常规】

**【题目】**
【材料】2019 年某市博物馆接待观众 682 万人次，2023 年为 856 万人次。
2019～2023 年，该市博物馆接待观众年均增长约多少万人次？
A. 28.6　B. 34.8　C. 39.2　D. 43.5

**【解】** 年均增长 + 单位 → 年均增长量；常规情况：
```
年份差 = 2023 − 2019 = 4
年均增长量 = (856 − 682) ÷ 4 = 174 ÷ 4 = 43.5
```
→ **选 D**

**【提醒】** **分母是 4，不是 5。** 2019→2020、2020→2021、2021→2022、2022→2023，**一共长了 4 次**。
> A（28.6）是 `174 ÷ 6` 之类凑出来的；C（39.2）接近 `174 ÷ 4.4`——**分母错一步，答案就偏一大截**。

#### 第 5 题　【年均增长量·五年规划】

**【题目】**
【材料】"十三五"时期（2016～2020 年），某市快递业务量由 2015 年的 12.6 亿件增长到 2020 年的 28.5 亿件。
"十三五"时期，该市快递业务量年均增长约多少亿件？
A. 3.18　B. 3.52　C. 3.86　D. 4.20

**【解】** "十三五"→ **基期往前推一年 = 2015 年**，年份差 **5**：
```
年均增长量 = (28.5 − 12.6) ÷ 5 = 15.9 ÷ 5 = 3.18
```
→ **选 A**

**【提醒】** 这题材料**特意把 2015 年的数据也给了**——如果按"常规情况"用 2016 年做基期，反而找不到数据。
> **"十三五" = (2020 − 2015) ÷ 5**，这个式子要能条件反射地写出来。

#### * 第 6 题　【年均增长量·题干已注明基期】

**【题目】**
【材料】以 2018 年为基期，某市 2018 年粮食产量 48.6 万吨，2023 年为 62.4 万吨。
2018～2023 年，该市粮食产量年均增长约多少万吨？
A. 1.84　B. 2.30　C. 2.76　D. 3.45

**【解】** 题干已注明"以 2018 年为基期" → 基期 2018，年份差 `2023 − 2018 = 5`：
```
年均增长量 = (62.4 − 48.6) ÷ 5 = 13.8 ÷ 5 = 2.76
```
→ **选 C**

**【提醒】** 注意这题和第 4 题的区别：**2018～2023 跨了 5 年，所以除以 5**。
> "2018～2023"看着像 6 个年份，但**增长的次数是 5**。
> 记住一句话：**年份差 = 末年 − 首年**，别数"有几个数"。

#### 第 7 题　【两年均增长量相减】

**【题目】**
【材料】2019～2023 年，甲市地区生产总值由 8620 亿元增至 11480 亿元；乙市由 5430 亿元增至 7860 亿元。
2019～2023 年，甲市地区生产总值年均增长量比乙市约多多少亿元？
A. 95.2　B. 107.5　C. 124.0　D. 148.6

**【解】** 分别求年均增长量，再作差：
```
甲：(11480 − 8620) ÷ 4 = 2860 ÷ 4 = 715
乙：(7860 − 5430) ÷ 4 = 2430 ÷ 4 = 607.5
差 = 715 − 607.5 = 107.5
```
→ **选 B**

**【简便算法】** 两个分母都是 4，可以**先作差再除以 4**：
```
(2860 − 2430) ÷ 4 = 430 ÷ 4 = 107.5
```
> **同分母时，先减后除永远更快**——而且只算一次除法。

### C 组　百化分求增长量

#### 第 8 题　【10% → n = 10】

**【题目】**
【材料】2024 年某市规模以上工业用水量 386.4 万吨，同比增长 10%。
2024 年该市规模以上工业用水量同比增加约多少万吨？
A. 26.4　B. 29.8　C. 32.1　D. 35.1

**【解】**
```
10% = 1/10 → n = 10
增长量 = 386.4 ÷ (10 + 1) = 386.4 ÷ 11 ≈ 35.1
```
→ **选 D**

**【提醒】** 选项设计：
- C（32.1）≈ `386.4 ÷ 12`，用错 n；
- B（29.8）≈ 把 10% 当 1/8 之类；
- **只有 n+1 = 11 才落在 35.1。**

#### * 第 9 题　【12.5% → n = 8】

**【题目】**
【材料】2024 年某市农村电商销售额 528 亿元，同比增长 12.5%。
2024 年该市农村电商销售额同比增加约多少亿元？
A. 58.7　B. 63.2　C. 68.4　D. 74.6

**【解】**
```
12.5% = 1/8 → n = 8
增长量 = 528 ÷ (8 + 1) = 528 ÷ 9 ≈ 58.7
```
→ **选 A**

**【提醒】** 12.5% 是**百化分表里最重要的一个**（因为 1/8 好算，而且 12.5% 在材料里出现频率极高）。
> 它的变形 **1.25% = 1/80** 也要会——用倍数法：`1.25% = 12.5% ÷ 10 = (1/8) ÷ 10`。

#### 第 10 题　【取中法：18.6% ≈ 1/5.5】

**【题目】**
【材料】截至 2024 年末，某市有效发明专利 8.64 万件，同比增长 18.6%。
2024 年该市有效发明专利同比约增加多少万件？
A. 1.05　B. 1.18　C. 1.33　D. 1.62

**【解】** 18.6% 不是现成的 1/n，夹在两个熟数之间：
```
1/6 ≈ 16.7%  <  18.6%  <  20% = 1/5
```
**取中**：`18.6% ≈ 1/5.5`，即 n ≈ 5.5
```
增长量 = 8.64 ÷ (5.5 + 1) = 8.64 ÷ 6.5 ≈ 1.33
```
→ **选 C**

**【验证·公式法】** `n = 100 ÷ 18.6 ≈ 5.38` → `8.64 ÷ 6.38 ≈ 1.35`，与 1.33 几乎一致。

**【提醒】** **取中法算出的 n 是小数（5.5），直接代公式，不用取整。**
> 如果把 5.5 取整成 5 或 6，误差会突然放大——**取中就是取中，别画蛇添足**。

#### 第 11 题　【7.1% → n = 14】

**【题目】**
【材料】2024 年某市文化创意产业营业收入 4268 亿元，同比增长 7.1%。
2024 年该市文化创意产业营业收入同比增加约多少亿元？
A. 246　B. 285　C. 321　D. 368

**【解】**
```
7.1% ≈ 1/14 → n = 14
增长量 = 4268 ÷ (14 + 1) = 4268 ÷ 15 ≈ 284.5
```
→ **选 B（285）**

**【提醒】** `1/14 ≈ 7.1%` 属于"冷门但常考"的配对，**必须单独记**：
> 记忆法：**7 和 14 是一对**——`1/7 ≈ 14.3%`、`1/14 ≈ 7.1%`，数字互为倒装。

#### 第 12 题　【6.25% = 1/16】

**【题目】**
【材料】2024 年某市常住人口 1286.4 万人，同比增长 6.25%。
2024 年该市常住人口同比增加约多少万人？
A. 58.4　B. 64.2　C. 69.8　D. 75.7

**【解】**
```
6.25% = 1/16 → n = 16
增长量 = 1286.4 ÷ (16 + 1) = 1286.4 ÷ 17 ≈ 75.7
```
→ **选 D**

**【提醒】** 6.25% 是"互换配对"里的另一半：`1/16 = 6.25%`、`1/6 ≈ 16.7%`——**记住这一对，两个都能用**。
> 用分数记比用百分数记稳：**记"1/16"，就记住了 6.25%。**

#### 第 13 题　【5.3% ≈ 1/19：分母凑成 20】

**【题目】**
【材料】2024 年某县农村居民人均可支配收入 21486 元，同比增长 5.3%。
2024 年该县农村居民人均可支配收入同比增加约多少元？
A. 1074　B. 1152　C. 1246　D. 1368

**【解】**
```
5.3% ≈ 1/19 → n ≈ 19
增长量 = 21486 ÷ (19 + 1) = 21486 ÷ 20 ≈ 1074
```
→ **选 A**

**【提醒】** 这题是"**百化分选得好，除法变心算**"的最好例子：
> n = 19 → 分母 20 → **直接除以 20，等于小数点前移一位再除 2**。
> 如果硬算 `21486 ÷ 1.053 × 0.053`，至少多花 20 秒。

### D 组　减少量

#### 第 14 题　【n − 1，不是 n + 1】

**【题目】**
【材料】2024 年某市传统燃油车产量 68.4 万辆，同比下降 20%。
2024 年该市传统燃油车产量同比减少约多少万辆？
A. 11.4　B. 13.7　C. 17.1　D. 22.8

**【解】** r < 0，求**减少量**：
```
20% = 1/5 → n = 5
减少量 = 现期 ÷ (n − 1) = 68.4 ÷ (5 − 1) = 68.4 ÷ 4 = 17.1
```
→ **选 C**

**【提醒】** 三个错项各有来路：
- **A（11.4）= `68.4 ÷ 6`**，用成了 n+1（**最典型的错**）；
- **B（13.7）= `68.4 × 20%`**，把现期当基期；
- **D（22.8）= `68.4 ÷ 3`**，用成了 n−2。

> **一句话**：**涨了用 n+1，跌了用 n−1。**

#### 第 15 题　【25% = 1/4，减少量 ÷ 3】

**【题目】**
【材料】2024 年某市钢材产量 4680 万吨，同比下降 25%。
2024 年该市钢材产量同比减少约多少万吨？
A. 1170　B. 1560　C. 1872　D. 2340

**【解】**
```
25% = 1/4 → n = 4
减少量 = 4680 ÷ (4 − 1) = 4680 ÷ 3 = 1560
```
→ **选 B**

**【提醒】** 这道题的四个选项正好对应四种算法：
| 选项 | 算法 | 对错 |
|---|---|---|
| A 1170 | `4680 ÷ 4`（n+1） | ✗ |
| **B 1560** | `4680 ÷ 3`（n−1） | **✓** |
| C 1872 | `4680 ÷ 2.5` | ✗ |
| D 2340 | `4680 ÷ 2` | ✗ |

> **选项能反推出错法**——这是资料分析最善良的地方：**选完能自检**。

#### 第 16 题　【16.7% ≈ 1/6，减少量 ÷ 5】

**【题目】**
【材料】2024 年某市纺织品出口额 62.4 亿美元，同比下降 16.7%。
2024 年该市纺织品出口额同比减少约多少亿美元？
A. 8.9　B. 10.4　C. 11.2　D. 12.5

**【解】**
```
16.7% ≈ 1/6 → n = 6
减少量 = 62.4 ÷ (6 − 1) = 62.4 ÷ 5 = 12.48
```
→ **选 D（12.5）**

**【提醒】** 陷阱 A（8.9）就是 `62.4 ÷ 7`——**n+1 的错解**，而且数值也"像"一个答案。

### E 组　比较 · 现期基期

#### 第 17 题　【折线图：正负定形状】

**【题目】**
【材料】2018—2022 年某市天然气产量（亿立方米）：2018 年 386、2019 年 402、2020 年 372、2021 年 351、2022 年 378。
对 2019—2022 年该市天然气产量**同比增量**变化趋势的描述，正确的是：
A. 两头高、中间低
B. 两头低、中间高
C. 逐年递减
D. 逐年递增

**【解】** 同比增量 = 今年 − 去年：

| 年份 | 计算 | 增量 | 正负 |
|---|---|---|---|
| 2019 | 402 − 386 | **+16** | 正 |
| 2020 | 372 − 402 | **−30** | 负 |
| 2021 | 351 − 372 | **−21** | 负 |
| 2022 | 378 − 351 | **+27** | 正 |

**正、负、负、正** → **两头高、中间低** → **选 A**

**【提醒】** **别把"产量"的变化当成"增量"的变化。**
> 产量本身：386 → 402 → 372 → 351 → 378（先升，再一路降，最后回升）；
> 增量：+16 → −30 → −21 → +27（**两头正、中间负**）。
> **这两个形状完全不同**，看错就全错。

#### 第 18 题　【环比增量的比较】

**【题目】**
【材料】2024 年 4—8 月某市快递业务量（万件）：4 月 820、5 月 864、6 月 802、7 月 918、8 月 889。
2024 年 5—8 月，该市快递业务量**环比增量最大**的是：
A. 5 月　B. 6 月　C. 7 月　D. 8 月

**【解】** "环比"= 和**上个月**比：

| 月份 | 计算 | 环比增量 |
|---|---|---|
| 5 月 | 864 − 820 | +44 |
| 6 月 | 802 − 864 | **−62** |
| 7 月 | 918 − 802 | **+116** ← 最大 |
| 8 月 | 889 − 918 | −29 |

→ **选 C**

**【提醒】** 两件事：
1. **"环比"要减上个月，"同比"要减去年同月**——这题没有同比数据，只能是环比；
2. **负数也要参与比较**：6 月、8 月都是负的，**不可能是最大**。

#### 第 19 题　【增量排序：四个都算】

**【题目】**
【材料】2024 年四类农产品产量（万吨）：

| 产品 | 2024 年 | 2023 年 |
|---|---|---|
| 甲 | 286.4 | 258.2 |
| 乙 | 148.6 | 136.4 |
| 丙 | 392.4 | 352.8 |
| 丁 | 216.8 | 198.5 |

2024 年产量同比增量由大到小排序正确的是：
A. 丙、甲、丁、乙
B. 甲、丙、丁、乙
C. 丙、丁、甲、乙
D. 丙、甲、乙、丁

**【解】** 各算增量：
```
甲：286.4 − 258.2 = 28.2
乙：148.6 − 136.4 = 12.2
丙：392.4 − 352.8 = 39.6
丁：216.8 − 198.5 = 18.3
```
→ **丙(39.6) > 甲(28.2) > 丁(18.3) > 乙(12.2)** → **选 A**

**【提醒】** 这题**四个都要算**，没有捷径（因为都是纯减法，一次到位）。
> 但**顺序有讲究**：先算**丙**（唯一三位数差）定第一、再算**乙**（最小）定最后，**中间两个只需确认先后**。
> **先定首尾，永远比从左到右算快。**

### F 组　比较 · 现期增长率

#### 第 20 题　【大大则大 + 一大一小看倍数】

**【题目】**
【材料】2024 年四类商品零售额及同比增速：甲 862 亿元、增长 8.6%；乙 1246 亿元、增长 6.2%；丙 948 亿元、增长 9.4%；丁 586 亿元、增长 7.8%。
2024 年零售额**同比增量最多**的是：
A. 甲　B. 乙　C. 丙　D. 丁

**【解】**
1. **先淘汰两个**：
   - 丙 vs 甲：丙现期（948 > 862）大、r（9.4% > 8.6%）也大 → **大大则大** → 甲淘汰；
   - 丙 vs 丁：丙现期大、r 也大 → 丁淘汰。
   → **只剩乙和丙**
2. **比乙、丙（一大一小）**：
   - 现期倍数：`1246 ÷ 948 ≈ 1.31`
   - r 的倍数：`9.4 ÷ 6.2 ≈ 1.52`
   - **r 的倍数更大** → 看 r → **丙增量大**
3. → **选 C**

**【百化分验证】** 丙 `948 ÷ 11.6 ≈ 81.7`；乙 `1246 ÷ 17.1 ≈ 72.9` → 丙胜 ✓

**【提醒】** 这题的关键是**先筛后比**：四个主体不用同时看，**"大大则大"能一次淘汰两个**。
> 剩下的两个再用倍数，**总共只比了一次**。

#### 第 21 题　【负增长如何参与比较】

**【题目】**
【材料】2024 年四市工业用电量及同比增速：甲 862 亿千瓦时、增长 4.6%；乙 1246 亿千瓦时、增长 2.8%；丙 686 亿千瓦时、下降 3.2%；丁 1042 亿千瓦时、增长 6.4%。
2024 年工业用电量**同比增量最少**的是：
A. 甲　B. 乙　C. 丁　D. 丙

**【解】**
1. **丙是唯一的负增长** → 它的增量是**负数**，其他三个都是正数。
2. **正数永远大于负数** → **丙的增量最小** → **选 D**

**【百化分验证】**
- 甲：`862 ÷ 22.7 ≈ 38.0`
- 乙：`1246 ÷ 36.7 ≈ 33.9`
- 丙：`−686 ÷ 30.3 ≈ −22.7`（下降用 n−1）
- 丁：`1042 ÷ 16.6 ≈ 62.8`

**【提醒】** **找"最少"时，先看正负号。**
> 只要有一个是负增长，**它一定是"最少"**——这一步 3 秒完成，剩下三个根本不用算。
> 反过来，如果题目问"最多"，负增长的就可以直接排除。

#### 第 22 题　【排序：r 相同就看现期】

**【题目】**
【材料】2024 年四行业营业收入及同比增速：① 5219 亿元、增长 10.4%；② 375 亿元、增长 10.5%；③ 3583 亿元、增长 7.3%；④ 2146 亿元、增长 18.8%。
按 2024 年营业收入**同比增量从高到低**排序，正确的是：
A. ①③④②
B. ①④③②
C. ④①③②
D. ①④②③

**【解】**
1. **① vs ②**：r 几乎一样（10.4% 与 10.5%），但 ① 的现期（5219）是 ②（375）的 **13⁺ 倍**
   → **现期倍数压倒性大** → **① > ②** → 排除 C
2. **② 最小**：② 现期最小（375），r 也不占优 → **② 垫底** → 排除 D
3. **比 ③、④**：
   - 现期：③ 3583 > ④ 2146
   - r：④ 18.8% > ③ 7.3%
   - 现期倍数：`3583 ÷ 2146 ≈ 1.67`
   - r 的倍数：`18.8 ÷ 7.3 ≈ 2.58`
   - **r 的倍数更大** → 看 r → **④ > ③**
4. → **① > ④ > ③ > ②** → **选 B**

**【百化分验证】** ① `5219 ÷ 10.6 ≈ 492`；④ `2146 ÷ 6.32 ≈ 340`；③ `3583 ÷ 14.7 ≈ 244`；② `375 ÷ 10.5 ≈ 36` ✓

**【提醒】** 排序题的正确流程：
> **① 找"r 几乎相同"的那一对**（① 和 ②）→ 直接看现期定胜负；
> **② 找最明显的最小值**（②）→ 定末尾；
> **③ 剩下的一对**用倍数比。
>
> **三步做完，一道排序题不到 30 秒。**

#### * 第 23 题　【连比：一大一小看倍数】

**【题目】**
【材料】2024 年四类服务业增加值及同比增速：甲 98642 亿元、增长 1.2%；乙 82416 亿元、增长 6.4%；丙 41258 亿元、增长 10.2%；丁 35624 亿元、增长 3.8%。
2024 年增加值**同比增量最多**的是：
A. 甲　B. 乙　C. 丙　D. 丁

**【解】**
> **先记住**："增加值"是一种**经济指标**，不是增长量——把它当**现期量**用。

1. **淘汰丁**：丁的现期最小（35624），r（3.8%）也不占优，对乙、丙都是"现期小 + r 小" → **大大则大，丁出局**。
2. **比甲、乙**：
   - 现期倍数：`98642 ÷ 82416 ≈ 1.20`
   - r 的倍数：`6.4 ÷ 1.2 ≈ 5.3`
   - **r 的倍数大得多** → 看 r → **乙 > 甲** → 排除 A
3. **比乙、丙**：
   - 现期倍数：`82416 ÷ 41258 ≈ 2.0`
   - r 的倍数：`10.2 ÷ 6.4 ≈ 1.6`
   - **现期倍数更大** → 看现期 → **乙 > 丙** → 排除 C
4. → **选 B**

**【百化分验证】** 甲 1170、乙 4957、丙 3819、丁 1304 ✓

**【提醒】** 甲的现期量**接近 10 万**，看着最"唬人"，但它的 r 只有 1.2%——**这就是"看着大、其实增量小"的典型**。
> **增量 ≈ 现期 × r**，两个因子都要看。**只盯现期，必错。**

#### 第 24 题　【倍数接近 → 必须百化分】

**【题目】**
【材料】2024 年两类产品出口额：甲 4157 万元、同比增长 7.2%；乙 1949 万元、同比增长 16.9%。
2024 年这两类产品出口额**同比增量之和**约为多少万元？
A. 512　B. 528　C. 541　D. 556

**【解】** 分别百化分，再相加：
```
甲：7.2% ≈ 1/14  → 增量 ≈ 4157 ÷ 15 ≈ 277
乙：16.9% ≈ 1/6   → 增量 ≈ 1949 ÷ 7  ≈ 278
之和 ≈ 277 + 278 = 555
```
→ **选 D（556）**

**【提醒】** 这题如果偷懒"看倍数"，会翻车：
```
现期倍数：4157 ÷ 1949 ≈ 2.13
r 的倍数：16.9 ÷ 7.2 ≈ 2.35
```
两个倍数**都在 2 附近**，肉眼分不出谁大——按"倍数法"硬判，很容易把大小关系弄反。
> **遇到"两个倍数都差不多"，别犹豫，直接百化分。** 算一遍 277 vs 278，差 1 万，但**结论是确定的**。
