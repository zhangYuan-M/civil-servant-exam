### A 组　多数加减

#### 第 1 题　**【尾数法·加法】**

2457 + 3816 + 5092 + 6748 =（　）
A. 18113　B. 18112　C. 18124　D. 18137

**【判断】** 选项精确到个位，与算式精度一致 → 尾数法。

**【解】** 尾数相加：7 + 6 + 2 + 8 = 23 → 尾数 **3**。
四个选项中只有 **A（18113）** 的尾数是 3 → **选 A**。

**【提醒】** 四个选项**末位各不相同**，**5 秒内必须出答案**。如果去列竖式，说明方法还没建立起来。

#### 第 2 题　**【尾数法·末两位】**

58462 + 27315 − 19284 − 41637 =（　）
A. 24856　B. 24916　C. 24786　D. 24996

**【判断】** 精度一致 → 尾数法。但注意：四个选项**末位都是 6**，尾数法失灵 → **退一位算末两位**。

**【解】** 末两位运算：62 + 15 − 84 − 37 = −44 → 对 100 取模，末两位 = **56**。
只有 **A（24856）** 末两位是 56 → **选 A**。

**【提醒】** 这就是"末位相同看两位"。另外，减法算尾数时**别怕负数**：−44 的末两位就是 56。

#### 第 3 题　**【尾数法·百分数 + 先抵消】**

58.7% − 44.9% + 6.4% − 1.3% =（　）
A. 18.9%　B. 18.6%　C. 19.4%　D. 17.2%

**【判断】** 百分数加减，精度一致 → 尾数法。百分号是共同单位，**直接当整数算**。

**【解】** 尾数：7 − 9 + 4 − 3 = **−1** → 尾数 **9**（对 10 取模）。
只有 **A（18.9%）** 尾数为 9 → **选 A**。

**【提速技巧】** 能抵消先抵消：7 + 4 = 11，9 + 3 = 12，11 − 12 = −1 → 尾 9，一步到位。

#### 第 4 题　**【高算低看·低位定生死】**

6284 + 5137 + 7946 + 4358 + 6819 ≈（　）
A. 28500　B. 30500　C. 31500　D. 32500

**【判断】** 选项都是整百，与算式精度不一致 → 估算 → 高算低看。

**【解】**
- 千位：6 + 5 + 7 + 4 + 6 = **28** → 28000，**排除 A**
- 百位：2 + 1 + 9 + 3 + 8 = **23** → +2300 = **30300**
- 30300 落在 30500 附近，与 31500 差 1200、与 32500 差 2200 → **选 B**

> （实际值 30544，B 完全吻合）

**【提醒】** 算到"30300"就该停手，**不需要再算十位个位**。这是"及时止损"的典型。

#### 第 5 题　**【高算低看·带"万/亿"单位】**

【材料】五个区县一般公共预算收入：13284、14657、11926、15348、13075 万元。
合计在以下哪个范围内？
A. 不到 6 亿元　B. 6～6.5 亿元　C. 6.5～7 亿元　D. 7 亿元以上

**【判断】** 选项是"范围"（整亿），精度远低于算式 → 高算低看。

**【解】**
- 万位：1 + 1 + 1 + 1 + 1 = **5** → 50000 万元
- 千位：3 + 4 + 1 + 5 + 3 = **16** → +16000 → **66000 万元**
- 单位换算：**1 亿元 = 10000 万元** → 66000 万元 = **6.6 亿元**，已超过 6.5 亿 → **排除 A、B**
- 百位最多 99 × 5 < 500 → 66000 + 几百 **到不了 70000（7 亿元）** → **排除 D**
- → **选 C**（实际 68290 万元 = 6.829 亿元）

**【提醒】** 这题的坑有两层：
1. **单位**：材料给"万元"，选项问"亿元"，**万元 ÷ 10000 = 亿元**；
2. **量级**：高算低看只负责确定数量级，单位换算必须单独走一步。

> 记住换算链：`万 → 亿` 除以 10⁴，`亿 → 万` 乘以 10⁴。选项跨度大时，先别急着算，**先把单位统一**。

#### 第 6 题　**【高算低看·六位数】**

【材料】五项业务收入：236487、308265、279413、351728、294836 元。
合计约为（　）
A. 145 万元　B. 147 万元　C. 149 万元　D. 151 万元

**【判断】** 选项精确到万位 → 估算 → 高算低看。

**【解】**
- 十万位：2 + 3 + 2 + 3 + 2 = **12** → 1 200 000
- 万位：3 + 0 + 7 + 5 + 9 = **24** → +240 000 = **1 440 000**
- 千位：6 + 8 + 9 + 1 + 8 = **32** → +32 000 = **1 472 000 元**
- 单位换算：**1 万元 = 10000 元** → 1 472 000 元 = **147.2 万元**
- 与 147 万最接近 → **选 B**

**【提醒】** 三位一起算，**累计到能区分选项就停**。这里 A、B、C、D 各差 2 万，必须算到千位。

### B 组　截位直除

#### 第 7 题　**【一步除法·截两位】**

【材料】GDP 51842 亿元，常住人口 3625 万人。人均 GDP 约为（　）
A. 9.8 万元　B. 11.6 万元　C. 14.3 万元　D. 17.9 万元

**【看选项】** 首位 9/1/1/1，最接近的一对是 B（11.6）与 C（14.3），次位差 4 − 1 = 3 **>** 首位 1 → **差距大 → 截两位**。

**【看式子】** 一步除法 → **只截分母**：3625 万人截两位 = 36。

**【解】** 51842 ÷ 36 → 首位商 1、次位商 4 → **14 开头** → **选 C**（实际 14.30 万元）

**【提醒】** 单位这里**天然抵消**：亿元 ÷ 万人 = 万元/人（10⁸ ÷ 10⁴ = 10⁴），所以数值直接算，不用再乘除换算。这也是"人均"类题最省事的地方。

#### 第 8 题　**【一步除法·截三位】**

【材料】2024 年营业收入 4735.8 万元，同比增长 12.6%。2023 年营业收入约为（　）
A. 4018 万元　B. 4206 万元　C. 4402 万元　D. 4658 万元

**【看选项】** A（4018）与 B（4206）首位同为 4，次位差 2 − 0 = 2 **≤** 首位 4 → **差距小 → 截三位**。

**【看式子】** 求基期：`4735.8 ÷ (1 + 12.6%)`，一步除法 → 只截分母。分母 `1.126` 截三位 = **1.13**。

**【解】** 4735.8 ÷ 1.13 ≈ 4191 → 与 B（4206）最接近 → **选 B**（实际 4205.9）

**【提醒】** 分母是 `1 + r%` 时，先化成小数 `1.126` 再截位，**不要对"12.6%"单独截位**。

#### 第 9 题　**【量级陷阱·1% 分界线】**

【材料】R&D 经费 41.7 亿元，GDP 23658 亿元。占比约为（　）
A. 0.18%　B. 0.8%　C. 1.8%　D. 8.0%

**【看选项】** 四个选项成倍拉开，A 与 B 相差 4 倍多、C 与 D 也是如此 —— 但关键在于 **A、B 小于 1%，C、D 大于 1%** → **先判量级**。

**【解·两步】**
1. **判是否超过 1%**：`23658 × 1% = 236.58`，而分子只有 41.7，`41.7 < 236.58` → **不足 1%** → **排除 C、D**。
2. **截两位定有效数字**：`42 ÷ 24` = 1.75 → 首位商 **1** → 对应 0.18%（有效数字 1.8）→ **选 A**。

> 实际值 0.176%，A 正确。

**【提醒】** 这是本讲**最容易丢分**的题型。口诀：
> **先看选项有没有 10 倍关系 → 有就先判量级（拿 1% 当分界线）→ 再截位**。

#### 第 10 题　**【多步除法·上下都截】**

【材料】甲市：零售额 358.4 亿元、人口 236.5 万人；乙市：246.7 亿元、158.2 万人。
甲市人均零售额是乙市的约（　）倍
A. 0.75　B. 0.85　C. 0.97　D. 1.15

**【看选项】** 首位 7/8/9/1 全不同 → **差距大 → 截两位**。

**【看式子】** 多步除法（两个"人均"相除）→ **上下都截**。

**【解】**
```
甲人均 = 358.4/236.5 → 截两位 → 36/24 = 1.5
乙人均 = 246.7/158.2 → 截两位 → 25/16
原式 = 36/24 ÷ (25/16)
     = 1.5 × 16/25
     = 24/25 = 0.96
```
0.96 与 C（0.97）最接近 → **选 C**（实际 0.972）

**【提醒】** `÷ (25/16)` 必须**颠倒相乘**变成 `× 16/25`。这一步错，答案会跑到 1.5 附近。

#### 第 11 题　**【多步除法·带 1+r%】**

【材料】甲产品 862.7 万吨、增长 23.4%；乙产品 391.5 万吨、增长 18.6%。
2023 年甲产量是乙的约（　）倍
A. 1.6　B. 1.9　C. 2.1　D. 2.6

**【看选项】** 最接近的一对是 C（2.1）与 D（2.6），次位差 6 − 1 = 5 **>** 首位 2 → **差距大 → 截两位**。

**【看式子】** 多步除法 → 上下都截。

**【解】**
```
原式 = 862.7/1.234 ÷ 391.5/1.186
     = 86/12 ÷ 39/12
     = 86/39
     ≈ 2.2
```
2.2 与 C（2.1）最接近 → **选 C**（实际 2.118）

**【提醒】** 两个分母都是 `1 + r%`，截两位后都是 12，**直接约掉**，计算量瞬间减半。这是多步除法的常见红利。

#### 第 12 题　**【一步除法·截三位·百分数结果】**

【材料】网上零售额 142839 亿元，其中实物商品 118736 亿元。占比约为（　）
A. 81.3%　B. 83.1%　C. 85.2%　D. 87.4%

**【看选项】** 首位都是 8，最接近的一对是 A（81.3）与 B（83.1），次位差 3 − 1 = 2 **≤** 首位 8 → **差距小 → 截三位**。

**【解】** 118736 ÷ 142839 → 截三位：**119 ÷ 143 ≈ 0.832** → 83.2% → **选 B**（实际 83.13%）

**【提醒】** 选项只在**小数第二位**上打架时，两位精度一定不够，必须上三位。

#### 第 13 题　**【多步除法·净利率之比】**

【材料】2024 年营收 1.87 亿元、净利 0.21 亿元；2023 年营收 1.62 亿元、净利 0.17 亿元。
2024 年净利率是 2023 年的约（　）倍
A. 0.85　B. 0.95　C. 1.07　D. 1.25

**【看选项】** 最接近的一对是 C（1.07）与 D（1.25），次位差 2 − 0 = 2 **>** 首位 1 → **差距大 → 截两位**。

**【解】**
```
2024 净利率 = 0.21/1.87 → 21/19
2023 净利率 = 0.17/1.62 → 17/16
原式 = 21/19 ÷ 17/16 = 21/19 × 16/17 = 336/323 ≈ 1.04
```
1.04 与 C（1.07）最接近 → **选 C**（实际 1.070）

**【提醒】** 这题是"**比值再比值**"的典型结构（比重、人均、净利率、合格率都会这么考）。识别信号：题目里出现"**A 是 B 的多少倍**"而 A、B 本身都要先算，就是多步除法。

#### 第 14 题　**【两次运算·先减后除】**

【材料】进出口总额 43.85 万亿元，出口 25.45 万亿元、进口 18.39 万亿元。
顺差占进出口总额的比重约为（　）
A. 15.1%　B. 16.1%　C. 17.1%　D. 18.1%

**【第一步·先求顺差】** 25.45 − 18.39 = **7.06** 万亿元（这里用精确减法，别估算）

**【看选项】** 首位都是 1，最接近的一对是 A（15.1）与 B（16.1），次位差 6 − 5 = 1 **=** 首位 1 → **差距小 → 截三位**。

**【解】** 7.06 ÷ 43.9 ≈ **0.1608** → 16.1% → **选 B**（实际 16.10%）

**【提醒】** 这类题的正确顺序是：**先算出被除的分子（精算），再对除法截位**。顺序反了，误差会叠加。

### C 组　分数比较

#### 第 15 题　**【一大一小·直接看】**

下列四个分数中最大的是（　）
A. 39.2/61.7　B. 43.7/58.2　C. 51.6/55.8　D. 47.9/62.4

**【思路】** 问最大 → 先找"分子最大 + 分母最小"。

**【解】**
- C 项分子 **51.6 为最大**，分母 **55.8 为最小** → 典型的"钱最多、人最少"
- **一大一小，直接判最大** → **选 C**

> 验证：C ≈ 92.5%，A ≈ 63.5%、B ≈ 75.1%、D ≈ 76.8%，差距悬殊。

**【提醒】** 这类题**一秒都不用算**。看到"分子最大且分母最小"就收工——这是四选项比大小里最该拿的分。

#### 第 16 题　**【同大同小·分子倍数大】**

比较大小：7.3/12.8 与 30.4/48.6
A. 左边大　B. 右边大

**【判断】** 左小右大（分子、分母都更大）→ **同大同小**。

**【解·横着看倍数】**
```
分子：7.3 → 30.4  ≈ 4.16 倍   ← 更大
分母：12.8 → 48.6 ≈ 3.80 倍
```
分子倍数大 → **看分子，分子大的分数大** → `7.3/12.8 < 30.4/48.6` → **选 B**

> 验证：0.570 < 0.626

**【提醒】** 判断"谁倍数大"时，把**大的除以小的**，两个商直接比，**不要约成整数倍**——4.16 与 3.80 的差别，正负号就在这一线之间。

#### 第 17 题　**【同大同小·分母倍数大 + 四选一】**

下列四个分数中最大的是（　）
A. 2136/384　B. 4278/792　C. 1572/296　D. 3264/612

**【思路】** 四个分数都是 5 倍多，分数值非常接近 → **必须两两比**，不能靠"一大一小"。先挑一个"种子"当擂主，逐个挑战。

**【解】** 以 A（2136/384）为擂主：

1. **A vs D**（3264/612）
   分子 2136 → 3264 ≈ **1.53 倍**；分母 384 → 612 ≈ **1.59 倍**
   分母倍数大 → 分母大的分数小 → **D < A**

2. **A vs B**（4278/792）
   分子 ≈ **2.00 倍**；分母 ≈ **2.06 倍**
   分母倍数大 → **B < A**

3. **A vs C**（1572/296）
   分子 2136 → 1572 ≈ **1.36 倍**；分母 384 → 296 ≈ **1.30 倍**
   分子倍数大 → 分子大的分数大 → **A > C**

三轮全胜 → **选 A**（实际：A 5.563、B 5.402、C 5.311、D 5.333）

**【提醒】** 这是"**同大同小 + 倍数极接近**"的硬题。策略要点：
1. **先选擂主**（一般选数值居中或分子分母较整齐的），不要四四比较（那是 6 次）；
2. 每次只比**一对倍数**，看谁大就听谁的。

#### 第 18 题　**【四选一找最小·两两比】**

下列四个分数中最小的是（　）
A. 15.7/48.3　B. 12.4/38.6　C. 9.8/37.2　D. 18.3/52.1

**【思路】** 这题没有"分子最小 + 分母最大"的送分项（C 的分子最小，但分母 37.2 比 B 的 38.6 还小，构不成一大一小）→ **必须比倍数**。

**【解】** 以 B（12.4/38.6）为中心：

1. **B vs A**：分子 12.4 → 15.7 ≈ **1.27 倍**；分母 38.6 → 48.3 ≈ **1.25 倍**
   分子倍数大 → A > B
2. **B vs C**：分子 12.4 → 9.8 ≈ **1.27 倍**；分母 38.6 → 37.2 ≈ **1.04 倍**
   分子倍数大 → B > C（即 C 更小）
3. **B vs D**：分子 ≈ **1.48 倍**；分母 ≈ **1.35 倍**
   分子倍数大 → D > B

由 2 得 C < B，由 1、3 得 A > B、D > B → **C 最小** → **选 C**

> 验证：A 32.5%、B 32.1%、C 26.3%、D 35.1%

**【提醒】** 找最小的题，**不要死盯"分子最小"**——分子最小但分母也小，很可能不是最小。**先看能不能一大一小秒杀，不能就老实比倍数**。

#### 第 19 题　**【先筛后比·四选一找最大】**

下列四个分数中最大的是（　）
A. 286.4/7193.5　B. 641.7/8632.9　C. 415.6/9418.3　D. 538.2/10246.7

**【思路】** 先筛掉一半，再做两两比。

**【解】**
1. **筛**：B 项分子 **641.7 最大**，分母 8632.9 比 C（9418.3）、D（10246.7）都小 → B 对 C、D 是"钱多人少" → **排除 C、D**
2. **比 A、B**（同大同小）：
   - 分子 286.4 → 641.7 ≈ **2.24 倍**
   - 分母 7193.5 → 8632.9 ≈ **1.20 倍**
   - 分子倍数大 → 分子大的分数大 → **A < B**
3. → **选 B**（实际：B 7.43%、A 3.98%、C 4.41%、D 5.25%）

**【提醒】** 优先用"一大一小"筛人，能把 4 选 1 直接砍成 2 选 1；剩下的一对再用倍数比。**这个顺序不能反**。

#### 第 20 题　**【倍数接近·要更精确】**

比较大小：542/3876 与 361/2569
A. 左边大　B. 右边大

**【判断】** 左分子分母都大 → **同大同小**。

**【解·两个办法】**

**① 更精确地算倍数（推荐）**
```
分子：361 → 542 ≈ 1.5014 倍
分母：2569 → 3876 ≈ 1.5088 倍
```
分母倍数大 → **分母大的分数小** → 左边小 → `542/3876 < 361/2569` → **选 B**

**② 凑整比（柳暗花明）**
```
542/3876 ≈ 540/3900 ≈ 0.1385
361/2569 ≈ 360/2570 ≈ 0.1401
0.1401 > 0.1385  →  右边大
```

**【验证】** 542/3876 = 13.98%，361/2569 = 14.05% —— **只差 0.07 个百分点**，属于典型的"倍数都在 1.5 附近"的刁钻题。

**【提醒】** 这种题最容易翻车在"**看反方向**"：
> 分子倍数大 → 分子大的**大**；
> 分母倍数大 → 分母大的**小**。

两边只差 0.5%，方向一错就丢分。**算完倍数，回头用"凑整"验一次**，10 秒的事。
