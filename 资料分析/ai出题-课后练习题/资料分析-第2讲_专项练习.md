### A 组　基期量·基础计算

#### 第 1 题　【公式一 + 尾数法】

**【题目】**
【材料】2024 年某市一般公共预算收入 864375 万元，比上年增加 27648 万元。
2023 年该市一般公共预算收入为多少万元？
A. 836728　B. 836725　C. 836727　D. 836726

**【判断】** 求 2023 年（过去）+ 材料给"**增加 27648**"（增长量）→ **公式一：基期 = 现期 − 增长量**。选项精确到个位 → **尾数法**。

**【解】** 尾数 `5 − 8 = −3` → **尾 7**。只有 **C（836727）** 尾数是 7 → **选 C**。

**【提醒】** 四个选项只差最后一位，**这是送分题，5 秒必须出答案**。去列竖式 = 方法没建立。

---

#### 第 2 题　【公式二 + 截两位】

**【题目】**
【材料】2024 年某市新能源装机容量 2856 万千瓦，同比增长 18.6%。
2023 年该市新能源装机容量约为多少万千瓦？
A. 2408　B. 2135　C. 2955　D. 2680

**【判断】** 求过去 + 给增长率 → 基期 = `2856 ÷ 1.186`。
**看选项**：A（2408）与 B（2135）首位同为 2，次位差 `4 − 1 = 3 > 2` → **差距大 → 截两位**。

**【解】**
```
2856 ÷ 1.186 → 分母截两位 → 2856 ÷ 1.2 = 2380
```
2380 落在 A（2408）附近 → **选 A**（实际 2408.1）

**【提醒】** 分母 1.186 截两位成 1.2 会**偏大**，所以估出的 2380 比真值 2408 **略小**——方向记清楚，选最接近的即可。

#### 第 3 题　【公式二 + r 为负 + 截三位】

**【题目】**
【材料】2024 年某企业营业收入 4.86 亿元，同比下降 12.5%。
2023 年该企业营业收入约为多少亿元？
A. 4.25　B. 5.90　C. 6.10　D. 5.55

**【判断】** 下降 → 分母是 `1 − 12.5% = 0.875`，**不是 1.125**。
**判方向**：`÷ 0.875`（小于 1）→ 结果 **> 4.86** → **排除 A**。
**看选项**：B（5.90）与 D（5.55）首位同为 5，次位差 `9 − 5 = 4 < 5` → **差距小 → 截三位**。

**【解】** `4.86 ÷ 0.875 ≈ 5.55` → **选 D**（实际 5.554）

**【提醒】** 本题两处易错：① 分母写成 1.125（那是"下降 12.5%"当"增长"了）；② 差距小还截两位。**先排方向，再定精度。**

#### 第 4 题　【小 r + 化除为乘】

**【题目】**
【材料】2024 年某市快递业务量 3.28 亿件，同比增长 0.6%。
2023 年该市快递业务量约为多少亿件？
A. 3.34　B. 3.26　C. 3.30　D. 3.24

**【判断】** `|r| = 0.6% ≤ 5%` → **化除为乘**。且结果 **< 3.28** → 排除 C、D。

**【解】**
```
3.28 ÷ 1.006 ≈ 3.28 × (1 − 0.6%) = 3.28 − 0.0197 ≈ 3.26
```
→ **选 B**（实际 3.2604）

**【提醒】** `3.28 × 0.6%` 心算方法：`3.28 × 0.6 / 100 ≈ 0.0328 × 0.6 ≈ 0.02`。**先缩小 100 倍，再乘。**

#### 第 5 题　【公式二 + 差距小 + 截三位】

**【题目】**
【材料】2024 年全国一般公共预算支出 28.46 万亿元，同比增长 6.4%。
2023 年全国一般公共预算支出约为多少万亿元？
A. 25.2　B. 27.4　C. 26.7　D. 29.9

**【判断】** `28.46 ÷ 1.064`。结果 **< 28.46** → **排除 D**。
**看选项**：A（25.2）与 C（26.7）首位同为 2，次位差 `6 − 5 = 1 ≤ 2` → **差距小 → 截三位**。

**【解】** `28.46 ÷ 1.06 ≈ 26.85` → 与 C（26.7）最接近 → **选 C**（实际 26.75）

**【提醒】** 这题 A 和 C 只差 1.5，B（27.4）卡在中间。**判了"差距小"就必须上三位**，否则 25 / 27 / 26 三个数会打架。

#### 第 6 题　【公式一 + 尾数法】

**【题目】**
【材料】2024 年末某市常住人口 2189.6 万人，比上年末增加 12.4 万人。
2023 年末该市常住人口为多少万人？
A. 2202.0　B. 2176.8　C. 2189.6　D. 2177.2

**【判断】** 给增长量 → 公式一。选项末位分别是 0 / 8 / 6 / 2，**各不相同** → 尾数法。

**【解】** 尾数 `6 − 4 = 2` → **选 D（2177.2）**

**【提醒】** **A（2202.0）是"加错了"的陷阱**——`2189.6 + 12.4 = 2202`。看清是"增加"，就用减法。
**C（2189.6）是现期值本身**，也是常见诱饵。

#### 第 7 题　【公式二 + 一眼看 + 截两位】

**【题目】**
【材料】2024 年某省规模以上工业增加值 18742 亿元，同比增长 9.3%。
2023 年该省规模以上工业增加值约为多少亿元？
A. 17150　B. 15120　C. 18900　D. 20480

**【判断】** 结果 **< 18742** → **排除 C、D**（一步排两个）。
**看选项**：A（17150）与 B（15120）首位同为 1，次位差 `7 − 5 = 2 > 1` → **差距大 → 截两位**。

**【解】** `18742 ÷ 1.1 ≈ 17038` → 与 A（17150）最接近 → **选 A**（实际 17147）

**【提醒】** 这题是"**先排后算**"的标准演示：`÷1.x` 一定变小，一句话排掉 C、D，然后只需在 A、B 之间二选一。

#### 第 8 题　【大 r + 截两位】

**【题目】**
【材料】2024 年某市新能源汽车产量 62.4 万辆，同比增长 96.5%。
2023 年该市新能源汽车产量约为多少万辆？
A. 24.6　B. 31.8　C. 38.5　D. 45.2

**【判断】** `62.4 ÷ 1.965`。结果 **< 62.4**，但四个选项都小，方向排不掉。
**看选项**：B（31.8）与 C（38.5）首位同为 3，次位差 `8 − 1 = 7 > 3` → **差距大 → 截两位**。

**【解】** `1.965` 截两位 = **2.0**，`62.4 ÷ 2.0 = 31.2` → 与 B（31.8）最接近 → **选 B**（实际 31.76）

**【提醒】** 分母 1.965 → 2.0 是**往上**截的，所以结果 31.2 比真值 31.76 **偏小**。
**偏差 2% 却不影响选答案**——因为选项之间差 20%。**这就是"差距大截两位"的底气。**

### B 组　化除为乘 / 判断 / 单位

#### 第 9 题　【化除为乘 + 判方向】

**【题目】**
【材料】2024 年某市图书馆藏书 386.5 万册，比上年下降 0.8%。
2023 年该市图书馆藏书约为多少万册？
A. 383.4　B. 392.1　C. 396.8　D. 389.6

**【判断】** 下降 → `÷ 0.992` → 结果 **> 386.5** → **排除 A**。
`|r| = 0.8% ≤ 5%` → **化除为乘（除变乘、加减变号）**：`÷(1−0.8%)` 变成 `×(1+0.8%)`。

**【解】**
```
386.5 ÷ (1 − 0.8%) ≈ 386.5 × (1 + 0.8%)
                  = 386.5 + 386.5 × 0.8%
                  ≈ 386.5 + 3.09
                  ≈ 389.6
```
→ 与 D（389.6）完全吻合 → **选 D**

**【提醒】** 这题三个干扰项都大于 386.5，**"判方向"只能排掉 A**，剩下必须真算。但化除为乘只需一次乘加，10 秒出结果。

【材料】2024 年某市某项民生支出 4528 万元，同比下降 4.8%。
2023 年该项支出约为多少万元？
A. 4311　B. 4982　C. 4756　D. 4528

**【判断】** 下降 → 结果 **> 4528** → **排除 A（4311）、D（4528）**。
**看选项**：B（4982）与 C（4756）→ 差距小 → 截三位（0.952 已是三位）。

**【解】** `4528 ÷ 0.952 ≈ 4756` → **选 C**

**【验证·化除为乘】** `4528 × (1 + 4.8%) = 4528 + 217 = 4745`，比真值 4756 略小，**同样指向 C**。

**【提醒】** 本题的正确顺序是：**先用方向排两个，再算剩下两个**。
如果一上来就闷头算，等于白算两个选项。

#### * 第 11 题　【综合分析：四个说法逐一判】

**【题目】**
【材料】2024 年某市三次产业增加值：
第一产业 428.6 亿元（增长 3.2%）；第二产业 5124.3 亿元（增长 4.9%）；第三产业 8762.5 亿元（增长 6.1%）。
根据上述数据，关于 **2023 年**的说法正确的是：
A. <u>第一产业增加值</u>超过 500 亿元
B. 第二产业增加值超过 4800 亿元
C. 第三产业增加值不足 8200 亿元
D. 三次产业增加值合计超过 14000 亿元

**【解·逐个验】**
```
第一产业：428.6 ÷ 1.032 ≈ 415.3   → 不足 500，A 错
第二产业：5124.3 ÷ 1.049 ≈ 4884.9 → 超过 4800，B 对
第三产业：8762.5 ÷ 1.061 ≈ 8258.7 → 超过 8200，C 错
　合　计：415.3 + 4884.9 + 8258.7 ≈ 13559 → 不足 14000，D 错
```
→ **选 B**

**【提醒·两个提速点】**
1. **A 项不必精算**：`428.6 ÷ 1.032 < 428.6 < 500`，一句话否掉。
2. **D 项抓大头**：
   - 现期合计 = `428.6 + 5124.3 + 8762.5 = 14315`
   - 要跌破 14000，只需合计缩水 **超过 315**
   - 三产**一项**就缩水 `8762.5 − 8259 ≈ 504`，远超 315 → 合计必然 **< 14000** → D 错

> **综合判断题的黄金法则**：**能用不等式否掉的，绝不精算。**
> 判断"总和够不够某个门槛"，**只看最大的那一项能不能把这个差距填上**——这叫"抓大头"。

#### 第 12 题　【单位换算 + 化除为乘】

**【题目】**
【材料】2024 年我国原油产量 21324 万吨，同比增长 1.8%。
2023 年我国原油产量约为多少亿吨？
A. 2.09　B. 2.17　C. 2.21　D. 2.05

**【判断】**
1. **单位先统一**：现期 21324 万吨 = **2.1324 亿吨**。
2. 结果 **< 2.13 亿吨** → **排除 B（2.17）、C（2.21）**。
3. `|r| = 1.8% ≤ 5%` → 化除为乘。

**【解】**
```
21324 ÷ (1 + 1.8%) ≈ 21324 × (1 − 1.8%)
                  ≈ 21324 − 384
                  = 20940 万吨 = 2.094 亿吨
```
→ **选 A**

**【提醒】** 这题有两道坎：
① **单位**：材料给"万吨"、选项问"亿吨"，先换算再判断（否则会误以为 2.09 太小）；
② **精度**：A（2.09）与 D（2.05）只差 0.04，`20940` 落在 2.094，**必须算到这一步才敢选**。

### C 组　基期比较

#### * 第 13 题　【排序 = 一连串"一大一小"】

**【题目】**
【材料】2024 年四市地区生产总值及同比增速：

| 城市 | 2024 年 GDP（亿元） | 同比增速 |
|---|---|---|
| 甲 | 12846 | 5.2% |
| 乙 | 9542 | 16.8% |
| 丙 | 15328 | 4.5% |
| 丁 | 11205 | 7.3% |

2023 年四市 GDP 由大到小排序正确的是：
A. 甲、丙、丁、乙
B. 丙、丁、甲、乙
C. 丙、甲、乙、丁
D. 丙、甲、丁、乙

**【解】** 基期 = 现期 ÷ (1+r)，**现期大 + r 小 → 基期大**。

```
丙：15328（现期最大）、4.5%（r 最小）→ 基期第一，一步定
乙：9542（现期最小）、6.8%（r 最大）→ 基期最后，一步定
甲 vs 丁：甲现期 12846 > 丁 11205，甲 r 5.2% < 丁 7.3% → 甲 > 丁
```
→ 顺序 **丙 > 甲 > 丁 > 乙** → **选 D**

**【验证】** 12211 / 8935 / 14668 / 10443 —— 与排序一致。

**【提醒】** 排序题**根本不用算出任何一个数**。这题两步就锁定了首尾，中间一对再用"一大一小"，**全程零计算**。
若把四个数都算出来，至少多花 40 秒。

#### * 第 14 题　【百分点的真相：它是"增长量"】

**【题目】**
【材料】2024 年四城市空气质量优良天数比例及其同比变化：

| 城市 | 2024 年优良天数比例 | 同比变化 |
|---|---|---|
| A 市 | 82.4% | 提高 1.2 个百分点 |
| B 市 | 86.1% | 提高 0.6 个百分点 |
| C 市 | 79.3% | 下降 2.1 个百分点 |
| D 市 | 84.7% | 提高 1.8 个百分点 |

2023 年空气质量优良天数比例最高的是：
A. A 市　B. D 市　C. B 市　D. C 市

**【判断·本题唯一考点】** "提高/下降 X **个百分点**"——**百分点是差，是增长量，不是增长率！**
所以求基期用**公式一（减法）**，不是公式二（除法）。

**【解】**
```
A 市：82.4 − 1.2 = 81.2
B 市：86.1 − 0.6 = 85.5   ← 最高
C 市：79.3 + 2.1 = 81.4   （注意：下降 → 加回去）
D 市：84.7 − 1.8 = 82.9
```
→ **选 C**（B 市）

**【提醒】** 这是本套题**最容易集体翻车**的一道：
- 看到"%"就想除 → 全错，方向反了；
- C 市是"**下降 2.1 个百分点**"，基期要**加**回去，减了就错。
> **记住**：`%` = 增长率（用除法）；`个百分点` = 增长量（用加减）。

#### * 第 15 题　【同大同小 + 倍数极接近】

**【题目】**
【材料】2024 年四行业营业收入及同比增速：

| 行业 | 2024 年营业收入（亿元） | 同比增速 |
|---|---|---|
| 甲 | 31200 | 18.6% |
| 乙 | 37181 | 57.3% |
| 丙 | 28450 | 12.4% |
| 丁 | 33960 | 31.8% |

2023 年营业收入最高的是：
A. 乙　B. 甲　C. 丙　D. 丁

**【解】** 四个都是几百亿到三千多亿，先看能不能"一大一小"：

- 乙分子最大（37181）但 `r` 也最大（57.3%）→ **与甲、丙、丁都是"同大同小"**，没有送分项。
- 以**甲（31200 / 1.186 = 26307）**为擂主，逐个比倍数：

| 对手 | 分子倍数 | 分母倍数 | 谁大 | 结论 |
|---|---|---|---|---|
| 乙 37181/1.573 | 1.19 | 1.33 | 分母 | 乙 < 甲 |
| 丙 28450/1.124 | 1.10 | 1.06 | 分子 | 甲 > 丙 |
| 丁 33960/1.318 | 1.09 | 1.11 | 分母 | 丁 < 甲 |

→ **选 B（甲）**，实际 26307 / 23637 / 25311 / 25766

**【提醒】** 这题的陷阱是"**乙的增速 57.3% 太扎眼**"，很多人下意识选乙。
**增速高 ≠ 基期大**——乙的基数被 57.3% 摊薄后，反而成了最小的。
> **看倍数时，永远把「分子倍数」和「分母倍数」并排写出来，谁大听谁的。**

#### 第 16 题　【负增长下的"一大一小"】

**【题目】**
【材料】2024 年四地区进出口总额及同比增速：

| 地区 | 2024 年进出口总额（亿元） | 同比增速 |
|---|---|---|
| 甲 | 8420 | −12.4% |
| 乙 | 7650 | −8.6% |
| 丙 | 6930 | −5.2% |
| 丁 | 8210 | −5.3% |

2023 年进出口总额最大的是：
A. 甲　B. 乙　C. 丙　D. 丁

**【解】** 四个都是下降，分母 0.876 / 0.914 / 0.848 / 0.947。
```
甲：8420（现期最大）、−12.4%（r 最小）→ 基期最大，一步定
```
→ **选 A（甲）**，实际 9612 / 8370 / 8172 / 8670

**【验证】** 直观理解：**跌得越狠，说明去年越高**。甲去年 9612，跌了 12.4% 才到 8420。

**【提醒】** 负增长时，"**r 小**"指数学上更小（−12.4% < −5.3%）。
**别被"跌得多"绕晕**——跌得越多，基期越大。这是本题唯一的坑。

### D 组　基期和差

#### 第 17 题　【现期坑 + 判方向】

**【题目】**
【材料】2024 年某市城镇居民人均可支配收入 48620 元，同比增长 4.5%；农村居民人均可支配收入 24180 元，同比增长 6.8%。
2023 年该市城镇居民人均可支配收入比农村居民多多少元？
A. 24440　B. 25120　C. 22700　D. 23886

**【解】**
1. **排现期坑**：`48620 − 24180 = 24440` → **A 是现期坑，排除**。
2. **判方向**：两者都要"缩水"，看谁缩得多：
   
   ```
   城镇缩水 ≈ 48620 × 4.5% ≈ 2188（基数大，缩得多）
   农村缩水 ≈ 24180 × 6.8% ≈ 1644
   ```
   **城镇缩水更多 → 基期差 < 现期差**（24440）→ **排除 B（25120）**
3. 剩 C（22700）、D（23886）。缩水差 ≈ 2188 − 1644 = **544**，`24440 − 544 = 23896` → **选 D**（实际 23886）

**【提醒】** 本题的关键是**"比谁缩水多"，而不是"比谁的 r 大"**。
城镇 r 只有 4.5%（比农村小），但**基数大 2 倍**，绝对缩水量反而更多。**看百分比，更要看基数。**

#### * 第 18 题　【现期坑 + 量级排除】

**【题目】**
【材料】2024 年某省电子信息制造业营业收入 1.86 万亿元，同比增长 21.3%；汽车制造业营业收入 1.24 万亿元，同比增长 12.7%。
2023 年该省电子信息制造业营业收入比汽车制造业多多少万亿元？
A. 0.62　B. 0.81　C. 0.43　D. 1.02

**【解】**
1. **排现期坑**：`1.86 − 1.24 = 0.62` → **A 排除**。
2. **量级排除**：两个基期分别是 **1.53 万亿**和 **1.10 万亿**左右，差值只能是 **0.4 上下**。
   B（0.81）、D（1.02）已经接近"一整个量"，**不可能** → **排除 B、D**
3. → **选 C（0.43）**

**【验证】** `1.86 ÷ 1.213 ≈ 1.533`；`1.24 ÷ 1.127 ≈ 1.100`；差 = **0.433** ✓

**【提醒】** **"量级排除"是基期和差题的第二把刀**，比硬算快得多：
> 差值一定小于"两个基期中较大的那个"，也一定小于现期差和两个基期差之间的合理范围。
> 看到选项里有"接近整个量"的数字，**直接划掉**。

#### 第 19 题　【结构转换：下半年 = 全年 − 上半年】

**【题目】**
【材料】2024 年某市社会消费品零售总额 9864.2 亿元，同比增长 5.6%；其中上半年 4728.6 亿元，同比增长 3.9%。
2023 年下半年该市社会消费品零售总额约为多少亿元？
A. 5136　B. 4790　C. 4980　D. 5240

**【解】**
1. **转结构**：`下半年 = 全年 − 上半年`，且**两边都要换成 2023 年的基期**：
   ```
   所求 = 9864.2/(1+5.6%) − 4728.6/(1+3.9%)
   ```
2. **排现期坑**：`9864.2 − 4728.6 = 5135.6` → **A 排除**。
3. **判方向**：全年缩水 `9864 × 5.6% ≈ 552`；上半年缩水 `4728 × 3.9% ≈ 184`。
   被减数缩得多 → **差值变小** → 小于 5136 → 排除 D（5240）。
4. 剩 B（4790）、C（4980）：`5135.6 − (552 − 184) = 5135.6 − 368 ≈ 4768` → **选 B**

**【验证】** `9864.2/1.056 = 9341.1`；`4728.6/1.039 = 4551.1`；差 = **4790** ✓

**【提醒】** 这题的**真正难点不是算，是"先转结构"**。
> 记住几个常用转换：**上半年 = 1—6 月；下半年 = 全年 − 上半年；第四季度 = 全年 − 前三季度。**
> **结构错了，算得再准也是白搭。**

#### * 第 20 题　【顺差 = 出口 − 进口（又是一个和差）】

**【题目】**
【材料】2024 年某省出口额 3.82 万亿元，同比增长 9.4%；进口额 2.65 万亿元，同比增长 3.1%。
2023 年该省货物贸易顺差约为多少万亿元？
A. 0.92　B. 1.17　C. 1.35　D. 1.62

**【解】**
1. **列式**：`顺差 = 出口 − 进口`，两边都取基期：
   ```
   所求 = 3.82/1.094 − 2.65/1.031
   ```
2. **排现期坑**：`3.82 − 2.65 = 1.17` → **B 排除**。
3. **量级排除**：两个基期约 3.49 和 2.57，差约 **0.92** → C（1.35）、D（1.62）都过大 → **排除**
4. → **选 A**

**【验证】** `3.82/1.094 = 3.492`；`2.65/1.031 = 2.570`；差 = **0.921** ✓

**【提醒】** 本题和例 18 是同一个套路：**排现期坑 → 量级排除 → 落到唯一答案**，一算都没算。

### E 组　现期量

#### 第 21 题　【保持增量 × 超目标 → 向上取整】

**【题目】**
【材料】2024 年某市博物馆接待观众 386.4 万人次，2023 年为 342.8 万人次。
若保持 2024 年同比增量不变，该市博物馆接待观众将首次超过 500 万人次是在哪一年？
A. 2026 年　B. 2029 年　C. 2028 年　D. 2027 年

**【解】**
```
增量 = 386.4 − 342.8 = 43.6
差距 = 500 − 386.4 = 113.6
113.6 ÷ 43.6 = 2.6  → 向上取整 = 3 年
年份 = 2024 + 3 = 2027
```
**【验算】** 2 年后：386.4 + 87.2 = 473.6 < 500，**不够**；
3 年后：386.4 + 130.8 = 517.2 > 500，**够了**。
→ **选 D**

**【提醒】** 2.6 年**不能四舍五入成 3 就完事**——要验算"3 年到底够不够"。
**"首次超过"= 第一次严格大于目标**，所以边界年份必须实打实加一遍。

#### 第 22 题　【追赶问题：只盯差距】

**【题目】**
【材料】2024 年，A 公司营业收入 58.6 亿元，比上年增加 6.4 亿元；B 公司营业收入 21.8 亿元，比上年增加 9.3 亿元。
若两家公司均保持 2024 年同比增量不变，到哪一年 B 公司营业收入将首次超过 A 公司？
A. 2036 年　B. 2038 年　C. 2037 年　D. 2039 年

**【解】**
```
当前差距 = 58.6 − 21.8 = 36.8
每年缩小 = 9.3 − 6.4 = 2.9
年数 = 36.8 ÷ 2.9 = 12.7  → 向上取整 = 13 年
年份 = 2024 + 13 = 2037
```
**【验算】** 12 年后：A = 58.6 + 76.8 = 135.4；B = 21.8 + 111.6 = 133.4 → **还差 2**
13 年后：A = 141.8；B = 142.7 → **超过了**
→ **选 C**

**【提醒】** 追赶题**千万不要每年列表**，只要三个数：**差距、每年缩小多少、除一下往上取整**。
这题 12.7 → 13，看似"四舍五入也是 13"，但**思路必须清晰**：12 年确实不够（验算给你看）。

#### 第 23 题　【保持增速 × 多年 → (1+r)ⁿ ≈ 1+nr】

**【题目】**
【材料】2024 年某市高新技术企业数量 12840 家，同比增长 8.4%。
若保持该增速不变，2026 年该市高新技术企业数量约为多少家？
A. 15090　B. 13920　C. 16300　D. 17600

**【解】** 2024 → 2026 是 **2 年**：

```
累计增速 ≈ 2 × 8.4% = 16.8%
12840 × (1 + 16.8%) = 12840 + 128.4 × 16.8
                    ≈ 12840 + 2157
                    ≈ 15000
```
→ 与 A（15090）最接近 → **选 A**（实际 15087.7）

**【提醒】** 本题有两个坑：

1. **年数**：2024 → 2026 是 **2 年**，不是 1 年。**B（13920）就是"只算 1 年"的坑。**
2. **(1+r)² 不要硬算**：`≈ 1 + 2r = 1.168`，比真值 1.175 小 0.6%，**不影响选答案**。

#### * 第 24 题　【保持增速 × 多年 → 用增量估算】

**【题目】**
【材料】2024 年某市常住人口 1052.6 万人，比上年增加 18.4 万人，增长 1.78%。
若保持 2024 年的<u>增长速度</u>不变，到哪一年该市常住人口将突破 1160 万人？
A. 2029 年　B. 2030 年　C. 2031 年　D. 2032 年

**【解·用增量估算（最快）】**

```
差距 = 1160 − 1052.6 = 107.4
年数 = 107.4 ÷ 18.4 = 5.8  → 向上取整 = 6 年
年份 = 2024 + 6 = 2030
```
**【验算·用增速】** `(1+1.78%)⁶ ≈ 1 + 6×1.78% = 1.1068`
`1052.6 × 1.1068 ≈ 1165 > 1160` ✓；5 年只有 `1052.6 × 1.089 ≈ 1146 < 1160`。
→ **选 B**

**【提醒】** 这里的"增量估算"要**小心方向**：

- 用"每年加 18.4"估，结果**偏小**（真实增量会随基数变大而变大，这里是确保下界）；
- 但估算值 107.4 ÷ 18.4 = 5.8 → 6 年，**真值只会更大**，所以 6 年足够 → **判断可靠**。
> 反过来，如果估算出来"刚好 6 年"，就不能直接下结论，必须用增速验一次。**这题我验了，是稳的。**（这里是验证上界）
